# 14 注意力、Transformer 与语言模型

本文行数：157行，预期阅读时长：10分钟

<a id="developer-overview"></a>

## 开发者理解：利用上下文，逐步生成输出

**注意力让模型根据当前内容，读取和组合其他位置的信息；Transformer 是使用这种机制的网络结构。** 它可以处理文字、图像表示或其他序列。语言模型只是其中一种用途，架构名称并不自动说明模型能完成什么任务。

文字进入模型时，先由配套的切分工具变成 **token**，即模型处理的小单位；token 不固定等于一个字或一个词。**embedding（嵌入表示）**把这些单位变成用于计算的数值表示。开发时可以先理解为“文字变成模型可用的输入”，无需先掌握向量的每一项。

**例子（教学示意）：** 读“红杯在蓝杯左边”，再回答“左边的是谁”，需要联系颜色、对象和相对位置。注意力提供了让不同位置交换信息的机制，但内部读取权重不能直接作为回答正确的证明。

| 概念 | 可以先理解为什么 |
| --- | --- |
| 自注意力 | 在同一组输入或已有输出内部联系上下文 |
| 交叉注意力 | 从另一组表示读取信息，如生成文字时读取图像表示 |
| 位置信息 | 让模型区分顺序或空间位置，避免只知道有哪些内容 |
| 因果限制 | 生成下一项时只能使用允许的已有信息，不能提前读取未来答案 |

**自回归语言生成**是根据当前上下文预测下一个 token，再把生成结果加入上下文，继续产生下一项。因此它能组合出新的句子，而非只能返回预存的固定答案；也可能沿着一个错误的开头继续生成。

训练时可以给定正确历史，用目标下一项教模型预测；使用时没有正确答案，只能依据输入与自己的已有输出继续。改变采样方式可以改变输出选择，却不会补充新的事实证据。

**上下文是本次计算能利用的信息，参数是训练学到的规律。** 把新材料放进输入会改变本次回答条件，不等于已经把材料训练进权重。KV cache 是生成时复用已有计算的缓存，也不是持久知识库。输入越长或输出越长，通常还会增加资源与时间需求。

**需要深入时：** [注意力计算](#2-一次完整的三位置注意力) · [未来信息限制](#3-因果遮罩改变未来早期输出应保持不变) · [不同信息来源](#4-self-attention-与-cross-attention信息来自哪里) · [生成与缓存](#7-kv-cache-与长上下文)。

[13](../13_sequence_models/README.md)介绍了序列、隐藏状态和编码器—解码器。本章解释模型如何读取不同位置的信息、怎样预测下一个 token，以及训练时为什么能同时计算多个位置。数字采用人工小矩阵，不是语言模型实测。

## 速记要点

- token ID 是离散索引，embedding 是查表得到的向量；位置还需表示顺序，向量默认没有物理单位。
- Q 与 K 决定匹配权重，V 提供被汇总的内容；输出为 V 的加权和。
- self-attention 的 Q/K/V 来自同一序列，cross-attention 的 Q 与 K/V 来自不同序列。
- 因果遮罩在 softmax 前屏蔽未来位置；输入与目标还要错开一位，防止提前看答案。
- 多头使用不同投影，再拼接与映射；不能预设每个头固定负责颜色、位置或语法。
- Transformer 还包含前馈层、残差与归一化；原始编码器—解码器不是所有语言模型的固定结构。
- 自回归训练同时计算已给定序列各位置的 loss，生成则等待上一步选择；KV cache 复用已有 K/V，不是学习新知识。

## 1. 从文字到输入矩阵

**教学词表：** `[开始,猫,在,睡觉,结束]` 对应 ID `[0,1,2,3,4]`，不是实际中文 tokenizer 的规则。真实 tokenizer 可能把词拆成子词，一个词也可能对应多个 ID。

若词表大小 V、向量维度 d，embedding 表为 `E∈Rⱽˣᵈ`。输入 ID `[0,1,2]`，取 E 的三行，得到 `X∈R³ˣᵈ`；ID 的数值大小不表示语义距离，embedding 才是模型可学习的表示。

对 `[B,T]` 个 ID，查表结果为 `[B,T,d]`。语言模型末端把每个位置的隐藏向量映射为 V 个 logits，输出 `[B,T,V]`；选概率最大的 ID，再通过 tokenizer 解码，才得到文字。

## 2. 一次完整的三位置注意力

忽略批次与位置编码，按行存储三个 token，指定：

\[
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
W_Q=W_K=I_2,\quad W_V=\begin{bmatrix}1&0\\0&2\end{bmatrix}.
\]

于是 `Q=XW_Q=X`、`K=XW_K=X`、`V=XW_V=[[1,0],[0,2],[1,2]]`。投影矩阵通常通过训练学习；本例是为看清计算而指定的。

缩放点积注意力为：

\[
A=\operatorname{softmax}_{row}(QK^\top/\sqrt{d_k}+M),\qquad O=AV.
\]

`d_k=2`；M 为可选遮罩，未限制的位置为 0，被屏蔽的位置为负无穷。若查询长 T_q、被读取序列长 T_k，则 Q 为 `[T_q,d_k]`、K 为 `[T_k,d_k]`、V 为 `[T_k,d_v]`，A 为 `[T_q,T_k]`、O 为 `[T_q,d_v]`。[原始 Transformer 注意力公式](https://arxiv.org/html/1706.03762v7#S3.SS2)

**第二个位置，不加遮罩：** q₂=`[0,1]`，与三项 K 的点积为 `[0,1,1]`，除以 √2 后为 `[0,0.707107,0.707107]`。

| 被读取位置 | softmax 权重 | V |
| --- | ---: | --- |
| 1 | 约 0.197776 | `[1,0]` |
| 2 | 约 0.401112 | `[0,2]` |
| 3 | 约 0.401112 | `[1,2]` |

**结果（静态计算）：** 第二个输出约为 `[0.598888,1.604448]`。权重和为 1，输出保持 d_v=2 维，没有变成 token ID，也不能解释为物体位置。

缩放 √d_k 用于控制高维点积的典型尺度；它不是物理距离换算。softmax 权重说明本层怎样汇总向量，不能单独当作事实依据或完整的模型解释。更短的两项投影例子保留在 [16 的预习页](../16_vision_language/01_tokens_attention.md#qkv-from-input)，无需重复背两组数。

## 3. 因果遮罩：改变未来，早期输出应保持不变

自回归模型第二个输入位置只能读取位置 1、2，不能读取位置 3。遮罩矩阵为：

\[
M=\begin{bmatrix}0&-\infty&-\infty\\0&0&-\infty\\0&0&0\end{bmatrix}.
\]

上例第二行的 softmax 变为约 `[0.330238,0.669762,0]`，输出为 `[0.330238,1.339523]`。未来项在归一化之前就被排除，而不是做完 softmax 后随意清零，否则剩余权重和可能小于 1。

**结果与可核对性质：** 把第三个输入任意改成 `[100,−100]`，因果注意力的前两个输出不变；不加遮罩则可能变化。这只证明教学实现的可见范围，不证明某个真实模型整体没有泄漏。padding mask 还需屏蔽无效位置；若某行全部被屏蔽，softmax 没有有效归一化分母，应在接口与序列构造中处理。

## 4. self-attention 与 cross-attention：信息来自哪里

继续采用 [13 的翻译](../13_sequence_models/README.md)：英文完整输入 `The cat sleeps`，中文目标 `猫 在 睡觉`。

| 计算 | Q 的来源 | K/V 的来源 | 是否读取中文未来位置 |
| --- | --- | --- | --- |
| 英文编码器 self-attention | 英文表示 | 英文表示 | 不涉及中文；本例英文可相互读取 |
| 中文解码器因果 self-attention | 中文输入表示 | 中文输入表示 | 不允许 |
| 中文解码器 cross-attention | 中文当前表示 | 英文编码器各位置输出 | 可读完整英文条件，仍不能偷看中文未来 |

例如只有一个解码器查询 `Q=[[1,0]]`，两个编码器位置 `K=[[1,0],[0,1]]`、`V=[[10,0],[0,20]]`，d_k=2。权重约 `[0.669762,0.330238]`，读取结果约 `[6.697615,6.604769]`。查询长 1、源序列长 2，因此 A 为 `[1,2]`，不是方阵。

**解释：** 两种注意力的差别是来源；因果限制的差别是允许看哪里。VLM 的 K/V 可以来自视觉表示，或把视觉与文字放进同一序列使用 self-attention；不必所有模型都显式采用 cross-attention。

## 5. 位置、多头与 Transformer 块

### 位置信息为什么必要

不加位置信息或其他顺序机制时，纯 self-attention 对输入位置的重排会相应重排输出，无法单靠内容向量区分“谁在谁前面”。因果 mask 提供可见范围，但一般不能替代模型的完整位置表示。

原始正弦位置编码为：`PE_(pos,2i)=sin(pos/10000^(2i/d))`、`PE_(pos,2i+1)=cos(pos/10000^(2i/d))`。在 d=2 时，位置 0 为 `[0,1]`，位置 1 约 `[0.841471,0.540302]`；再与内容向量结合。[位置编码原理与例子](https://zh.d2l.ai/chapter_attention-mechanisms/self-attention-and-positional-encoding.html)

也可以学习位置向量或采用其他相对位置方法。文本位置索引不是秒，图像 patch 顺序不是米；机器人不等间隔历史还需实际时间信息。

### 多头怎样组合

H 个头分别用自己的 `W_Q^h,W_K^h,W_V^h`，得到不同 O_h，再 `Concat(O₁,…,O_H)W_O`。常见设置 d 可被 H 整除，每头维度 d/H；整体输出可仍为 `[B,T,d]`。

**独立小例子：** 使用同一个 X，两个一维头分别选择第一、第二个输入分量，Q/K/V 都使用该分量。第二位置在第一头的 q=0，权重均为 1/3，输出 2/3；第二头 q=1，权重约 `[0.155362,0.422319,0.422319]`，输出约 0.844638。拼接后为 `[0.666667,0.844638]`，本例 W_O=I₂。

这些头读取不同投影，并不是预先分配“语法头”和“视觉头”。[多头注意力](https://zh.d2l.ai/chapter_attention-mechanisms/multihead-attention.html)进一步解释并行投影与张量组织。

### 注意力之外还有哪些计算

一个 Transformer 块还包含逐位置前馈网络，如 `FFN(h)=W₂ activation(W₁h+b₁)+b₂`，以及残差、LayerNorm。注意力混合不同位置的信息，FFN 变换每个位置的特征通道；层叠后共同形成表示。归一化在残差前还是后随结构变化，[11](../11_training_optimization/README.md)解释其训练作用。

编码器型常形成双向表示；编码器—解码器型可用于翻译；decoder-only 常用于因果语言生成。原始 Transformer 的层数、维度和顺序是具体设计，不能当作所有 LLM 的规格。[Transformer 数据流](https://zh.d2l.ai/chapter_attention-mechanisms/transformer.html)

## 6. 从隐藏向量到下一 token 分布

**教学词表只有三个候选：** `[猫,狗,结束]`。当前隐藏向量 h=`[1,0]`，输出矩阵取三列 `[2,0]`、`[1,0]`、`[0,0]`，无偏置，得到 logits=`[2,1,0]`，softmax≈`[0.665241,0.244728,0.090031]`。

**结果（静态计算）：** greedy 选择“猫”；采样按分布随机选择，可能得到“狗”。温度 τ>0 时用 logits/τ；改变 τ 不会增加新的视觉证据或知识。预测分布校准与 [09](../09_probability_uncertainty/README.md)一样，需要实际评估。

整句训练仍使用错位目标：

~~~text
输入： [开始, 猫, 在, 睡觉]
目标： [猫,   在, 睡觉, 结束]
       ↑每个输入位置预测下一项
~~~

正确历史已给定，所有位置的矩阵计算可以并行，每层用因果 mask 限制信息流；loss 对有效目标取平均。生成时下一个位置需要先得到本步 token，因而标准自回归解码仍逐步进行。RNN 在训练时的状态递推也依赖前一步，不能把这两种并行能力混为一谈。

## 7. KV cache 与长上下文

对因果 decoder-only，已有位置的 K/V 可缓存；追加 token 时计算它的新 Q/K/V，与之前缓存及新位置读取。若输入、位置和参数一致且评估计算确定，结果应与重算完整前缀相符。缓存不更新参数，不是新增记忆库；换图、改前缀或模板后不能盲目沿用旧缓存。

标准全注意力的每头分数矩阵为 T×T，直接存储的元素数随 T² 增长；从 128 到 256 位置会变为 4 倍。优化实现可以降低实际内存占用，不能把理论矩阵大小当显存实测。

**教学 KV 存储：** 普通多头模型 L=4 层、H=2 头、每头 d_h=8、T=100、B=1，K/V 各按 2 字节存储，共 `2×L×B×H×T×d_h×2=25,600` 字节。某些结构共享 K/V 头，实际公式需相应修改；这里也未计其他张量。

本章所有向量、投影、token 分布和缓存例子均为教学计算，核对了遮罩、重排与逐步缓存的一致性；没有训练语言模型、执行真实 tokenizer 或测试 VLM。见[数值与实现边界](../examples/README.md#multimodal)。
