# 15 表示学习、自监督与预训练

本文行数：126行，预期阅读时长：9分钟

<a id="developer-overview"></a>

## 开发者理解：学习可复用的特征，让数据支持更多任务

**表示学习让模型把原始输入变成对后续任务有用的特征。** 图片像素很多，后续分类、检索或预测可以利用网络形成的内部表示；“表示好不好”取决于它保留了哪些任务信息。

**例子（教学场景）：** 同一个杯子换了光照，仍希望能认出它；但如果任务是“选择红杯”，红色和蓝色就不能被当成无关差别。能忽略哪些变化、必须保留哪些变化，决定学到的特征是否适合用途。

**自监督**是从数据本身构造学习目标，不必为每条数据人工提供类别答案。它仍然有目标与训练误差，例如遮住部分图片，要求预测被遮住的内容；或者把同一张图的两个合理变体作为相关例子。没有人工类别标签，不等于没有学习依据。

| 方法 | 学习的直觉 | 结果有什么用 |
| --- | --- | --- |
| 自编码器 | 将输入形成内部表示，再尝试重建输入 | 学习压缩或重建用的特征 |
| 对比学习 | 让相关例子的表示更接近，与其他候选区分 | 为检索或分类等任务形成相似性表示 |
| 掩码预测 | 利用可见部分预测被遮住的内容 | 学习输入结构与上下文关系 |

**预训练**是在已有数据和任务上建立参数，**下游适配**是把这种能力用于自己的目标任务。第 07 章借用已有视觉特征、训练新分类头，就是一种使用方式；也可以进一步微调特征本身。预训练可以用监督、自监督或其他信号，不是某一种训练方法的同义词。

重建得像、相似度高，不代表所有需要的信息都在。若大量背景被很好重建，却丢掉小物体的位置，整体分数可能好，机器人任务仍可能失败。遮住的内容也可能只是被合理猜测，不能当成实际测量。

特征的各个数通常没有事先指定的物理意义。两个模型都输出相同数量的数，不代表它们的表示可以直接互换；图像和文字的特征要能够比较，也需要相应训练建立联系。

**需要深入时：** [重建与压缩](#2-自编码器压缩再重建) · [对比学习](#3-对比学习正对与负对从哪里来) · [增强与信息保留](#4-增强定义了模型应当忽略什么) · [接入下游任务](#6-预训练如何接到下游任务)。

[05](../05_clustering/README.md)用 PCA 压缩数据，[07](../07_transfer_learning/README.md)使用预训练视觉特征。本章解释表示如何学到、没有人工类别标签时目标从哪里来，以及预训练为何能用于 [16 图文对齐](../16_vision_language/README.md)。

## 速记要点

- 表示学习让编码器把输入变成对任务有用的特征；特征维度相同不意味着语义已对齐。
- 自编码器通过重建输入训练，低维瓶颈限制信息；重建好不保证分类或控制好。
- 自监督从数据自身构造目标，例如两种增强视图、被遮住的像素或下一个 token；仍有明确 loss。
- 对比学习让正对比负对更相似；增强定义了应忽略的变化，错误增强会删除任务信息。
- 掩码预测要求根据可见部分恢复缺失部分，模型可能利用统计规律；它不保证恢复真实隐藏状态。
- 预训练是参数来源，微调是下游适配；冻结、线性探测和全量微调评估的是不同能力。

## 1. 表示与原始数据有什么不同

编码器 `f_θ(x)=h` 可把图片变为向量或带空间结构的特征。原图有数十万个像素，h 可能仅有几百维，或是一组 patch 向量；降低维度不是唯一目标，还要保留任务信息。

若不同相机亮度下的同一杯子特征仍接近，可以帮助识别；但若红杯、蓝杯也被变成相同特征，就损失了“抓红杯”所需的颜色信息。表示的好坏必须相对于目标任务判断。

## 2. 自编码器：压缩，再重建

自编码器（autoencoder）有编码器 `h=f_θ(x)`、解码器 `x̂=g_φ(h)`，以重建损失训练，例如 `L=½‖x̂−x‖²`。输入与重建目标都是 x，但中间需要经过瓶颈或其他约束，不能无条件复制全部输入。

**二维教学例子：** x=`[2,0]`，指定一维编码 `h=(x₁+x₂)/2`，解码 `x̂=[h,h]`。输出 h=1、重建 `[1,1]`、平方损失为 1。输入 `[0,2]` 也得到 h=1，无法从这个表示区分两个原样本。

**结果与原因（静态计算）：** 编码只保留了总量方向，丢掉差异方向。如果两维分别是左侧和右侧信号，本例表示无法判断目标在哪边。这里权重是手工指定的，未训练自编码器。

在线性、平方重建误差和适当约束下，最优低维重建子空间与 PCA 有联系；实际编码坐标不必与 PCA 的轴完全相同，非线性自编码器也不是直接等同于 PCA。[自编码器与 PCA 的作者教材说明](https://www.deeplearningbook.org/contents/autoencoders.html)

重建损失容易关注占比大的背景或纹理。对机器人关心的少量接触点、姿态与细小障碍，整体像素重建好仍可能不足。若瓶颈过宽、目标过容易，还可能学成近似恒等映射。

## 3. 对比学习：正对与负对从哪里来

以同一张图的两种增强视图作为正对，其他图片视图作为负对，是一种常见自监督设计。[SimCLR 原论文](https://arxiv.org/abs/2002.05709)使用增强、编码器及投影头学习视觉表示；其类别标签不是对比 loss 的必需输入。

对一个 anchor 表示 u，正例 v⁺ 与其他候选 v_j，用归一化向量余弦相似度：

\[
L=-\ln\frac{\exp(s(u,v^+)/\tau)}{\sum_j\exp(s(u,v_j)/\tau)}.
\]

τ 是正温度，分母包含正例和本例负例，不包含 anchor 自己。具体方法的候选组织可能不同；不是所有自监督方法都使用负例。

**输入（教学单位向量）：** u=`[1,0]`，正例 v⁺=`[0.8,0.6]`，负例 v⁻=`[0,1]`，相似度分别 0.8、0，τ=0.2。

**结果（静态计算）：** 正例概率 `e⁴/(e⁴+1)≈0.982014`，loss≈0.018150。如果三者都变成同一个向量，两候选相似度相同，概率 0.5，loss=ln2≈0.693147；该例的负例让表示完全坍塌并非最优。

坍塌（collapse）是许多输入得到同样或几乎无差别的表示。单纯最小化正对距离即可用“全部输出 0”投机完成；不同方法用负例、预测器、统计约束等处理，不能把任何一种防坍塌设计推广到全部方法。

**假负例：** 两张不同图片都拍到同类杯子，“不同图片”不保证“语义不同”。直接推远可能与下游类别任务相冲突；图文配对的类似问题见 [16 CLIP](../16_vision_language/02_clip_alignment.md)。

## 4. 增强定义了模型应当忽略什么

| 目标任务 | 可能合理的增强 | 需要避免的解释错误 |
| --- | --- | --- |
| 材料或类别识别 | 保留对象的轻微亮度、尺度变化 | 强烈颜色变化可能改变真实材质线索 |
| 区分红杯与蓝杯 | 保持颜色语义的扰动 | 任意色相变换不能仍声称同一个颜色标签 |
| 框、掩码、关键点预测 | 同步变换图像与标注 | 只翻转图像、不更新坐标会制造错标 |
| 机器人方向或姿态任务 | 与坐标定义一致的变换 | 水平翻转后“图像左边”与动作方向不能照旧 |

例如宽 640 px 的连续坐标图像水平翻转，框 `[120,140,220,300]` 变为 `[420,140,520,300]`，u 方向反向；这与离散像素中心使用 `W−1−u` 的约定不同。图像增强和真实机器人空间变换的关系需另外定义。

增强后的正对表达的是“这些变化不应影响当前表示”；若去掉颜色或左右关系，却还想依赖表示判断这些属性，目标本身就矛盾。

## 5. 掩码预测：利用上下文恢复缺失部分

掩码预测遮住部分输入，用可见内容预测被遮住的目标；掩码比例、目标类型和 loss 位置共同定义任务。文字可预测被遮住的 token，图像可重建 patch；自回归下一 token 则使用因果前缀，三者不是同一种可见范围。

**四维教学输入：** x=`[1,2,3,4]`，只保留位置 1、3，位置 2、4 被遮住。模型预测为 `[任意,2.5,任意,3.5]`，仅在遮住位置取平均平方误差：`[(2.5−2)²+(3.5−4)²]/2=0.25`。

**结果与解释：** 可见位置不参与本例 loss，不能把整个向量都算进去稀释误差；loss mask 与 [14 的 attention mask](../14_attention_transformer/README.md)决定的可读位置也要区分。

[MAE 原论文](https://arxiv.org/abs/2111.06377)让图像编码器只处理可见 patch，用轻量解码器和 mask token 重建缺失部分。以 224×224、16×16 patch 的教学尺寸为例，共 196 个 patch；遮住 75% 时，可见 49 个、重建目标 147 个。这些尺寸仅是教学配置，不是所有 MAE 的统一规格。

像素重建可能根据上下文猜出一种合理内容，不能保证隐藏物体就是猜测结果。例如遮住红杯后，仅凭其余桌面无法确定杯子颜色；训练误差最优预测也可能是颜色的平均，生成的多种可能留到 [17](../17_generative_models/README.md)。

## 6. 预训练如何接到下游任务

预训练用较广的数据与学习目标建立参数；下游用目标任务数据适配表示。监督、自监督和图文学习都可能用于预训练，“预训练”不自动意味着没有标签。

| 用法 | 可训练部分 | 得到的证据 |
| --- | --- | --- |
| 冻结表示直接检索 | 通常无更新 | 现有特征在固定检索任务上的表现 |
| 线性探测（linear probe） | 冻结编码器，只训练线性头 | 表示对线性分类是否容易读取 |
| 部分微调 | 头与部分骨干层 | 允许有限适配后的任务表现 |
| 全量微调 | 所选网络全部参数 | 数据与优化条件下的整体适配表现 |

[07](../07_transfer_learning/README.md)的冻结 ResNet18 与新分类头就是使用已有表示；若跨模型比较，需固定训练标签量、数据划分、输入处理与评价配置，不能用全量微调结果替代“冻结表示本来就好”的证据。

预训练知识可以提高起点，也可能对相机视角、透明材质或机器人状态不足。下游测试仍按独立场景/轨迹划分；预训练数据是否包含评估材料无法确认时，要保留这一限制。

## 7. 接到 VLM：对齐的是什么

视觉编码器和文本编码器可以分别形成表示，再用图文配对目标学习联系。两边相同维度只满足点积接口，配对训练才使这些数值对跨模态任务有意义；“同一空间”是表示中的语义联系，不是物理标定。

表示还可能保留整图信息而丢掉细粒度位置。图文检索正确，不能据此宣称能完成 [12](../12_detection_segmentation/README.md)的框、掩码或关键点任务。16 将进一步区分整图相似度、语言回答与区域定位。

本章小向量、掩码与增强坐标是静态教学计算，没有训练自编码器、SimCLR、MAE 或新预训练模型；核对结果见[12～17 记录](../examples/README.md#multimodal)。
