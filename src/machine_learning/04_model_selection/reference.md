# Digits：决策树、KNN 与模型选择

本文行数：311行，预期阅读时长：15分钟

概念复习见[本章入口](README.md)。以下命令在 `src/machine_learning/04_model_selection/` 下运行，使用已安装本项目依赖的 Python 环境。数据来源见 `data/README.md`，训练会在 `outputs/` 生成结果和模型。

本项目使用 scikit-learn 内置的手写数字数据集（Digits）完成 0～9 的多分类任务。重点是区分训练、模型选择与最终测试：候选模型和超参数只能使用训练集及其交叉验证结果决定；保留测试集只在最后评估一次。

## 欠拟合、过拟合与泛化

模型的目标不是把训练题“背下来”，而是在没见过的新样本上也能表现稳定，这种能力叫作**泛化**。训练集用于让模型学习；验证集（本项目中由训练集内部交叉验证承担）用于比较模型和超参数；测试集在最后才用于一次独立检查。

| 情况 | 训练集表现 | 验证集表现 | 含义与例子 |
| --- | --- | --- | --- |
| 欠拟合 | 较差 | 较差，且通常与训练集接近 | 模型过于简单或学习不足，连训练数据中的规律也没有学到。例如 KNN 取非常大的 `k`，对每个数字都参考过多、相差很远的邻居，训练准确率 0.78、验证准确率 0.76。 |
| 泛化良好 | 较好 | 较好，且与训练集差距较小 | 模型学习到了可迁移的规律，而非偶然细节。例如某个 KNN 配置训练准确率 0.99、5 折交叉验证准确率 0.97；两者都高且差距只有 0.02。 |
| 过拟合 | 很高，甚至接近 1.00 | 明显低于训练集 | 模型记住了训练样本中的噪声或偶然细节，换一批样本就不稳定。例如不限制深度的决策树训练准确率 1.00、交叉验证准确率 0.86，0.14 的差距是过拟合信号。 |

这些数值只是便于理解的示例，是否过拟合应比较多个交叉验证折的均值和波动，而不是只看一次划分。还要注意：训练分数高、验证分数低才是典型过拟合；两者都低更像欠拟合。

可通过限制决策树的 `max_depth`、增大 `min_samples_leaf`、为 KNN 选择合适的 `n_neighbors`，或增加有代表性的训练样本来缓解过拟合。学习曲线也能帮助判断：若训练分数和验证分数都低，优先考虑提高模型能力或改进特征；若两者差距大，优先考虑简化模型、增加数据或加强正则化。

这张图统计全部 `1,797 × 64` 个像素强度的出现次数。

- 横轴：像素强度 `0～16`。`0` 是背景，`16` 表示最强的笔画位置，中间值通常是笔画边缘或灰度过渡；在本项目图表的 `gray_r` 映射中，数值越大颜色越黑。
- 纵轴：具有该强度的像素总次数。

`0` 通常出现最多，因为数字只占图像中央的一部分，许多边缘像素始终或经常是背景。这也说明 64 个像素特征的信息量并不完全相同。

#### `outputs/figures/pixel_feature_statistics.png`：像素特征统计热力图

此图将展平后的 64 个特征重新摆回 `8 × 8` 图像位置，并包含三个子图。三个子图共同的坐标含义是：

- 横轴 `Pixel column`：像素列 `0～7`，从左到右。
- 纵轴 `Pixel row`：像素行 `0～7`，从上到下。
- 每个小格：一个像素特征，例如第 0 行、第 3 列对应 `pixel_0_3`。
- 右侧色条：颜色对应数值的大小；偏黄表示较大，偏紫表示较小。

三个子图分别回答不同问题：

| 子图 | 统计内容 | 如何理解 |
| --- | --- | --- |
| `Mean intensity` | 该位置在全部样本中的平均亮度 | 较亮的中央区域表示数字笔画更常出现于这些位置。 |
| `Standard deviation` | 该位置的像素强度在不同样本之间的变化程度 | 数值较高说明该处有时亮、有时暗，可能更有助于区分不同数字。 |
| `Nonzero rate` | 该位置像素强度大于 0 的样本比例 | 例如 0.9 表示约 90% 的图像在该位置不是纯背景。 |

可以把它概括为：平均亮度告诉我们“笔画常在哪里”，标准差告诉我们“哪里最因数字而异”，非零比例告诉我们“哪里经常被写到”。

### 可选预处理：`MinMaxScaler` 与 `StandardScaler`

Digits 没有缺失值或类别特征，因此不需要填补或编码。对于 KNN，可以将不同的缩放方式作为**仅在训练集内部比较的可选实验**；决策树一般不需要缩放，因为缩放不会改变它按大小关系寻找切分阈值的能力。

| 工具 | 对每个像素特征做什么 | 转换后的典型范围 | 对 Digits 的含义 |
| --- | --- | --- | --- |
| `MinMaxScaler` | 用训练集的最小值与最大值将数值线性映射 | 通常为 0～1 | 原始像素本就在 0～16 的同一量纲，第一版通常不必使用；若使用，它会把每列像素都压到相同范围。 |
| `StandardScaler` | 减去训练集均值，再除以训练集标准差 | 均值约为 0、标准差约为 1；可有负值 | 让变化幅度不同的像素在 KNN 距离中更接近同等权重，可能改善也可能削弱效果，值得与原始特征对照。 |

它们的计算方式分别是：

```text
MinMaxScaler:    x' = (x - min_train) / (max_train - min_train)
StandardScaler:  x' = (x - mean_train) / std_train
```

例如像素值为 8，若该像素在训练集中的最小值为 0、最大值为 16，`MinMaxScaler` 会得到 `0.5`；若该像素的训练集均值为 4、标准差为 2，`StandardScaler` 会得到 `2.0`。前者保留“从最暗到最强笔画”的 0～1 比例；后者表示该数值比这一位置的平均强度高了多少个标准差。

本项目建议先比较三条 Pipeline：原始像素 → KNN、`StandardScaler` → KNN、原始像素 → 决策树。若再试 `MinMaxScaler` 或 PCA，也必须把它们放入 Pipeline，使每个交叉验证折只从该折训练数据学习最小值、最大值、均值、标准差或主成分，避免验证集与测试集信息泄漏。

## 决策树：从训练数据中学习“如果……那么……”规则

可以把决策树理解成：通过连续提问，将样本一步步分到不同类别中。例如判断一只动物是否为猫：

```text
体重 ≤ 8 kg？
├── 否：可能不是猫
└── 是：会“喵喵”叫？
    ├── 是：猫
    └── 否：可能不是猫
```

在本项目中，问题不会是“会不会叫”，而可能是 `pixel_3_4 ≤ 6.5 吗？`：该像素位置的笔画强度是否较弱。树会根据训练数据自动寻找这些特征与阈值。

### 1. 决策树和 KNN 有什么不同？

KNN 的思路是查看新样本附近的 `K` 个训练样本，再根据邻居投票；决策树的思路是从训练数据中学到一套判断规则，然后让新样本沿着规则逐步向下判断。

| 对比项 | KNN | 决策树 |
| --- | --- | --- |
| 学习阶段 | 几乎不学习参数，主要保存训练样本 | 学习特征、阈值与分裂规则 |
| 预测阶段 | 计算与训练样本的距离，再投票 | 从根节点沿条件判断走到叶子节点 |
| 特征缩放 | 通常值得考虑，距离会受尺度影响 | 通常不需要，单调缩放不改变分裂顺序 |
| 可解释性 | 一般，需要检查邻居 | 较强，可直接阅读“如果……那么……”路径 |
| 决策边界 | 由邻居分布决定，通常较局部 | 在原始特征空间中通常是按特征轴切分的分区 |
| 主要风险 | `K` 不合适、特征维度较高时距离失真 | 树过深而过拟合，对训练数据变化敏感 |

### 2. 决策树怎样训练？

假设有一组贷款数据：

| 收入 | 是否有房 | 是否违约 |
| ---: | --- | --- |
| 3000 | 否 | 是 |
| 5000 | 否 | 是 |
| 8000 | 否 | 否 |
| 6000 | 是 | 否 |
| 10000 | 是 | 否 |

算法会尝试很多问题，例如“收入是否小于 7000”“是否有房”“收入是否小于 4000”，并选择能让分类结果变得更纯的问题。若按“是否有房”分裂后，有房的人都不违约，这个子节点已经很纯；无房的人仍可能需要继续按收入分裂。

训练过程可以概括为：

1. 尝试不同特征和不同分裂位置。
2. 计算每种分裂后的类别纯度。
3. 选择效果最好的分裂。
4. 对左右子节点重复以上过程。
5. 达到停止条件后，生成叶子节点。

### 3. 什么叫“纯”？

一个节点中若 10 个样本全是猫，节点非常纯；若有 5 个猫、5 个狗，节点很不纯。分类树常用基尼不纯度或信息熵衡量这种混合程度。

**基尼不纯度（Gini impurity）**是 scikit-learn 分类树的默认指标：

```text
Gini = 1 - Σ(pₖ²)
```

`pₖ` 是节点中第 `k` 类的比例。二分类时，全部属于同一类的 `Gini = 0`；两类各占一半时 `Gini = 0.5`。训练时希望分裂后子节点的加权基尼不纯度尽可能小。

**信息熵（Entropy）**也表达类别混乱程度：

```text
Entropy = -Σ(pₖ × log₂(pₖ))
信息增益 = 分裂前的熵 - 分裂后的加权熵
```

节点越纯，熵越小；信息增益越大，说明这次分裂让类别更容易区分。基尼不纯度和信息熵通常会得到相近的树；初学时可先使用默认的基尼不纯度。

### 4. 数值特征怎样分裂？

对于排好序的年龄 `18、22、25、32、40`，树会尝试类似“年龄 ≤ 20”“年龄 ≤ 23.5”“年龄 ≤ 28.5”的阈值，并计算每种分裂后的不纯度，选择最好的一个。因此问题和阈值不是人预先写死的，而是从训练数据中寻找的。

Digits 的 64 个像素都是数值特征，树同样会尝试诸如 `pixel_2_5 ≤ 7.5` 的问题。由于每一步只按一个像素及其阈值切分，单棵树在像素空间形成的边界通常比较生硬。

### 5. 叶子节点怎样预测？

新样本从根节点出发，根据每个条件进入左或右子树，直到叶子节点。若某叶子中的训练样本有 8 个属于 A 类、2 个属于 B 类：

```text
预测类别：A
P(A) = 0.8，P(B) = 0.2
```

分类树通常预测叶子节点内最多的类别，并将各类别在该叶子中的比例作为预测概率。决策树也能用于回归；回归树的叶子通常输出其中训练样本目标值的平均数。

### 6. 最大问题：过拟合

若不限制决策树，它可能不断分裂，直到几乎记住每个训练样本：训练准确率接近 100%，但新样本准确率可能明显较低。一条诸如“年龄小于 31.7、收入大于 6284，并且编号等于某个值”这样的规则过于精细，通常没有泛化能力。

常用的复杂度控制参数包括：

- `max_depth`：树的最大深度；
- `min_samples_split`：节点至少包含多少样本才允许继续分裂；
- `min_samples_leaf`：每个叶子至少保留多少样本；
- `max_leaf_nodes`：叶子节点的最大数量；
- `ccp_alpha`：通过代价复杂度剪枝降低树的复杂度。

初学时最值得关注的是 `max_depth` 和 `min_samples_leaf`。本项目的交叉验证也显示：最佳决策树的训练—验证准确率差距为 0.139，远大于最佳 KNN 的 0.014，是单棵树过拟合的实际例子。

#### 剪枝（Pruning）

**剪枝**就是主动删去树中“过于细碎、对新数据帮助不大”的分支，让树更简单、更容易泛化。它的直觉是：若一个分支只是为了正确区分极少数训练样本而存在，它很可能记住了偶然噪声，而不是稳定规律。

剪枝有两种常见方式：

| 方式 | 做法 | 常用参数 |
| --- | --- | --- |
| 预剪枝（pre-pruning） | 在树生长过程中，提前限制继续分裂 | `max_depth`、`min_samples_split`、`min_samples_leaf`、`max_leaf_nodes` |
| 后剪枝（post-pruning） | 先长出较完整的树，再删除收益不足的分支 | `ccp_alpha` |

scikit-learn 中的 `ccp_alpha` 使用**代价复杂度剪枝**：它会在“训练分类更准确”和“树结构更简单”之间权衡。`ccp_alpha=0` 表示不额外剪枝；值越大，删去的分支越多，树越浅、叶子越少。它过小时仍可能过拟合，过大时又会使模型过于简单而欠拟合。

因此，剪枝参数不应凭直觉固定。应只在训练集内部通过交叉验证比较多个 `max_depth`、`min_samples_leaf` 或 `ccp_alpha` 值，选择验证表现好的复杂度；之后才对保留测试集做一次最终评估。

### 7. 决策树的优缺点

**优点：**容易理解和解释；通常不需要特征标准化；能处理非线性关系；能自动发现特征之间的组合规则；预测速度快。

**缺点：**容易过拟合；对训练数据的小变化较敏感；单棵树的预测能力可能不够稳定；分裂形成的边界通常较生硬。

一句话记忆：**KNN 通过附近样本进行预测；决策树通过学到的一系列“如果……那么……”规则进行预测。** 学会单棵树后，下一步通常会接触随机森林：它组合多棵不同的决策树，让预测更稳定。

默认使用 `random_state=42` 和分层 80% / 20% 划分。Digits 的每张图片是 `8 × 8` 灰度图，脚本可将其展平成 64 个像素特征供 KNN 和决策树使用。若改用 MNIST，请在 `data/README.md` 和实验记录中补充数据来源、下载日期、样本量及新的划分信息。

## 模型选择配置与当前结果

`src/select_models.py` 使用相同的、带随机打乱的 5 折 `StratifiedKFold`，仅在 `data/train_split.csv` 上比较 32 个候选方案：

- 原始像素 KNN 与 `StandardScaler` → KNN：`n_neighbors` 为 1、3、5、7、9，`weights` 为 `uniform` 或 `distance`；
- 原始像素决策树：`max_depth` 为 `None`、5、10、15，`min_samples_leaf` 为 1、2、5。

按验证准确率均值选择；同分时依次比较宏平均 F1 和训练—验证准确率差距。当前固定切分上的选择结果如下：

| 候选方案 | 训练集内部 5 折验证准确率 | 训练—验证准确率差距 | 结论 |
| --- | ---: | ---: | --- |
| 原始像素 KNN，`k=5`，距离加权 | **0.986 ± 0.010** | 0.014 | 最终选择；原始像素在本数据上优于标准化版本。 |
| `StandardScaler` → KNN，`k=5`，均匀加权 | 0.974 ± 0.007 | 0.012 | 有竞争力，但低于最佳原始像素 KNN。 |
| 原始像素决策树，`max_depth=10` | 0.851 ± 0.020 | 0.139 | 训练分数显著更高、验证分数较低，出现明显过拟合信号。 |

最佳 KNN 的学习曲线中，训练准确率始终为 1.000（训练样本本身会成为最近邻），验证准确率从每折 114 个训练样本时的 0.908 提升至 1,149 个训练样本时的 0.986；验证曲线持续上升且最终与训练分数差距较小，说明增加有代表性的样本有益，未见决策树那样的严重过拟合。

最后一次保留测试集评估得到：准确率 **0.983**、宏平均 F1 **0.983**，360 个测试样本中有 6 个误分类。测试结果与交叉验证结果接近。最终测试脚本在结果已经存在时会默认拒绝重复运行，避免无意中根据测试集继续调参。
