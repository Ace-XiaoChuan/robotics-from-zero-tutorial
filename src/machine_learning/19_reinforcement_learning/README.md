# 19. 强化学习：从回报到连续动作

本文行数：197行，预期阅读时长：12分钟

<a id="developer-overview"></a>

## 开发者理解：通过行动结果学习策略

**强化学习（RL）让策略在环境中行动，利用奖励改进后续选择。** 与行为克隆参考专家动作不同，奖励评价行动结果是否有利；可以没有每一步的专家答案，却需要能够交互的环境和明确的任务目标。

先认识交互中的角色：

| 概念 | 表示什么 |
| --- | --- |
| 状态与观测 | 状态描述环境情况，观测是策略实际能获得的信息 |
| 策略与动作 | 策略依据观测选择动作，动作经环境或控制系统产生影响 |
| 奖励 | 对一次行动后结果的评价分数 |
| 回报 | 累计后续奖励，表达长期效果 |
| 环境 | 执行动作、产生新状态与观测，给出奖励和结束信息的系统 |

**例子（教学任务）：** 机械臂要绕过障碍到达目标。暂时远离目标的一步，可能有利于最终绕过去；只奖励眼前距离缩短，就可能把策略引向错误的偏好。因此强化学习关注后续回报，不只选当前看起来最有利的动作。

**奖励是任务的数值表达，不是系统自动理解了真实意图。** 若等待也能持续得到比到达更高的回报，策略可能学会不动。训练奖励提高，仍需看是否真正到达、是否违反任务约束，以及这种行为在独立条件下是否有效。

**探索**表示尝试不同动作，获得过去没有的经验。它需要环境交互，试错会消耗时间和资源。仿真能提供反复交互条件，但仿真里学到的行为未必直接适合真实机器人。

**价值函数**估计某种状态或动作之后的长期效果，策略决定实际怎么行动。Q-learning、PPO 和 SAC 是利用这些学习信息的不同方法；PPO 常根据近期策略采集的数据更新，SAC 可以复用过去交互记录。先理解交互任务，不必先掌握它们的目标公式。

训练时策略在交互与更新中变化；评估时使用选定策略检查表现，不把每次执行都当成继续训练。动作仍需明确位置目标、增量、速度等语义，并通过匹配的控制器执行；神经网络只是一种策略表示方式。

**需要深入时：** [交互定义](#1-mdp把交互写清楚) · [长期回报](#2-回报现在这步为什么值得走) · [价值与动作选择](#3-用三状态表计算-v-和-q) · [结束条件与接口](#8-episode-结束与机器人接口)。

**强化学习（Reinforcement Learning，RL）用行动后的奖励改进策略，目标是提高期望累计回报。** [18 的行为克隆](../18_imitation_learning/README.md)有专家动作标签；RL 可以没有这种标签，却需要环境转移、奖励定义与探索数据。两者可以结合，但学习信号不同。

本章用一个三状态表解释价值和更新，再连接策略梯度、PPO、SAC 与连续动作。所有数值来自人工表格或代数，没有调用训练库、训练策略或运行机器人环境。

## 速记要点

- 状态描述环境，观测描述智能体实际能看见的部分；只有位置、没有速度时，输入未必足以预测下一步。
- 奖励评价一次转移，回报累计后续奖励；贪图眼前奖励可能妨碍最终任务。
- V 评价一个状态，Q 评价某状态下的一个动作；Bellman 方程把长期价值拆成即时奖励与后续价值。
- Q-learning 用下一状态的最大 Q 更新当前动作；策略梯度直接调整动作概率。
- PPO 用旧策略数据和概率比率约束更新倾向；SAC 用回放数据、价值估计与熵项学习随机策略。
- 连续动作仍需单位、幅度、周期和控制器；更高回报不等于任务验收通过。

## 1. MDP：把交互写清楚

Markov Decision Process（马尔可夫决策过程，MDP）用状态 s、动作 a、转移概率 P、奖励 r 和折扣因子 γ 描述环境。“马尔可夫”表示：给定当前状态与动作，下一状态的分布不再需要更早历史。

~~~text
当前状态 s_t → 观测 o_t → 策略 π(a|o_t) → 动作 a_t
环境产生：s_(t+1)、本次转移奖励 r_(t+1)、是否终止
~~~

例如机械臂状态可含 q、dq、物体位姿、接触状态等；相机只提供遮挡后的图像，因而观测可能不完整，形成部分可观测问题。速度未测、通信延迟或执行器内部状态也会使“当前图片”不足以描述状态；历史窗口或 RNN 可以帮助推断，不能保证恢复全部信息，见 [13 序列模型](../13_sequence_models/README.md)。

策略可以是确定函数 `a=π(o)`，也可以给动作分布 `π(a|o)` 再采样；用表格、线性函数或神经网络都能表示。深度强化学习只是采用深度网络表示策略或价值，并非另一种奖励定义。

本章第一例是完全可观测、确定性、离散状态的 MDP；后面连续动作例仍采用固定基座 B 系 x 方向增量，Δt=0.1 s，与 18 一致。

## 2. 回报：现在这步为什么值得走

采用 `r_(t+1)` 表示动作 a_t 之后获得的奖励。若 episode（一段从重置到结束的交互）在 T 结束：

~~~text
G_t = r_(t+1) + γ r_(t+2) + … + γ^(T−t−1) r_T
~~~

γ 在这里无量纲，表示对较远奖励的折扣；奖励是人工任务分数，不是米或焦耳。若后续奖励为 `[-1,−1,10]`、γ=0.9，回报是 6.2。眼前两步为负，仍可能通向最终成功。

折扣的“远”按决策步计数。γ=0.9 时，第 10 步权重约 0.348678；Δt=0.1 s 对应约 1 s 后。若把周期改为 0.05 s，要保持相同真实时间的指数折扣，应改为 `γ'=sqrt(0.9)≈0.948683`；否则任务偏好也变了。按时间积累的奖励项也需随 Δt 定义。

## 3. 用三状态表计算 V 和 Q

设 S₀ 为“远处”、S₁ 为“近处”、G 为“到达”。动作“前进”或“等待”；一次转移如下，γ=0.9，G 终止且之后不再产生奖励。

| 当前状态 | 动作 | 下一状态 | 本次奖励 | 是否终止 |
| --- | --- | --- | ---: | --- |
| S₀ | 前进 | S₁ | −0.1 | 否 |
| S₀ | 等待 | S₀ | −0.1 | 否 |
| S₁ | 前进 | G | +1 | 是 |
| S₁ | 等待 | S₁ | −0.1 | 否 |

固定策略 π 在两处都前进。状态价值 `V^π(s)=E_π[G_t|s_t=s]`；动作价值 `Q^π(s,a)` 表示先采取 a，再按 π 行动的期望回报。

~~~text
V^π(G)  = 0
V^π(S₁) = 1
V^π(S₀) = −0.1 + 0.9×1 = 0.8
Q^π(S₀,等待) = −0.1 + 0.9×0.8 = 0.62
Q^π(S₁,等待) = −0.1 + 0.9×1   = 0.8
~~~

**结果与解释：** S₀ 等待一次再前进的奖励序列是 `[-0.1,−0.1,1]`，展开回报也等于 0.62。前进在两处都更好，因此本例这条 π 同时是最优策略；这不是所有环境都成立的结论。

这种“即时奖励 + 折扣后续价值”的递推就是 Bellman 方程。随机转移时，右侧还要对下一状态和奖励取期望；随机策略还要对动作取期望。最优动作价值用最大值替代后续策略平均：

~~~text
Q*(s,a) = E[r_(t+1) + γ max_(a') Q*(s_(t+1),a') | s_t=s,a_t=a]
终止转移的目标只有 r_(t+1)，不加入后续价值。
~~~

V 是状态的长期评价，Q 是带动作的长期评价；它们都不是预测下一位置。策略决定实际选什么动作，价值函数帮助评估这项选择。

## 4. Q-learning：未知转移时怎样用样本更新

上节直接知道整个转移表；Q-learning 只需要采到 `(s,a,r,s',terminal)`。表格更新为：

~~~text
y = r + γ max_(a') Q(s',a')          # 非终止
y = r                              # 终止
Q(s,a) ← Q(s,a) + η[y−Q(s,a)]
~~~

`y−Q` 是 temporal-difference error（TD 误差）；η 是更新步长，与 γ 不同。初始所有 Q=0，η=0.5，按以下顺序更新：

| 次序 | 样本 | 当前目标 y | 更新后的对应 Q |
| ---: | --- | ---: | ---: |
| 1 | S₁ 前进到 G，r=1 | 1 | Q(S₁,前进)=0.5 |
| 2 | S₀ 前进到 S₁，r=−0.1 | −0.1+0.9×0.5=0.35 | Q(S₀,前进)=0.175 |
| 3 | 再采 S₁ 前进到 G | 1 | Q(S₁,前进)=0.75 |
| 4 | 再采 S₀ 前进到 S₁ | −0.1+0.9×0.75=0.575 | Q(S₀,前进)=0.375 |

**结果与解释：** 成功的价值从临近状态向前传播，四次更新还没达到 Q*=1 和 0.8。max 使用自己的估计，因此称为 bootstrapping（用估计更新估计）。有限的样本和固定步长不能据此宣布收敛。

收集数据时可以用 ε-greedy：以一定概率探索，否则选当前最大 Q。更新仍用下一状态的最大 Q，而不必使用采样策略实际选的下一个动作，因而是 off-policy（采样策略与目标策略可不同）。动作完全没被试过，价值就缺少证据；函数逼近时还可能有估计与稳定性问题。

## 5. 策略梯度：直接提高好动作的概率

连续动作难以枚举 `max_a Q`，可以直接训练参数化策略。先用一个一步终止例：动作“到达”奖励 1，“不动”奖励 0，策略到达概率为 `p=sigmoid(θ)`。

~~~text
J(θ) = E[G] = p
dJ/dθ = p(1−p)
θ=0：p=0.5，J=0.5，梯度=0.25
~~~

逐条样本不知道整个期望，但可以用 `G ∂logπ(a)/∂θ` 估计梯度。到达时 `∂logp/∂θ=1−p`，不动时 `∂log(1−p)/∂θ=−p`；按两种动作的概率加权，结果同样为 0.25。梯度上升提高到达概率；若代码用梯度下降，就最小化负目标。

常用基线 b(s) 减少估计方差，得到优势 `A=G−b(s)`。θ=0 时取 b=0.5，到达与不动的 A 分别为 +0.5、−0.5；两种样本的 `A ∂logπ/∂θ` 都为 +0.25。动作无关基线的期望梯度为零，故不改变目标梯度；随意用依赖当前动作的基线则没有这项保证。

实际 actor-critic 中，actor 是策略，critic 是学习 V 或 Q 的价值网络。优势可用回报减 V，也可由多步 TD 误差构造；它表示“比这个状态通常的结果好多少”。critic 错误会影响优势估计，并非额外提供了可靠专家标签。

## 6. PPO：为什么要比较新旧动作概率

PPO 的常见版本 PPO-Clip 先用旧策略采样，再更新新策略。对一个已采到的动作，定义概率比 `ρ=π_θ(a|o)/π_old(a|o)`；连续动作比较的是概率密度。其目标最大化：

~~~text
L_clip = E[min(ρ A, clip(ρ,1−ε,1+ε) A)]
~~~

A 在这轮 actor 更新中作为固定的优势估计。ε=0.2，下面是两个独立的教学样本：

| 优势 A | 概率比 ρ | 未裁剪项 ρA | 裁剪项 | 取 min 后 |
| ---: | ---: | ---: | ---: | ---: |
| +2 | 1.3 | 2.6 | 1.2×2=2.4 | 2.4 |
| −2 | 0.7 | −1.4 | 0.8×(−2)=−1.6 | −1.6 |

**结果与解释：** 好动作的概率已经增加过多时，继续增加不再提高该样本的裁剪目标；坏动作的概率已经降低很多时，同样限制继续获益。需要同时看优势的符号与 min，不能简单裁剪所有梯度。PPO 也有其他目标版本，详见 [PPO 原论文](https://arxiv.org/abs/1707.06347)。

裁剪目标没有强制每个概率比都落在 `[0.8,1.2]`，更不是完整策略的硬距离约束；共享参数更新仍能改变其他动作概率。常见实现另检查 KL、价值损失与熵项；同一批数据可以更新若干轮，随后重新采样，不能无限使用陈旧数据冒充当前策略分布。[Spinning Up 的 PPO-Clip 说明](https://spinningup.openai.com/en/latest/algorithms/ppo.html)

## 7. SAC：价值、熵与连续动作

SAC（Soft Actor-Critic）在累计奖励中加入策略熵的奖励，让策略兼顾高回报与分布多样性。连续策略的熵是 `H(π)=E[−logπ(a|s)]`，依赖动作坐标与尺度；温度 α 控制熵项相对权重。它通常使用经验回放，因此能重复利用过去转移。[SAC 原论文](https://arxiv.org/abs/1801.01290)

用常见的双 Q 实现说明：两个 critic 估计 Q₁、Q₂，目标网络缓慢跟随训练网络；下一动作 a' 由当前随机策略采样。critic 目标与 actor 的最小化目标分别是：

~~~text
y = r + γ(1−terminal)[min(Q₁_target(s',a'),Q₂_target(s',a')) − α logπ(a'|s')]
L_actor = E[α logπ(a|s) − min(Q₁(s,a),Q₂(s,a))]
~~~

例如 r=−0.1、γ=0.9、两个下一 Q 为 0.8/1.0、α=0.1、`logπ(a'|s')=−0.5`，非终止目标是 `−0.1+0.9(0.8+0.05)=0.665`。不加熵项为 0.62；终止时两者都只剩 −0.1。取较小 Q 用于抑制过估计，但不是实际回报的保证下界。[Spinning Up 的 SAC 公式](https://spinningup.openai.com/en/latest/algorithms/sac.html)

连续 actor 常先预测高斯分布的均值和尺度，再采样原变量 u，并用 `a=a_max tanh(u)` 限定范围。本章若 a_max=0.05 m、u=2，则请求增量约 0.048201 m；直接把 u=2 发给接口会变成 2 m，而非这个受限动作。

计算对数密度还要修正变量变换：一维、零偏置时 `logπ(a)=logp_U(u)−log[a_max(1−tanh²u)]`。u=0、a_max=0.05 时，雅可比项为 `−log0.05≈2.995732`；密度可以大于 1，对数密度可以为正。动作单位和缩放需固定，归一化坐标下的熵权重不能未经核对就照搬到物理坐标。

## 8. episode 结束与机器人接口

真正终止（任务完成或定义中的失败）没有后续价值；外部时间上限截断一个本来可以继续的任务，通常仍对最后有效观测 bootstrap。Gymnasium 区分 `terminated` 与 `truncated`，不能把两者合成 done 后一律清零。若任务本身就是有限时间，则时间耗尽可属于终止，剩余时间需纳入状态定义。[官方时间上限说明](https://gymnasium.farama.org/v0.26.3/tutorials/handling_time_limits/)

例如 r=−0.1、V_next=0.8、γ=0.9：真正终止目标为 −0.1，外部截断目标为 0.62；即使下一次程序调用会 reset，也不能用 reset 后的新初始观测代替最后观测。

策略输出增量还需通过控制器执行，真实转移由机器人动力学决定。奖励应包含任务结果，必要时考虑碰撞、动作代价等；要分别报告各分量。若把“等待”改为每步 +0.2 且允许一直等，γ=0.9 时等待价值为 2，高于本例前进的 0.8；策略学会不动是奖励设计的结果，算法没有理解你的真实意图。

| 方法 | 数据怎样来 | 核心估计或损失 |
| --- | --- | --- |
| BC | 专家观测与动作 | 拟合动作标签 |
| Q-learning | 转移与奖励，可用探索策略采集 | TD 目标与下一状态最大 Q |
| PPO-Clip | 近期旧策略 rollout | 优势与新旧概率比的裁剪目标 |
| SAC | 环境转移与回放数据 | 双 Q、随机 actor 与熵项 |

**结果与解释：** 选择算法前，先明确示教是否可得、环境能否反复交互、奖励是否表达任务、动作与反馈接口是否可靠。本文的表格更新、概率梯度与目标公式已通过[数值核对](../examples/README.md#robot-learning)；没有 PPO/SAC 训练结果，不能以高奖励宣称机械臂任务完成。独立成功率、泛化和失败分类在下一章展开。
