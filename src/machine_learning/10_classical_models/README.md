# 10 经典模型进阶与方法选择

本文行数：197行，预期阅读时长：12分钟

<a id="developer-overview"></a>

## 开发者理解：同一个预测功能，可以用不同规则实现

**经典模型用不同方式表达“输入与答案的关系”。** 对同一批传感特征，可以按相似案例预测，也可以学一条分界规则，或组合许多条件判断。开发者先理解这些表达方式的区别，就能描述任务和取舍；具体采用哪种实现，可以根据数据比较。

| 方法 | 可以先怎样理解 | 输出是什么 |
| --- | --- | --- |
| 逻辑回归 | 综合各项输入形成分类判断 | 类别及概率形式的分数；名称含回归，但这里做分类 |
| SVM，支持向量机 | 学习区分两类的边界，并关注边界附近的样本 | 类别或边界分数；分数不直接等于概率 |
| 决策树 | 学习一串条件判断，把样本分到不同区域 | 类别或预测数值 |
| 随机森林 | 汇总多棵带随机性的树的判断 | 综合的类别、分数或数值 |
| 梯度提升 | 顺序增加小模型，逐步修正当前预测 | 最终组合模型的预测 |

**例子（任务示意）：** 输入某台设备的振动、温度和负载，希望输出“正常或异常”。这是一项分类需求；上述多种方法都可能用于它。若异常取决于温度与负载的组合，单独看某一个字段，或只用过于简单的综合规则，可能表达不了真正的关系。

这里的**线性与非线性**可以先理解为关系能有多复杂。简单线性边界只能按一种整体分界区分类别；树的区域划分或核 SVM 的相似度规则，可以表达更复杂的组合。更复杂的表达也可能记住噪声，不能凭方法名称断定一定更好。

**集成**是组合多个模型的输出。森林让多棵树分别学习再汇总，提升则让后续模型接着改进前面的预测。组合有机会减轻单个模型的局限，但如果输入都缺少必要信息，或多个模型犯相同错误，增加数量也不能自动解决问题。

选方法时，预测效果之外还可能关心：是否容易解释、对少数异常会漏掉多少、预测有多快、数据量和资源是否够用。比较只有在输入定义、数据划分和指标一致时才有意义；模型中的相关关系，也不能直接作为现实因果结论。

**需要深入时：** [逻辑回归](#2-逻辑回归从线性分数到概率) · [SVM](#3-svm间隔支持向量与核) · [树与森林](#4-决策树与随机森林分区域再汇总) · [模型比较](#6-放在一起看边界与错误)。

本章把[01 的距离](../01_supervised_knn/README.md)、[02 的损失与正则化](../02_regression/README.md)、[04 的泛化](../04_model_selection/README.md)和[09 的概率](../09_probability_uncertainty/README.md)串起来。重点是模型如何表达分类规则、怎样训练、会在哪种结构上出错；不要求安装或训练这些模型。

## 速记要点

- 逻辑回归（logistic regression）做分类：线性分数经过 sigmoid 得到正类概率，用交叉熵训练。
- 线性 SVM 关注分类间隔，hinge loss 惩罚错分和间隔不足；边界分数不是概率。
- 核 SVM 用样本间相似度表达非线性边界；特征尺度、核宽度和正则化都会改变它。
- 决策树按条件切分区域；随机森林让多棵带随机性的树分别学习，再汇总输出。
- 梯度提升（gradient boosting）顺序添加小模型，让新模型修正当前损失的下降方向；分类时一般不能简单称为“拟合标签残差”。
- 输入表示和划分决定比较是否有意义。模型排名不能从四个教学点推广到真实机器人数据。

## 1. 同一组四点：为什么一条直线不够

**输入（教学数据）：** 两个特征都已经按训练尺度变为无量纲数。可把 x₁、x₂ 想成中心化后的两项传感特征；标签规则是两者符号不同时为 1，否则为 0。它展示特征交互，不代表真实可抓取判据。

| 点 | x₁ | x₂ | 标签 y |
| --- | ---: | ---: | ---: |
| A | −1 | −1 | 0 |
| B | −1 | +1 | 1 |
| C | +1 | −1 | 1 |
| D | +1 | +1 | 0 |

~~~text
        x₂
    B:1 │ D:0
   ─────┼───── x₁
    A:0 │ C:1
~~~

这就是 XOR（异或）结构。两个正类在一条对角线上，两个负类在另一条对角线上；无法用一条直线把正负类完全隔开。例如若要求 `f(B)>0`、`f(C)>0`，两者相加得到 `2b>0`；同时要求 `f(A)<0`、`f(D)<0`，相加却得到 `2b<0`，矛盾。这里 `f(x)=w₁x₁+w₂x₂+b`。

这说明模型表达能力的限制。错误不一定来自优化器没找到参数，也不一定来自数据量不足；先要看可用特征下，模型能否表达目标规律。

## 2. 逻辑回归：从线性分数到概率

对 d 维输入 `x∈Rᵈ`、权重 `w∈Rᵈ`、偏置 `b∈R`：

\[
z=w^\top x+b,\qquad
p=\sigma(z)=\frac1{1+e^{-z}},\qquad
\hat y=\mathbf1[p>0.5].
\]

本章约定刚好 `p=0.5` 时归 0；这是教学并列处理规则，不是所有库的默认规则。sigmoid 单调，因此阈值 0.5 的边界仍是 `z=0`，没有凭空变成非线性分类器。

二分类平均交叉熵与可选 L2 项为：

\[
\mathcal L=\frac1n\sum_i[\ln(1+e^{z_i})-y_i z_i]+\frac\lambda2\|w\|^2,
\]

\[
\nabla_w\mathcal L=\frac1n\sum_i(p_i-y_i)x_i+\lambda w,\qquad
\frac{\partial\mathcal L}{\partial b}=\frac1n\sum_i(p_i-y_i).
\]

**结果（四点数据的静态推导）：** 在 `w=(0,0), b=0`，每点 `p=0.5`；正负标签和特征对称，两个权重梯度、偏置梯度都为 0，平均损失为 `ln2≈0.693147`。该目标是凸函数，这个驻点就是全局最优解之一；加正的 L2 项后也不能创造缺失的交互表达。按本章并列规则，四点都报 0，漏掉 B、C。

如果增加交互特征 `φ=x₁x₂`，线性分数 `z=−2φ` 已能表达这个规则：正类概率约 0.880797，负类约 0.119203，四点都分类正确。这组系数是教学指定值，未执行拟合；它说明“对特征线性”与“对原始输入线性”不是同一回事。未经独立数据检验的概率仍不能宣称校准。

逻辑回归名称中的“回归”来自对数赔率 `ln[p/(1−p)]=wᵀx+b` 的线性关系。常规实现提供概率输出，支持正则化；scikit-learn 的 `C` 是正则强度的倒数，不能当成上式 λ 原样代入。[scikit-learn 1.7.2 逻辑回归](https://scikit-learn.org/1.7/modules/linear_model.html#logistic-regression)

## 3. SVM：间隔、支持向量与核

### 线性 SVM 为什么不仅关心分对没有

先把标签改为 `t_i=2y_i−1∈{−1,+1}`。`t_i f(x_i)` 是带正确类别符号的分数：正值表示分对，负值表示分错。hinge loss 为：

\[
\ell_i=\max(0,1-t_if(x_i)),\qquad
\mathcal L=\frac\lambda2\|w\|^2+\frac1n\sum_i\ell_i.
\]

| 带符号分数 `t f(x)` | hinge loss | 解释 |
| ---: | ---: | --- |
| −0.5 | 1.5 | 分错 |
| 0.2 | 0.8 | 分对但距边界较近 |
| 1.5 | 0 | 已满足本例间隔要求 |

当 `w≠0` 时，点到超平面的几何距离是 `|f(x)|/‖w‖`。正负两侧 `f=±1` 之间宽度为 `2/‖w‖`，所以减小权重范数与扩大间隔相关。软间隔允许违反条件，用损失和正则项权衡；支持向量是训练中对最终边界起作用的样本。[SVM 原理与参数](https://scikit-learn.org/1.7/modules/svm.html#svm-classification)

**四点结果（静态推导）：** 在 `w=0,b=0`，每点 hinge loss 为 1，对称性使梯度为 0；该凸目标达到最小值。由于允许软间隔，这里有些偏置取值也同样最优；本章选择 b=0。它仍无法把 XOR 四点全分对，换一套线性损失没有解除表达限制。

### 核 SVM 如何得到非线性边界

核函数 `K(x,x')` 给出隐式特征空间中的内积，无需显式列出所有新特征。RBF 核为：

\[
K(x,x')=e^{-\gamma\|x-x'\|^2},\qquad
f(x)=\sum_i\alpha_i t_iK(x_i,x)+b.
\]

`γ` 控制相似度随距离下降的速度；过大时影响局限在样本附近，过小时差异被抹平。`α_i` 是训练求出的系数，非零项对应支持向量；`f(x)` 的正负决定类别，不能把 `f=0.9` 当作 90% 概率。

**四点的可核对解：** 取 `γ=0.5`、标准软间隔 SVC 的 `C=2`。利用对称性，可取全部 `α_i=α=1/(1−e⁻²)²≈1.337533`、b=0。相邻角的核值为 `e⁻²`，对角为 `e⁻⁴`，在每个训练点有：

\[
t_i f(x_i)=\alpha(1-2e^{-2}+e^{-4})=1.
\]

系数在 `(0,C)` 内，且 `Σα_i t_i=0`；这些满足此凸优化问题的最优性条件。四点均分对，全部是支持向量。这是对称教学数据的解析解，不是调用 scikit-learn 求解器的实测。

对于 `q=(−0.8,+0.8)`，核展开得到 `f(q)≈0.818561>0`，预测 1。RBF 边界在本例为两条坐标轴；轴上的分数是 0，输入分布稍变，边界未必仍是如此。原始特征单位也会改变距离与 γ 的意义，仍要按[03](../03_preprocessing_pipeline/README.md)使用训练统计缩放。[官方核函数说明](https://scikit-learn.org/1.7/modules/svm.html#kernel-functions)

## 4. 决策树与随机森林：分区域，再汇总

**指定一棵深度为 2 的教学树：** 先检查 `x₁≤0`，再检查 `x₂≤0`。两个符号相同的叶子输出 0，不同的叶子输出 1；四点均正确。它用轴对齐的区域分割形成非线性规则，叶子通常保存训练样本类别比例或回归均值。

树的训练需要选择切分，而不是预先知道规则。例如分类常用 Gini 不纯度 `G=1−Σp_k²`。四点根节点有一半正类、一半负类，G=0.5；只沿任何一个轴切一次，两侧都仍是一半正类、一半负类，加权 G 仍为 0.5，第一步改善为 0。

**结果与易错点：** 深度 2 的树“能表示”XOR，但贪心算法若拒绝零改善的第一步，就未必能学到它。不能因手工树分对，就说任意默认决策树都能得到相同结果。树深、最小叶子样本数和切分停止条件决定容量与稳定性。[决策树原理](https://scikit-learn.org/1.7/modules/tree.html)

随机森林的典型机制是：每棵树从训练样本中有放回抽样（bootstrap），切分时再随机选择候选特征，然后汇总多棵树。随机性让树的错误不完全相同；完全相关的错误不会因为树数量多就消失。

**一个汇总示例，非森林训练：** 指定三棵树 T₁、T₂、T₃。前两棵分别按 x₁、x₂ 开始，完整表达 XOR；第三棵始终报 0。对 B，各树正类叶子概率为 `[1,1,0]`，平均为 2/3；对 A 为 `[0,0,0]`，平均为 0。这里叶子都是纯类，所以平均概率等同于投票比例。

真实 scikit-learn 分类森林汇总的是各树类别概率，叶子混合时不等于硬投票。例如叶子概率 `[0.51,0.51,0]`，硬投票会选择 1，但平均概率只有 0.34，按 0.5 阈值选择 0。汇总概率仍需按 09 检查校准；三棵手工树不是已训练的随机森林。[随机森林汇总方式](https://scikit-learn.org/1.7/modules/ensemble.html#forest)

## 5. 梯度提升：新树修正当前预测

森林的树分别训练并汇总；梯度提升按顺序构造：

\[
F_m(x)=F_{m-1}(x)+\eta h_m(x).
\]

`F` 是当前预测函数，`h_m` 是新增小树，η 是学习率。新树拟合每个训练点上损失对当前预测的负梯度。

- 平方回归损失 `½(y−F)²`：负梯度是 `y−F`，正好为通常所说的残差。
- 二分类交叉熵：F 表示 logit，`p=σ(F)`，负梯度是 `y−p`；不能直接用 `y−F`。

**输入（同一四点）：** 正负各半，初始 `F₀=0`，所以 p=0.5。A/B/C/D 的负梯度分别是 `[-0.5,+0.5,+0.5,−0.5]`。指定前一节的深度 2 区域，叶子取各区域负梯度均值，得到小树 h₁ 的相应输出。

**一次纯梯度提升结果（静态计算）：** η=1，`F₁=±0.5`，正类点概率约 0.622459，负类点约 0.377541；平均交叉熵从 0.693147 降为 0.474077，四点分类正确。η=0.1 时分数为 ±0.05，平均损失约 0.668460，单步改善更小。

这里演示的是“拟合负梯度后直接加一小步”。具体库可能进一步优化叶子值，或用二阶梯度信息；本例数字不是 `GradientBoostingClassifier` 或其他库的默认训练输出。[梯度提升的加法模型与损失](https://scikit-learn.org/1.7/modules/ensemble.html#gradient-boosting)

如果只允许深度 1 的树桩（stump），四点沿任何轴切分后的负梯度均值都是 0，新树只能报 0，第一步就没有改进。增加这样的树数不能自动学会特征交互；弱模型的表达能力、树深、学习率和训练轮数必须一起考虑。验证损失开始上升时还应回查 04 的过拟合，而非只看训练损失。

## 6. 放在一起看边界与错误

**固定查询集（教学构造）：** 把四个角分别向原点移动，得到 `(-0.8,-0.8)`、`(-0.8,+0.8)`、`(+0.8,-0.8)`、`(+0.8,+0.8)`；仍按符号不同为 1 的人为规则给标签 `[0,1,1,0]`。不是随机留出的真实测试集。

| 方法与本文设置 | 四个查询的预测 | 错误数 | 边界或限制 |
| --- | --- | ---: | --- |
| 原始两特征逻辑回归，解析最优 w=0,b=0 | `[0,0,0,0]` | 2 个假阴性 | 全部 p=0.5，缺少交互 |
| 原始两特征线性 SVM，选 w=0,b=0 | `[0,0,0,0]` | 2 个假阴性 | 线性表示仍不足 |
| 1-NN，等尺度欧氏距离 | `[0,1,1,0]` | 0 | 最近角决定类别，轴处会并列 |
| RBF SVM，上述解析解 | `[0,1,1,0]` | 0 | 非线性相似度边界；分数不是概率 |
| 手工深度 2 树 | `[0,1,1,0]` | 0 | 按轴切分；未证明贪心训练可得到 |
| 三棵手工树的概率平均 | `[0,1,1,0]` | 0 | 只演示森林汇总，不是训练结果 |
| 指定深度 2 树的一步梯度提升 | `[0,1,1,0]` | 0 | 分类对但概率尚接近 0.5 |

**结果（标准库计算已核对）：** 上表说明同一数据结构下，表达方式会改变结果。它不支持“树一定比线性模型好”：若实际规则就是线性的，简单模型可能更稳；若四个点含错标，复杂模型也可能把噪声记下来。对于轴上的 `(0,0.2)`，本例规则还未定义真实标签，模型间的并列处理差异不能算谁正确。

## 7. 面向已有机器人学习主线，怎样选起点

| 数据与需要 | 可以先比较什么 | 必须核对的局限 |
| --- | --- | --- |
| 少量表格或传感特征，需要解释影响方向 | 逻辑回归、浅树 | 单调或线性假设、特征交互、相关特征对系数解释的影响 |
| 距离有明确意义、样本规模较小 | KNN、缩放后的核 SVM | 维度、尺度、预测开销；噪声与相似度是否有意义 |
| 表格中存在阈值和复杂交互 | 随机森林、梯度提升 | 场景划分、树容量、概率校准、训练外范围 |
| 原始图像或长序列 | 回查 07，后续接 12～15 | 先明确表示和任务；表格模型仍可比较提取后的特征 |

这些是按模型机制选择比较对象，最终结论来自同一数据契约和评估划分。先固定预处理、按场景或轨迹划分、选任务相关指标，再在验证集选择模型；一次性测试集不参与反复调参。召回、误报、推理延迟和不确定性是否满足任务，要分开记录。

树通常不依赖特征尺度，但输入的单位、类别含义与数据划分仍需正确。这里用四个教学点比较模型规则，真实任务的效果需用独立数据评估。
