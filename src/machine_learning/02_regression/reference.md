## 核心概念

| 概念 | 简明解释 | 在本项目中的含义 |
| --- | --- | --- |
| 回归 | 预测可取任意数值范围内数值的监督学习任务。 | 根据面积、房间数、位置等信息预测房价；或根据日期、天气等预测单车租赁量。 |
| 线性回归 | 用特征的加权和加上截距来预测数值的模型。 | 模型会学习每个特征对预测结果的大致线性影响。 |
| 基线模型 | 第一个简单、可运行、可比较的方案。 | 先训练 `LinearRegression`，后续模型或特征改进都以它为参照。 |
| 拟合（fit） | 从训练数据中学习并记住规则或参数。 | 填补器学中位数、标准化器学均值和标准差、编码器学类别列表、线性回归学特征权重。 |
| 残差 | 单个样本的真实值减去预测值。 | `残差 = y_true - y_pred`，正值表示预测偏低，负值表示预测偏高。 |
| 损失函数 | 将一批预测误差汇总成一个数，用来衡量模型好坏并指导训练。 | 线性回归通常以残差平方的平均值为优化目标。 |
| 均方误差（MSE，Mean Squared Error） | 所有残差平方后的平均值。 | 值越小表示平均误差越小；它会更严厉地惩罚少量很大的错误。 |
| 平均绝对误差（MAE） | 所有残差绝对值的平均值。 | 值越小越好，且单位与房价或单车需求量相同，便于直接理解“平均差多少”。 |

### 线性回归在做什么？

对于一个样本的特征 `x₁, x₂, …, xₚ`，线性回归预测：

```text
ŷ = b + w₁x₁ + w₂x₂ + … + wₚxₚ
```

其中 `ŷ` 是预测值，`b` 是截距，`w` 是模型从训练数据中学习到的权重。例如，若其他条件不变，面积对应的权重为正，模型就倾向于认为面积增大时房价更高。线性回归并不要求原始世界完全是线性的；它只是一个透明、快速、很适合作为起点的近似模型。

### 线性回归对特征数量和幂次有什么要求？

线性回归不要求只有一个特征。用 `p` 个输入特征预测房价时，模型通常需要学习 `p + 1` 个参数：一个截距和每个特征各一个权重。

```text
SalePrice = b₀ + b₁ × 居住面积 + b₂ × 卧室数 + b₃ × 建造年份
```

其中居住面积、卧室数和建造年份是输入特征；`b₀、b₁、b₂、b₃` 是需要从训练数据中估计的未知参数。理论上，普通最小二乘要获得稳定、唯一的解，训练样本数应至少多于待估计参数数，且特征不能完全重复。实践中，训练样本数应**明显多于**特征数；若两个特征表达几乎相同的信息，系数会变得不稳定、难以解释，这种现象称为**多重共线性**。

线性回归的“线性”是指模型对未知参数保持线性，而不是规定每个输入特征只能出现一次。下面两个模型对参数都是线性的：

```text
y = b₀ + b₁x
y = b₀ + b₁x + b₂x²
```

第二个式子中的 `x²` 是一个新特征，称为二次项；模型仍只是学习 `b₀、b₁、b₂` 三个权重，因此仍可用线性回归。相反，`b₁ × b₂ × x` 让未知参数彼此相乘，不是普通线性回归的形式。本周的第一版基线先不加入平方项或特征交互项。

### 原始特征与独热编码

**原始特征**是从数据集中直接选出的、尚未经过模型专用转换的字段。例如 Ames Housing 的 `Gr Liv Area`（居住面积）、`Year Built`（建造年份）和 `Neighborhood`（社区）都是原始特征。`Order`（记录顺序）、`PID`（房屋编号）虽也在原始数据中，但只是标识符，通常应排除；`SalePrice` 是目标值，绝不能作为输入特征。

数值原始特征可直接进入数值预处理流程；但类别原始特征不能直接交给线性回归。对于 `Neighborhood` 这类社区名称，**独热编码（One-Hot Encoding）**会为每个可能类别建立一个 0/1 指示列，例如：

| Neighborhood | Neighborhood_NAmes | Neighborhood_Gilbert | Neighborhood_CollgCr |
| --- | ---: | ---: | ---: |
| NAmes | 1 | 0 | 0 |
| Gilbert | 0 | 1 | 0 |
| CollgCr | 0 | 0 | 1 |

这样，线性回归可以为每个类别学习独立的权重，而不会误认为类别名称之间存在数值大小或距离。某些字段看起来是数字也未必是数值特征：例如 `MS SubClass` 是住宅类型代码，应按类别进行独热编码；而 `Lot Area`（土地面积）的数值差值有实际意义，应作为数值特征处理。

因此，本项目第一版的输入处理原则为：保留有业务含义的原始特征；数值特征填补缺失值后标准化；类别特征填补缺失值后独热编码；删除 `Order`、`PID`；并将全部步骤放进 `Pipeline`，使预处理规则只从训练集学习。

### 为什么先建立基线模型？

基线不是“随便做一下”，而是之后判断改进是否真实有效的标尺。一个合格的线性回归基线应固定数据划分、把预处理和模型放进同一个 `Pipeline`，并保存训练集和测试集指标。之后新增特征、替换模型或调整处理方式时，只改变一个或少数变量，与同一基线对比。

还可以增加一个更朴素的参照：无论输入是什么，都预测训练集目标值的平均数。若线性回归没有明显优于它，通常说明特征、数据处理或问题定义仍值得检查。

### 残差、损失函数、MSE 与 MAE 的关系

对第 `i` 个样本：

```text
残差：eᵢ = yᵢ - ŷᵢ
平方误差：eᵢ²
MSE： (e₁² + e₂² + … + eₙ²) / n
MAE： (|e₁| + |e₂| + … + |eₙ|) / n
```

残差保留了方向，因此适合画图检查系统性偏差：如果高房价样本大多为正残差，模型可能普遍低估高房价。**MSE（Mean Squared Error，均方误差）**则通过平方消除了正负抵消，并放大大误差；这使它对严重预测失败很敏感。MSE 的单位是目标值单位的平方。

**MAE（Mean Absolute Error，平均绝对误差）**先取每个残差的绝对值再求平均，不会让正负误差互相抵消。它的单位与目标值相同：如果房价以“万元”为单位，`MAE = 8` 可以直接理解为“模型平均相差约 8 万元”。相比 MSE，MAE 对少量极端大误差没有那么敏感；因此建议同时报告两者：用 MAE 说明典型误差大小，用 MSE 观察严重错误是否很多。

### 什么是最小二乘法？

**最小二乘法（Ordinary Least Squares，OLS）**是一种估计线性回归参数的方法。“二乘”指把每个样本的残差平方，得到平方误差；“最小”指不断调整截距和各个特征的权重，让所有训练样本的平方误差之和最小：

```text
残差平方和（RSS）= e₁² + e₂² + … + eₙ²
```

因为同一训练集上的样本数 `n` 是固定的，最小化 RSS 与最小化 `MSE = RSS / n` 得到的最佳参数相同。`scikit-learn` 的 `LinearRegression` 默认使用的就是普通最小二乘思想：它会寻找一组权重，使训练数据上的残差平方和尽可能小。这里的“最小”只保证训练集的平方误差最小，不保证测试集也最好，因此仍需用未参与训练的测试集 MSE、MAE 和 R² 评估泛化能力。

## 推荐工作流程

```text
原始数据
  → 确认目标列与特征列，检查缺失值和异常值
  → 划分训练集（80%）与测试集（20%）
  → 仅在训练集内拟合预处理：数值列填补/标准化，类别列填补/独热编码
  → 训练线性回归基线
  → 分别评估训练集、测试集：MSE、MAE、R²
  → 绘制预测图和残差图，分析绝对误差最大的五个样本
```

对表格数据，建议使用 `ColumnTransformer` 分别处理数值列和类别列，再用 `Pipeline` 连接到 `LinearRegression`。这样对测试集调用 `predict()` 时会自动复用从训练集学到的处理规则，避免泄漏。

对预处理器调用 `fit()` 时，它从训练集记住填补值、均值、标准差和类别列表；对线性回归调用 `fit()` 时，它学习各特征的权重。测试集不能再次 `fit()`，只能沿用训练集规则完成 `transform()`，再调用 `predict()` 得到房价预测。

## 如何判断结果？

- 训练误差和测试误差都高：可能是特征信息不足、线性关系假设过强，或预处理不合适，属于欠拟合信号。
- 训练误差很低、测试误差明显更高：模型可能对训练数据拟合过度，或训练集与测试集分布不同。
- 残差应大致围绕 0 随机分布；若呈现曲线、扇形或明显分组，说明可能存在未建模的非线性、异方差或遗漏特征。
- 即使模型正确实现，误差也通常不可避免：特征并未包含影响结果的全部因素，测量与标注会有噪声，未来数据也会与训练数据略有差异。

## 运行说明

先启用本项目使用的虚拟环境。若需要重新生成固定的训练/测试集划分：

```bash
source ~/mujoco-env/bin/activate
python src/split_ames.py --random-state 42 --test-size 0.2
```

这会读取完整的 `data/AmesHousing.txt`，随机打乱并输出 `data/train.csv`（2,344 条）与 `data/test.csv`（586 条）。之后进行数据探索：

```bash
python src/explore_ames.py
```

完成探索后，可在训练集上拟合预处理规则，并转换训练集与测试集：

```bash
python src/preprocess_ames.py
```

脚本会删除 `Order`、`PID`；将 `MS SubClass`、`Mo Sold` 视为类别；对 34 个数值特征使用“中位数填补 → 标准化”，对 45 个类别特征使用“`Missing` 填补 → 独热编码”。预处理器只在训练集上 `fit`，测试集只执行 `transform`，最终得到 341 列特征。

最后训练均值参照和线性回归基线，并生成指标、预测图、残差图和最大误差样本：

```bash
python src/train_baselines.py
```

若要查看拟合后的线性回归公式和全部系数：

```bash
python src/inspect_linear_formula.py
```

公式中的数值特征已经标准化，类别特征已经独热编码；完整公式以“截距 + 所有系数项之和”的形式保存在 `outputs/linear_regression_formula.md`，并非一条只含面积、房间数等少数原始字段的短公式。

脚本会打印数据规模、数值/类别字段数量、五个典型房屋特征及其房价、缺失值最多的字段，以及 `SalePrice` 的描述统计、偏度和房价区间计数；同时将直方图保存到 `outputs/saleprice_distribution.png`。

可选参数示例：

```bash
python src/explore_ames.py --rows 5 --histogram-bins 20
```
