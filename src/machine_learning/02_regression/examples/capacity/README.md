## 实际配置与结果

2026-09-29 运行完成。Python 3.10.12、NumPy 1.21.5、Matplotlib 3.5.1，CPU、无窗口绘图。仅依赖 NumPy 与 Matplotlib；没有使用 scikit-learn、下载数据或读取其他私人项目环境。

- 输入 x、输出 y 均无量纲；x 均匀分布于 [-1,1]，y=sin(πx)+独立高斯噪声，噪声标准差 0.2。
- 单次对比：训练种子 42、20 个样本；验证种子 2026、2,000 个样本。次数为 1、3、12；十二次额外比较 λ=0.001、1。
- 数据量对比：训练种子 100～129，各生成 320 个样本，再取前 20、80、320 个作为嵌套子集；每次重新拟合标准化。共 30×3×4=360 次拟合，加上单次对比 5 次，共 365 次。
- 每次相同训练子集供各模型共享；同一独立验证集用于所有比较。没有最终测试集或最优模型交付结论。
- 指标与每次重复的原始误差保存在[metrics.json](results/metrics.json)，训练及预测均未截断；拟合图仅为可读性裁切纵轴。

## 数值实现

目标为平均平方误差加 λ 倍非截距系数平方和。用训练集统计标准化多项式特征，以增广最小二乘求解：在设计矩阵下方附加非截距对角项 sqrt(nλ)，对应标签补零；`numpy.linalg.lstsq` 求解，不显式求逆。

高次单项式具有数值条件问题。标准化并不能完全消除列相关性，SVD 最小二乘也不会消除统计过拟合；本案例同时体现小样本覆盖不足与高次多项式的脆弱性，不代表所有高容量模型都会如此。
