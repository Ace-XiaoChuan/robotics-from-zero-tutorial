# 机器学习概念总览：把已有知识串起来

本文行数：101行，预期阅读时长：6分钟

## 速记要点

- 监督、无监督、强化学习描述学习信号；深度学习描述使用多层神经网络的方法，不能把四者平排为互斥类别。
- 分类预测类别，回归预测数值；神经网络既能做分类，也能做回归或表示策略。
- 训练调整模型，推理使用模型；有些模型用梯度更新参数，KNN 等方法并不这样训练。
- 模型在训练数据上表现好，只说明能适应这些数据；泛化要看未参与拟合和选模型的数据。
- 迁移学习利用已有任务学到的知识。只训练分类头，也可以在使用深度网络。

## 1. 三个维度放在一起看

| 维度 | 回答什么 | 例子 |
| --- | --- | --- |
| 任务 | 想输出什么？ | 类别、价格、数据分组、下一步动作 |
| 学习信号 | 根据什么改进？ | 标签、数据结构、奖励 |
| 模型与方法 | 怎样表示和求解？ | KNN、线性模型、决策树、深度神经网络 |

VLM（视觉语言模型）按处理的模态与任务能力命名，不是与监督学习、深度学习并列的互斥类别。它联系图像和语言，既可以做图文匹配，也可以生成看图回答；按训练阶段使用对比学习、目标 token 预测或指令微调等方法。尚未学过时，进入 [VLM 首次预习](16_vision_language/README.md)补齐 token、注意力和跨模态原理。

监督学习使用输入与目标标签，例如图片对应“纸张”。无监督学习在没有目标标签的情况下寻找结构，例如按消费特征分组。强化学习研究如何依据奖励改善序列决策，动作会影响后续遇到的情况。

本页用于串联入门概念；表示学习、自监督与预训练已在[第 15 章](15_representation_learning/README.md)展开，生成与扩散见[第 17 章](17_generative_models/README.md)，强化学习算法见[第 19 章](19_reinforcement_learning/README.md)。复习已有案例时按需回查，不要求先读完全部扩展。

## 2. 从数据到预测

以“房屋面积预测房价”为示意：一个样本是一套房，输入特征是面积，标签是成交价。对 N 套房、D 个特征，特征表 `X` 的形状为 `[N, D]`，单目标回归标签 `y` 为 `[N]`。

```text
训练：训练输入 X + 正确答案 y → 拟合规则/参数
推理：新输入 x + 已有模型      → 预测 ŷ
评估：预测 ŷ + 留出的正确答案 y → 误差或分类指标
```

标签在训练中用于计算误差，不是新样本推理时必须提供的输入。否则模型只是在读取答案。

“特征”也有两种来源：Iris 直接使用人选定的长度和宽度；ResNet18 从像素逐层计算特征。神经网络让特征表示本身也可以通过数据学得。

## 3. 模型、损失、梯度各负责什么

下面是无量纲教学例子，采用单参数模型 `ŷ = wx` 和损失 `L = (ŷ - y)²`。

| 量 | 示例 | 含义 |
| --- | --- | --- |
| 输入与标签 | x = 2，y = 6 | 希望输入 2 时输出 6 |
| 当前参数 | w = 1 | 当前预测为 2 |
| 损失 | (2 - 6)² = 16 | 当前偏差大小 |
| 梯度 | dL/dw = 2(wx - y)x = -16 | w 小幅增加时，损失在当前位置倾向下降 |
| 一步梯度下降 | w′ = 1 - 0.1 × (-16) = 2.6 | 学习率取 0.1 |
| 更新后 | ŷ′ = 5.2，L′ = 0.64 | 这个示例的一步更新减小了损失 |

结果是静态推导，不是训练测得。梯度给局部变化信息，学习率决定走多远；步子过大可能使损失增大。反向传播负责高效求神经网络中各参数的梯度，优化器使用梯度更新参数。

`w` 是从数据学习的**参数**；学习率、网络宽度、KNN 的 K 是事先配置或用验证结果选择的**超参数**。线性回归也能用其他数值求解方式，不能把所有训练都等同于反向传播。

## 4. 为什么要把数据分开

| 数据 | 用途 | 会影响什么 |
| --- | --- | --- |
| 训练集 | 拟合模型及需要学习的预处理统计量 | 权重、均值、标准差等 |
| 验证集 / 交叉验证留出折 | 选择配置、训练轮次和模型 | 学习率、K、最佳 checkpoint 等选择 |
| 测试集 | 方案确定后的独立评估 | 用于报告最终表现 |

验证数据虽然不直接更新权重，也会通过选择过程影响最终方案，因此需要额外留出测试集。反复看测试结果再改模型，测试集就逐渐承担了验证集的角色。

先划分，再拟合预处理；交叉验证每一折都重新拟合预处理。相邻视频帧或同一机器人轨迹通常高度相关，应按场景、轨迹或时间关系划分，不能把近似样本随机分开后当成独立泛化证据。[scikit-learn 的数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)给出了预处理与 Pipeline 的基本规则。

## 5. 从图片分类到机器人学习

| 方法 | 输入 → 输出 | 改进依据 |
| --- | --- | --- |
| 视觉感知 | 图片 → 类别或位置 | 类别或位置标签 |
| 视觉语言模型（VLM） | 图片 + 文字 → 匹配分数、文字回答或特定定位输出 | 图文配对、目标回答等，依任务而异 |
| 行为克隆（BC） | 观测 → 动作 | 示教中的动作标签 |
| 强化学习（RL） | 观测/状态 → 动作 | 行动后的奖励与后续回报 |

视觉网络识别物体，再由规划器和控制器执行抓取，可以全程不用强化学习。BC 是模仿学习的一种常见方法，通常按监督学习训练；机器人使用神经网络也不自动意味着强化学习。

VLM 可以帮助语言选目标，几何测量和控制仍需具体模块；VLA 将动作预测纳入视觉语言条件下的模型任务，使用示教训练时也可以属于模仿学习。它们的输入输出、坐标与动作边界见 [VLM 机器人应用](16_vision_language/05_robotics_vla.md)，不因生成了一段抓取描述就标记闭环执行完成。

强化学习先记六个词：**状态**描述环境情况；**观测**是传感器或仿真提供给智能体的信息，不一定完整；**动作**是决策输出；**奖励**评价一次转移；**策略**规定怎样选动作；**回报**累计后续奖励。

一个纯示意的到达目标任务：观测为平面位置误差 `[e_x, e_y]`（米），动作是下一步平面位移 `[Δx, Δy]`（米、在固定世界坐标系表达），策略输出受限幅。普通一步奖励 -1，抵达目标终止并奖励 +10，碰撞终止并奖励 -10；真实机械臂还需定义执行器与物理约束，此例没有实现。

若某段轨迹后续三次奖励为 `[-1, -1, 10]`，折扣因子 γ = 0.9，则当前折扣回报为 `G = -1 + 0.9×(-1) + 0.9²×10 = 6.2`。这是静态推导；前两步奖励为负，仍可能值得采取，因为它们通向后续成功。学习目标通常是提高期望累计回报，而非只挑眼前奖励最大的动作。

用小表存储策略或价值也可以做强化学习；用深度网络表示它们，则进入深度强化学习。动作标签学习见 [18](18_imitation_learning/README.md)，价值更新、策略梯度、PPO/SAC 见 [19](19_reinforcement_learning/README.md)，泛化与仿真迁移见 [20](20_generalization_sim2real/README.md)；实际机器人训练与闭环实验仍按路线推进。术语与回报定义可按需查阅 [Spinning Up 强化学习概念](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)。
