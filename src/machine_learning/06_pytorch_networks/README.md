# 06 神经网络与反向传播：从计算图到参数更新

本文行数：122行，预期阅读时长：7分钟

## 速记要点

- 神经网络把输入逐层变换为输出；Linear 学权重和偏置，激活函数引入非线性。
- 前向传播算预测，损失比较预测与标签，反向传播求梯度，优化器更新参数。
- batch 是一批样本，iteration 是一次迭代，epoch 是遍历一轮训练数据。
- 推理仍需前向计算，但不需要通过标签计算梯度或更新参数。
- 反向传播沿计算图使用链式法则；自动微分求的是所执行计算的导数，不会替我们判断损失与数据定义是否正确。

新增的小网络计算采用无量纲教学值，已用[逐参数数值差分](../examples/README.md)交叉核对；MNIST 仍使用原实现与历史记录。

## 手算一次完整训练：两个输入、一个隐藏单元

**模型与输入：** `x=[1,2]`，目标 y=2。隐藏层只有一个单元，输出为一个回归数值：

~~~text
a = w₁x₁+w₂x₂+b       # 激活前的加权和
h = ReLU(a)=max(0,a)  # 隐藏激活
ŷ = vh+c             # 输出
L = ½(ŷ−y)²          # 本例损失，前面的 ½ 方便求导
~~~

初始参数 `w₁=0.5、w₂=−0.5、b=1、v=2、c=0.5`。x 是输入，a、h 是中间结果，w₁、w₂、b、v、c 是待学习参数；这些名字的角色不同。

| 前向步骤 | 计算 | 结果 |
| --- | --- | ---: |
| 隐藏加权和 | 0.5×1−0.5×2+1 | a=0.5 |
| 非线性 | max(0,0.5) | h=0.5 |
| 输出 | 2×0.5+0.5 | ŷ=1.5 |
| 损失 | ½×(1.5−2)² | L=0.125 |

### 反向传播：沿依赖关系逐步求导

**链式法则**表示：若一个量通过中间量影响损失，就把沿途的局部导数相乘；有多条路径时再把贡献相加。例如 `w₁ → a → h → ŷ → L`：

$$\frac{\partial L}{\partial w_1}=\frac{\partial L}{\partial\hat y}\frac{\partial\hat y}{\partial h}\frac{\partial h}{\partial a}\frac{\partial a}{\partial w_1}.$$

本例 `∂L/∂ŷ=ŷ−y=−0.5`，`∂ŷ/∂h=v=2`。因为 a=0.5>0，ReLU 在这里的导数为 1，因此 `∂L/∂a=−1`。先利用已知前向结果，再得到各参数梯度：

| 参数 | 梯度计算 | 梯度 | 学习率 0.05 更新后的值 |
| --- | --- | ---: | ---: |
| w₁ | `(−1)×x₁` | −1 | 0.55 |
| w₂ | `(−1)×x₂` | −2 | −0.4 |
| b | `−1` | −1 | 1.05 |
| v | `(ŷ−y)×h` | −0.25 | 2.0125 |
| c | `ŷ−y` | −0.5 | 0.525 |

所有更新都用旧参数处的梯度，规则是 `参数′=参数−学习率×梯度`，不在更新一项后重新求其他项。若 a<0，ReLU 的导数为 0，这条隐藏路径在该样本上的梯度会被阻断；a=0 是不可导点，框架需采用约定。

**结果与解释（静态计算，已核对）：** 新的 a=h=0.8，预测 `2.0125×0.8+0.525=2.135`，损失为 0.0091125，低于原来的 0.125。若从相同初值改用学习率 0.1，损失反而变为 0.302253125。梯度给局部方向，多参数一起迈出的有限步长不保证降损失。

### 自动微分怎样对应上述计算

PyTorch 在前向计算时记录需要梯度的操作及中间信息，调用 `backward()` 后按链式法则累积到参数的 `.grad`。优化器使用这些梯度更新参数；`zero_grad()` 清除或置空上一次累积值，避免下一批意外叠加。机制见 [PyTorch 2.6 自动微分说明](https://docs.pytorch.org/docs/2.6/notes/autograd.html)。

本次数值检查用中央差分 `(L(θ+ε)−L(θ−ε))/(2ε)` 逐项核对手算梯度，ε=10⁻⁶，结果一致；差分仅用于独立核对，不是 PyTorch 反向传播的实现，也没有运行本例的 PyTorch 训练。真正的自动微分仍按计算图求导。

多个样本组成 batch 时，若损失取平均，梯度也按同样方式平均。标签错位、把错误单位当作目标或用错损失，都会得到“计算上正确、任务上错误”的梯度，不能靠 `backward()` 自动修复。

## 仓库网络：一张图怎样变成十个分数

[DigitMLP 源码](src/model.py)默认结构为 `784 → 128 → 10`，只有一个隐藏层，是神经网络入门的小型模型，不必把所有神经网络都称为深度网络。

| 步骤 | 一个 batch 的形状 | 作用 |
| --- | --- | --- |
| 输入 | `[B, 1, 28, 28]` | B 张单通道 MNIST 图片，像素转换为 0～1 |
| Flatten | `[B, 784]` | 每张图展平，保留 batch 维；不学习参数 |
| Linear | `[B, 128]` | 对输入加权求和，再加偏置 |
| ReLU | `[B, 128]` | 负数变零，非负数保留 |
| Linear | `[B, 10]` | 得到数字 0～9 的十个分数 logits |

标签为 `[B]` 的整数类别编号，范围 0～9。B 是样本数量，不是通道数。两层参数量静态推导为 `(784×128+128) + (128×10+10) = 101,770`。

如果只堆叠仿射变换而没有非线性，中间的多层可以合成一次仿射变换；ReLU 使网络可以表达更复杂的映射。这里的展平没有显式利用图像局部邻域结构，第七章的 CNN 会利用这一结构。

对一批样本，`Linear(784,128)` 的权重在 PyTorch 中存为 `[128,784]`，前向按 `X Wᵀ+b` 计算：`[B,784] × [784,128] → [B,128]`。偏置 `[128]` 复用于每行样本，权重不是按 batch 为每张图各存一份。梯度与对应参数形状相同。

## 例子：分数、概率与损失

为了便于手算，假设一个三分类网络输出 logits `[2, 1, 0]`，正确类别为第 0 类。这是教学示意，不是 MNIST 的十分类实测。

Softmax 得到约 `[0.6652, 0.2447, 0.0900]`，最大项对应第 0 类；该样本交叉熵约为 `-ln(0.6652) = 0.4076`。若正确标签其实为第 2 类，损失约为 2.4076：同一组分数，在不同正确答案下有不同损失。

**解释：** logits 可以为负，也不必加起来等于 1；softmax 转成概率形式。当前代码的 CrossEntropyLoss 直接接收 logits，不要先手动 softmax 再传入。预测只需取最大分数的类别，高分并不保证预测正确。接口约定见与历史环境对应的 [PyTorch 2.6 CrossEntropyLoss](https://docs.pytorch.org/docs/2.6/generated/torch.nn.CrossEntropyLoss.html)。

对于本例的普通单样本交叉熵（无类别权重或标签平滑），对各 logit 的梯度为 `p_j−1[j=正确类别]`。正确类别为 0 时，得到约 `[-0.334759,0.244728,0.090031]`：梯度下降倾向于增大正确类别分数、减小其他分数。网络真正更新的是这些分数背后的共享参数，因此还要沿计算图继续传回；不是直接把某张图的 logits 永久存成参数。

## 一次训练究竟发生什么

```text
读取一批图片与标签
→ 清除上一次梯度
→ 前向计算 logits
→ 用 logits 与标签计算损失
→ 反向传播求各参数梯度
→ 优化器更新参数
```

梯度和一步更新的数字例子见[概念总览](../overview.md)。反向传播本身不修改参数；调用优化器更新才改变参数。loss 是训练目标，accuracy 是最终选对类别的比例，两者变化未必完全同步。

50,000 张训练图片、batch size 64、保留尾批时，一轮为 `ceil(50000/64) = 782` 次迭代，五轮共 3,910 次更新。这是按当前基线配置推导；一轮不是只更新一次。

## 训练模式、评估模式与存储

`train()` / `eval()` 切换 Dropout、BatchNorm 等层的行为；`no_grad()` 等开关控制梯度记录，二者职责不同。本章默认 MLP 没有这些模式敏感层，但仍保留切换，方便扩展。

`state_dict` 保存参数和持久缓冲区；加载时需要匹配的模型结构。输入预处理和类别顺序也必须一致，只有权重文件不足以说明模型怎样用于实际任务。
