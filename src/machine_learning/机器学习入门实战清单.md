# 机器学习入门实战清单（8 周）

本文行数：211行，预期阅读时长：6分钟

适用对象：刚开始系统学习机器学习、希望把知识落到项目和实验上的学习者。  
建议投入：每周 6～10 小时；每个项目都保留代码、实验记录、结论和简短 README。

## 学习原则

- 先完成一个可运行的基线，再逐项改进；不要一开始追求最高分。
- 训练数据以外的信息不能参与预处理、调参或选模型，避免数据泄漏。
- 测试集只用于最终评估；日常比较模型使用验证集或交叉验证。
- 每次实验只改变少量变量，并记录数据版本、参数、指标和结论。
- 不只看分数：查看错误样本，尝试解释模型为什么会出错。

每周项目的 `README.md` 至少回答：**问题是什么、数据来自哪里、如何运行、结果如何、得到了什么结论、下一步改进什么。**

## 第 1 周：建立完整认知

**项目：鸢尾花分类（Iris）**

目标：理解监督学习从数据到评估的完整最小流程。

任务清单：

- [ ] 区分样本、特征、标签；理解分类与回归的差异。
- [ ] 使用 Pandas 查看数据形状、描述统计、类别分布和缺失值。
- [ ] 划分训练集和测试集，建议使用分层划分以保持类别比例。
- [ ] 仅用训练集完成必要预处理，再将相同规则应用到测试集。
- [ ] 训练 KNN 分类器，建立基线结果。
- [ ] 尝试多个 `K` 值，比较准确率变化。
- [ ] 输出准确率和混淆矩阵，查看被混淆的类别。

验收标准：能从零运行脚本/Notebook，输出不同 `K` 的结果与一张混淆矩阵。

交付问题：模型从训练数据中学到了什么？你如何判断它对未见过的新数据仍然有效？

## 第 2 周：回归与误差

**项目：房价预测或共享单车需求预测**

目标：理解连续数值预测、误差及特征处理。

任务清单：

- [ ] 使用线性回归建立基线模型。
- [ ] 理解损失函数、残差和均方误差（MSE）。
- [ ] 分别处理数值特征与类别特征，例如缺失值填补、编码和标准化。
- [ ] 对比训练误差和测试误差，判断是否存在明显过拟合或欠拟合。
- [ ] 绘制真实值与预测值对比图，最好补充残差图。
- [ ] 找出绝对误差最大的五个样本，结合原始特征分析原因。

验收标准：报告训练/测试集上的 MSE（可同时报告 MAE、R²），并附最差五个样本分析。

交付问题：分类与回归有什么区别？为什么真实任务中误差通常不可避免？

## 第 3 周：数据预处理与管道

**项目：泰坦尼克号生存预测**

目标：把预处理和模型封装为可复现、无泄漏的工作流。

任务清单：

- [ ] 检查各列缺失情况，并为数值、类别字段选择合理处理方式。
- [ ] 对类别变量进行编码。
- [ ] 对数值特征标准化；注意树模型通常不依赖标准化。
- [ ] 用 `ColumnTransformer` 和 `Pipeline` 串联预处理与模型。
- [ ] 比较逻辑回归、KNN 和决策树。
- [ ] 计算准确率、精确率、召回率、F1，并阅读混淆矩阵。

验收标准：所有预处理都位于 Pipeline 内；有模型指标对比表和选择理由。

交付问题：为什么准确率高不一定代表模型好？在“生存者很少”的数据中应重点看哪些指标？

## 第 4 周：过拟合与模型选择

**项目：手写数字分类（Digits / MNIST）**

目标：理解泛化能力，并学会在不碰测试集的前提下选择模型。

任务清单：

- [ ] 解释欠拟合、过拟合和泛化，并用训练/验证表现举例。
- [ ] 使用交叉验证评估候选模型。
- [ ] 调整 KNN 和决策树的关键超参数。
- [ ] 绘制学习曲线，观察训练数据量增加时的误差变化。
- [ ] 明确训练集、验证集、测试集的职责。
- [ ] 最后才使用测试集进行一次最终评估。

验收标准：输出交叉验证结果、学习曲线和最终一次测试集结果；测试集不参与调参。

交付问题：模型为什么会“背答案”？如何发现并缓解过拟合？

## 第 5 周：无监督学习

**项目：机器人传感器数据或客户数据聚类**

目标：理解没有标签时，模型如何从相似性中组织数据。

任务清单：

- [ ] 明确哪些列可作为聚类特征，并处理缺失值、量纲差异和异常值。
- [ ] 使用 K-Means 完成聚类。
- [ ] 尝试不同聚类数量；可借助肘部法和轮廓系数，但不要机械依赖它们。
- [ ] 使用 PCA 降至二维并可视化聚类结果。
- [ ] 为每个簇总结典型特征和代表性样本。
- [ ] 若数据有真实类别，仅将其作为事后参考，不把聚类编号当成真实类别。

验收标准：给出至少两种聚类数量的图和解释，并说明最终选择的局限。

交付问题：无监督学习发现的是客观规律，还是我们希望看到的一种解释？

## 第 6 周：神经网络基础

**项目：使用 PyTorch 识别手写数字**

详细工作框架：[06_pytorch_networks/README.md](06_pytorch_networks/README.md)

目标：亲手实现神经网络训练与模型保存流程。

任务清单：

- [ ] 理解神经元、线性层、激活函数和输出层。
- [ ] 解释前向传播、损失计算、反向传播和梯度下降。
- [ ] 自己编写训练循环：取 batch、前向、计算损失、反向、更新参数。
- [ ] 打印一个 batch 的输入、标签、模型输出形状。
- [ ] 改变学习率、网络深度和 batch 大小并记录对训练的影响。
- [ ] 保存 `state_dict`，新建模型后重新加载并验证推理结果。

验收标准：可独立训练、保存、加载和推理；训练记录包含 loss/accuracy 曲线。

交付问题：一次训练迭代具体发生了什么？梯度是怎样影响参数的？

## 第 7 周：计算机视觉

**项目：识别 2～5 类日常物品**

学习笔记与目录入口：[07_transfer_learning/README.md](07_transfer_learning/README.md)

目标：使用现成的带标签图片，体验从数据准备、迁移学习到单张图片推理的小型视觉任务。以理解流程和记录实验为主，按需学习概念，不要求深入推导数学细节。

任务清单：

- [ ] 选择现成的已标注图片数据集，选取 2～5 类；理解标签含义，记录数据来源、类别数量和样本数，无需自行采集与标注。
- [ ] 按训练/验证/测试划分数据，避免同一场景的近似图片跨集合泄漏。
- [ ] 使用预训练模型进行迁移学习。
- [ ] 使用适度的数据增强，例如随机裁剪、翻转、颜色扰动。
- [ ] 保存错误样本，分析光照、角度、遮挡、背景和类别定义的影响。
- [ ] 用摄像头或本地图片完成单张/实时推理。

验收标准：有数据集说明、评估结果、错误样本集和可运行的推理入口。

交付问题：模型在什么光照、角度、背景或遮挡条件下容易失败？

## 第 8 周：与机器人结合

**项目：视觉引导的机器人任务**

从以下方向选择一个，优先选择你现有硬件或仿真环境最容易验证的方向：

1. 摄像头识别目标，并将目标类别、位置和置信度发布为 ROS 2 消息。
2. 移动机器人根据识别结果靠近目标。
3. 在仿真中让机械臂抓取指定颜色或类别的物体。

任务清单：

- [ ] 定义感知输入、模型输出、ROS 2 消息和执行动作之间的接口。
- [ ] 记录端到端推理延迟、任务成功率和失败原因。
- [ ] 设计置信度阈值；低置信度时执行拒绝、重试或请求新视角。
- [ ] 将失败案例按感知、定位、通信、规划和执行分类。
- [ ] 录制约两分钟演示视频，并完成项目报告。

验收标准：演示中能稳定完成一个明确任务；报告中包含指标、失败案例和下一步改进。

交付问题：模型离线准确率很高，为什么机器人在真实环境中仍可能执行失败？
