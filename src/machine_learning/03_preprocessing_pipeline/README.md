# 03 数据预处理与评估指标：表示、泄漏与阈值

本文行数：110行，预期阅读时长：6分钟

## 速记要点

- 缺失值填补、类别编码和缩放，是预测流程的一部分；需要学习的规则只从训练部分拟合。
- Pipeline 把预处理与模型连起来，但无法自动修复错误的数据划分或泄漏标签的特征。
- 准确率看总体，精确率看“报为正的有多少是真的”，召回率看“实际为正的找到了多少”。
- 编码列、缩放统计和类别顺序是模型输入约定的一部分，推理时必须复用。
- 分类阈值改变预测集合；机器人能否执行还取决于坐标、时效、几何与规划条件。

本章新增例子均为教学数值，已由[核对程序](../examples/README.md)检查；Titanic 指标仍沿用历史记录。

## 例子一：验证数据怎样被悄悄用进去

训练集中某列年龄为 `[20, 40]` 岁，验证集为 `[80]` 岁。使用均值中心化作为教学示意：

| 做法 | 用于拟合的均值 | 验证值中心化结果 |
| --- | ---: | ---: |
| 只从训练集拟合 | 30 岁 | 80 - 30 = 50 岁 |
| 先对全量数据拟合 | 46.67 岁 | 80 - 46.67 ≈ 33.33 岁 |

**结果与解释：** 后者的变换规则依赖验证数据，评估过程不再完全独立。泄漏不一定每次都抬高分数，但会破坏评估依据。正确做法是先划分，训练部分 `fit`，验证和测试部分只 `transform`；交叉验证的每一折也要遵循这个过程。

本例只演示减均值，不是完整标准化。完整 StandardScaler 还除以训练标准差。[官方说明](https://scikit-learn.org/stable/common_pitfalls.html)包含预处理不一致与数据泄漏的对照例子。

## 标准化、填补与编码分别改变什么

对一个数值特征，标准化使用 `z=(x−μ_train)/σ_train`。沿用年龄训练值 `[20,40]` 岁，均值为 30 岁；按 `StandardScaler` 的总体方差约定，标准差为 `√[(100+100)/2]=10` 岁。

| 输入年龄 | 标准化结果 | 含义 |
| ---: | ---: | --- |
| 20 岁，训练值 | −1 | 比训练均值低一个训练标准差 |
| 40 岁，训练值 | 1 | 比训练均值高一个训练标准差 |
| 80 岁，验证值 | 5 | 比训练均值高五个训练标准差 |

**结果与解释（静态计算，已核对）：** z 无量纲，但没有被限制在 `[−1,1]`。推理遇到 80 岁时继续使用均值 30、标准差 10；按这一个新样本重新计算均值会把它变成 0，并改变模型输入的含义。

若训练年龄为 `[20,缺失,40]`，中位数填补器可从有效训练值学到 30，随后把缺失项替换为 30。填补是提供一个可计算的替代值，不是恢复真实年龄。缺失本身可能携带信息，也可能意味着采集故障，需要结合来源判断；机器人缺失位姿不能简单填成原点后继续执行。

对于无自然大小顺序的类别，独热编码为每个类别设置一列。人为规定颜色列顺序 `[红,蓝]`：

| 输入类别 | 向量 |
| --- | --- |
| 红 | `[1,0]` |
| 蓝 | `[0,1]` |
| 训练时未见的黄，设 `handle_unknown="ignore"` | `[0,0]` |

**结果与解释：** 向量列代表类别，不是颜色深浅。直接将红、蓝编码为 0、1，会让使用数值大小或距离的模型引入额外顺序。忽略未知类别时，全零表示它没有匹配已有类别列，并不意味着它属于某个默认类别；需要记录并评估这种输入。若另设丢弃基准列，基准类别也可能全零，本表没有启用该设置。

输入有 N 个样本、D 列时，原表为 `[N,D]`，编码后可能变为 `[N,D′]`，D′不一定等于 D。保存模型时还应保存列顺序、类别列表及填补和缩放统计。定义与接口见 [scikit-learn 1.7 预处理说明](https://scikit-learn.org/1.7/modules/preprocessing.html)。

## 仓库流程：Titanic

输入为乘客舱位、性别、年龄、亲属数量、票价、登船港等七个字段，标签 `Survived` 为 0/1。填补器处理缺失项，编码器把类别转为可计算形式，模型输出生存类别。

```text
训练部分 → 数值列：填补 → 缩放 ─┐
         类别列：填补 → 编码 ─┴→ 分类模型
验证/测试 → 使用同一组已拟合规则 → 预测与评估
```

逻辑回归虽然名字有“回归”，这里用于分类；它把线性分数映射为类别概率形式。决策树通过特征阈值逐步分支；KNN 根据邻居投票。树通常不依赖标准化，而距离模型会明显受尺度影响。

## 例子二：直接读懂历史混淆矩阵

以下来自[历史测试指标](outputs/tables/final_test_metrics.json)，共 179 人；行是真实类别，列是预测类别，以“生存=1”为正类。

| 真实 / 预测 | 未生存 0 | 生存 1 |
| --- | ---: | ---: |
| 未生存 0 | 98（TN） | 12（FP） |
| 生存 1 | 23（FN） | 46（TP） |

- 准确率 = (98+46)/179 ≈ **80.45%**：总体有多少判断正确。
- 精确率 = 46/(46+12) ≈ **79.31%**：预测生存的人中，有多少实际生存。
- 召回率 = 46/(46+23) ≈ **66.67%**：实际生存的人中，模型找出了多少。
- F1 = 2TP/(2TP+FP+FN) = 92/127 ≈ **72.44%**：精确率与召回率的调和平均。

**解释：** 总体准确率约八成，但实际生存者仍漏掉三分之一。应根据漏报和误报的代价选择指标，不能只追求准确率。以上是历史结果重算，本次没有训练模型。

二分类中，提高报为正类的分数阈值通常减少正类预测，精确率和召回率可能此消彼长；阈值也应在验证数据上选择。概率形式的输出不保证已经校准。

## 类别不平衡：99% 准确率为什么仍可能没用

**教学条件：** 1,000 个样本中有 10 个需要被检出的异常，其余 990 个正常。将异常定义为正类，若模型全部预测正常，则 TN=990、FN=10、TP=FP=0。

**结果（静态计算）：** 准确率为 99%，异常召回率为 0。因为没有任何正类预测，精确率分母 TP+FP=0，数学上未定义；软件可以按配置返回 0 等值，但必须说明约定。这一结果适合作为基线比较，不能说明模型已经解决异常检出。

为少数类加权、重新采样或调整阈值，都要只依据训练与验证数据安排；重复复制少数样本不会增加独立观测。分类损失变了，输出分数的概率解释也需要重新检查。图像增强还应保留标签语义，第 07 章给出具体例子。

## 同一批分数：改变阈值会失去或得到什么

假设六个验证样本的正类分数为 `[0.95,0.70,0.65,0.40,0.35,0.10]`，真实标签为 `[1,1,0,1,0,0]`。规则是“分数≥阈值 τ 就预测正类”。这些分数为人为示意，没有训练模型或证明概率校准。

| τ | TP | FP | FN | TN | 精确率 | 召回率 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.3 | 3 | 2 | 0 | 1 | 0.60 | 1.00 |
| 0.5 | 2 | 1 | 1 | 2 | 0.666667 | 0.666667 |
| 0.8 | 1 | 0 | 2 | 3 | 1.00 | 0.333333 |

**结果与解释（静态计算，已核对）：** τ=0.8 时避免了这六个样本中的误报，但漏掉三分之二的正类。阈值变高时预测正类集合只会缩小，因此此处召回率不会增加；精确率不保证随阈值单调改善，具体取决于被删去的样本。

应该先明确漏报与误报的代价，再在验证集上选择阈值，最后用独立测试集报告。阈值选好后也不会补回缺失深度、修复过期 TF 或保证抓取可达；机器人执行条件见[第 08 章](../08_robot_integration/README.md)。机制可查 [scikit-learn 1.7 阈值选择说明](https://scikit-learn.org/1.7/modules/classification_threshold.html)。
