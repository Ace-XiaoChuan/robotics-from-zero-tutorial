## 实验信息

- 日期：2026-08-20
- 数据集与来源：Kaggle Titanic 训练集的公开镜像；详见 `data/README.md`。
- 随机种子：42

## 数据与配置

- 样本数与字段数：891 条原始记录；使用 7 个输入特征和目标 `Survived`。
- 训练/测试集划分：分层随机划分，80% / 20%，随机种子 42；训练集 712 条、测试集 179 条。
- 数值特征处理：`Age`、`SibSp`、`Parch`、`Fare`；仅在训练集以中位数填补，再标准化。训练集学得的中位数依次为 28.5、0、0、14.4542。
- 类别特征处理：`Pclass`、`Sex`、`Embarked`；仅在训练集以 `Missing` 填补，再独热编码。
- 模型与超参数：均值基线为 `DummyClassifier(strategy="prior")`；候选模型为 `LogisticRegression(max_iter=1000, random_state=42)`、`KNeighborsClassifier(n_neighbors=5)`、`DecisionTreeClassifier(random_state=42)`。三者均使用同一预处理 Pipeline。
- 是否全部封装在 `Pipeline` 中：是。预处理器和均值基线均在同一个 Pipeline 中，只对训练集调用 `fit`。

## 观察与结论

- 选择哪个模型，为什么？选择逻辑回归。它的生存类平均 F1 为 0.730，是三个候选模型中最高；平均准确率也最高（0.802）。最终测试集 F1 为 0.724，与交叉验证平均结果接近。
- 准确率与精确率、召回率、F1 是否一致地支持这个选择？均值基线的 0.615 准确率只来自预测多数类，生存类别的精确率、召回率、F1 均为 0。三种候选模型均能识别出生存者；逻辑回归在准确率、召回率和 F1 上均优于 KNN，且 F1 优于决策树，因此支持该选择。
- 数据是否类别不平衡？它对指标解读有什么影响？未生存 549 人、生存 342 人，存在中等程度不平衡；不能只看准确率，应重点比较生存类的召回率和 F1。
- 是否有数据泄漏、欠拟合或过拟合迹象？填补值、标准化参数、类别列表和模型参数均只从训练集学习；最终测试集只用于一次预测和评分。测试 F1（0.724）与交叉验证 F1（0.730）接近，未显示明显过拟合迹象。
