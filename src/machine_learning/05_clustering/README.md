# 05 无监督学习：聚类与 PCA

本文行数：56行，预期阅读时长：3分钟

## 速记要点

- 聚类依据特征相似性分组，没有用于拟合的目标标签；簇编号没有天然类别含义。
- K-Means 反复“分给最近中心 → 更新均值中心”，K 是预先选择的簇数。
- 特征选择、缩放和距离决定什么叫相似；不同处理可能给出不同分组。
- PCA 找变化较大的投影方向；二维图方便观察，但可能遗漏重要结构。

## 例子：手算一次 K-Means

用无量纲一维数据 `[1, 2, 8, 9]`，设 K=2，初始中心为 1 和 8，采用欧氏距离。

| 步骤 | 第一簇 | 第二簇 |
| --- | --- | --- |
| 按最近中心分配 | 1、2 | 8、9 |
| 求均值更新中心 | (1+2)/2 = 1.5 | (8+9)/2 = 8.5 |
| 再分配 | 仍为 1、2 | 仍为 8、9 |

**静态推导结果：** 分组稳定，簇内平方距离总和为 `4 × 0.5² = 1`。把两簇的编号 0 和 1 交换，结果没有变化；编号不等于“好客户”“坏客户”等业务标签。

增加 K 可以降低最优簇内平方距离，但不意味着更有解释价值。实际算法还可能受初始化影响，得到局部解。

## 怎么解释结果

| 工具 | 回答什么 | 不能据此断言什么 |
| --- | --- | --- |
| inertia / 肘部图 | 增加簇数后，簇内紧凑程度改善多少？ | 弯折点必然是唯一正确 K |
| 轮廓系数 | 样本与本簇相比其他簇是否更接近？ | 分数高就对应真实业务类别 |
| 簇画像 | 各簇在原始单位下有哪些典型特征？ | 簇名就是客观身份 |
| PCA 二维图 | 主要变化投影后看起来怎样？ | 二维重叠就代表原空间无法区分 |

轮廓系数通常介于 -1 与 1，较大表示在所选距离下分离更清楚，接近零表示边界重叠。K-Means 偏好紧凑、近似球形的簇，对极端值、弯曲结构或密度差异大的数据可能不合适。

PCA 将中心化后的特征投影到互相正交、依次保留较多方差的方向；它不读取类别来寻找最好分类边界，也不是自动选择原始特征列。数据尺度会改变哪些方向具有较大方差。

## 仓库历史例子：客户消费结构

[实验记录](experiment_log.md)使用 440 位客户的六类商品年消费字段，排除 Channel 与 Region。先 `log1p` 缓解长尾，再用 RobustScaler 按中位数和四分位距缩放；消费币种见原始数据说明，不在此补猜单位。

| 历史配置 | 轮廓系数 | 解释 |
| --- | ---: | --- |
| K=2 | 0.252915 | 252 / 188 人，两个消费画像较容易概括 |
| K=3 | 0.244659 | 分得更细，但当前解释需求不足以支持增加复杂度 |

最终保留 K=2；PCA 前两维保留约 69.1% 的方差。以上为历史结果，本次未重新聚类。

**结果含义：** 这里得到的是消费特征与预处理条件下的一种分组。Channel 仅作事后解释对照；既然它曾参与选择理由，就不能再把同一对照当作独立验证。不能把簇与 Channel 的一致比例叫作本任务的分类准确率。
