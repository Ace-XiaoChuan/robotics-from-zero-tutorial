# 05 聚类与降维：中心、投影与信息损失

本文行数：115行，预期阅读时长：8分钟

<a id="developer-overview"></a>

## 开发者理解：发现相似分组，把数据变得更容易观察

**聚类是在没有目标类别标签的情况下，按特征相似性把样本分组；降维是把较多特征转换成较少的表示。** 两者可以帮助探索和整理数据，分别回答“哪些样本相似”和“怎样用更少的信息表示这些样本”。

与第 01 章分类任务不同，这里不必事先告诉模型每条记录属于哪个正确类别。例如，只有客户的消费记录，希望先观察有哪些消费模式，就可以用聚类探索；这些组的含义需要结合实际用途解释。

| 功能 | 输入 | 输出及含义 |
| --- | --- | --- |
| 聚类 | 一批样本的特征，如六类商品的消费记录 | 每条记录所属的组，以及各组的典型特征 |
| 降维 | 同一批多特征记录 | 每条记录的较少综合特征，可用于观察或后续处理 |

**例子（教学示意）：** 假设一项无量纲特征的四个值为 1、2、8、9，按相似性分成两组，得到“1、2 一组，8、9 一组”。组编号只是标记；把它们叫作组 0、组 1，并没有自动说明哪组是“优质客户”。它也不同于已知答案的分类任务，不能直接用“预测对了多少类别”评价这种分组。

**K-Means**是本章使用的一种聚类方法，可以先理解为“围绕若干代表中心分组”。它需要指定分成几组；分得更多通常能描述更细的差异，却不一定更有使用价值。什么算相似，取决于给它哪些特征、怎样表示这些特征。例如，按消费金额分组与按商品偏好分组，可能得到不同结果。

**PCA（主成分分析）**是一种降维方法，可以先理解为“用少数综合方向概括数据的主要变化”。例如，把六项消费特征变成两个综合特征，就能画在平面上观察。图上的坐标是转换后的表示，不等于两项原始消费金额，也不自动代表两个业务类别。

**表示变简单，可能丢掉重要差别。** 就像把三维物体投影到平面上，不同高度的点可能重合；PCA 二维图中两个样本挨得近，不代表它们在全部特征上都相似。保留了大部分变化，也未必保留分类或机器人任务最需要的信息，例如很小的高度差可能决定是否碰撞。

**需要深入时：** [K-Means 例子](#例子手算一次-k-means) · [分组怎样解释](#怎么解释结果) · [PCA 与信息损失](#pca-手算四个点怎样变成一列数) · [中心求导、PCA 约束求导与斜方向例子](derivations.md) · [客户消费数据案例](#客户消费结构案例)。

## 速记要点

- 聚类依据特征相似性分组，没有用于拟合的目标标签；簇编号没有天然类别含义。
- K-Means 反复“分给最近中心 → 更新均值中心”，K 是预先选择的簇数。
- 特征选择、缩放和距离决定什么叫相似；不同处理可能给出不同分组。
- PCA 找变化较大的投影方向；二维图方便观察，但可能遗漏重要结构。
- 聚类目标是使同簇数据在选定距离下接近；PCA 目标是保留较大方差，两者都不保证保留分类或机器人任务所需的信息。

## 例子：手算一次 K-Means

用无量纲一维数据 `[1, 2, 8, 9]`，设 K=2，初始中心为 1 和 8，采用欧氏距离。

| 步骤 | 第一簇 | 第二簇 |
| --- | --- | --- |
| 按最近中心分配 | 1、2 | 8、9 |
| 求均值更新中心 | (1+2)/2 = 1.5 | (8+9)/2 = 8.5 |
| 再分配 | 仍为 1、2 | 仍为 8、9 |

**静态推导结果：** 分组稳定，簇内平方距离总和为 `4 × 0.5² = 1`。把两簇的编号 0 和 1 交换，结果没有变化；编号不等于“好客户”“坏客户”等业务标签。

增加 K 可以降低最优簇内平方距离，但不意味着更有解释价值。实际算法还可能受初始化影响，得到局部解。

## 二维例子：中心为什么取均值

设无量纲点为 `(0,0)`、`(0,2)`、`(8,0)`、`(8,2)`，K=2，初始中心为 `(0,0)`、`(8,0)`。按欧氏距离分配后，左侧两点同簇，右侧两点同簇，更新中心为 `(0,1)`、`(8,1)`。

K-Means 的目标为 $J=\sum_i\|x_i-\mu_{c_i}\|^2$：`c_i` 是第 i 个样本的簇编号，`μ_k` 是第 k 个中心。固定中心时，最近中心使每个点的误差最小；固定分组时，对中心求导并令其为零，得到 $\mu_k=\frac{1}{n_k}\sum_{i:c_i=k}x_i$。这里假设簇非空，n_k 是该簇样本数。

**结果（静态计算，已核对）：** 更新后每点到本簇中心的平方距离为 1，总和为 4，下一次分配不变。每一步都在改善或保持当前目标，但这不证明找到了全局最优。空簇、并列距离和初始化需要实现层面的处理，机制见 [scikit-learn 1.7 K-Means 说明](https://scikit-learn.org/1.7/modules/clustering.html#k-means)。

尺度也会改写目标：若第二维扩大 10 倍，其差异的平方扩大 100 倍，算法可能更倾向上下分组。是否缩放，取决于希望哪些差异影响分组；不能把默认距离当作天然正确的相似性定义。

## 怎么解释结果

| 工具 | 回答什么 | 不能据此断言什么 |
| --- | --- | --- |
| inertia / 肘部图 | 增加簇数后，簇内紧凑程度改善多少？ | 弯折点必然是唯一正确 K |
| 轮廓系数 | 样本与本簇相比其他簇是否更接近？ | 分数高就对应真实业务类别 |
| 簇画像 | 各簇在原始单位下有哪些典型特征？ | 簇名就是客观身份 |
| PCA 二维图 | 主要变化投影后看起来怎样？ | 二维重叠就代表原空间无法区分 |

轮廓系数通常介于 -1 与 1，较大表示在所选距离下分离更清楚，接近零表示边界重叠。K-Means 偏好紧凑、近似球形的簇，对极端值、弯曲结构或密度差异大的数据可能不合适。

PCA 将中心化后的特征投影到互相正交、依次保留较多方差的方向；它不读取类别来寻找最好分类边界，也不是自动选择原始特征列。数据尺度会改变哪些方向具有较大方差。

## PCA 手算：四个点怎样变成一列数

沿用上述四点，均值为 `μ=[4,1]`，每点减去均值后得到 `[-4,−1]`、`[-4,1]`、`[4,−1]`、`[4,1]`。减均值使我们观察“相对中心的变化”，而不是原点到样本的距离。

对 `[N,D]` 的中心化表 `X_c`，样本协方差矩阵定义为 `S=X_cᵀX_c/(N−1)`，形状 `[D,D]`。对角项是各维方差，非对角项描述两维一起变化的程度；本例 N=4、D=2：

$$S=\begin{bmatrix}64/3&0\\0&4/3\end{bmatrix}.$$

若暂不熟悉特征向量，可以先理解为寻找一个单位方向 u，使投影 `z=x_c·u` 的方差最大。这里沿 x 轴的方向 `u=[1,0]ᵀ` 保留方差 `64/3`，沿 y 轴为 `4/3`，所以第一个主方向取 x 轴；方向整体取反也表示同一条轴。

| 原始点 | 一维投影 z | 只用第一主方向重建 `μ+zu` |
| --- | ---: | --- |
| (0,0) | −4 | (0,1) |
| (0,2) | −4 | (0,1) |
| (8,0) | 4 | (8,1) |
| (8,2) | 4 | (8,1) |

**结果与解释（静态计算，已核对）：** 第一主方向保留 `64/(64+4)=16/17≈94.12%` 的方差，但上下位置完全丢失，重建平方误差总和为 4。对于本例，`X_c[4,2] × u[2,1]` 得到投影 `[4,1]`；重建得到的仍是 `[4,2]`，不等于原数据。

如果人为把下排 y=0 标为 A、上排 y=2 标为 B，一维投影中不同类别会重合。**保留较多方差不等于保留分类信息。** 这也解释了为什么机器人数据的低方差方向仍可能重要：很小的高度差也可能决定接触与碰撞，不能只按方差删掉。

标准化、保留维数和是否重建都应围绕任务选择；PCA 的均值与方向只由训练数据拟合，推理用原样变换。理论和实现约定见 [scikit-learn 1.7 PCA 说明](https://scikit-learn.org/1.7/modules/decomposition.html#pca)。本页采用 N−1 的样本协方差，和第 03 章标准化的总体方差约定不同；两种分母在本例不改变主方向或方差比例。

## 客户消费结构案例

[实验记录](results.md)使用 440 位客户的六类商品年消费字段，排除 Channel 与 Region。先 `log1p` 缓解长尾，再用 RobustScaler 按中位数和四分位距缩放；消费币种见原始数据说明，不在此补猜单位。

| 配置 | 轮廓系数 | 解释 |
| --- | ---: | --- |
| K=2 | 0.252915 | 252 / 188 人，两个消费画像较容易概括 |
| K=3 | 0.244659 | 分得更细，但当前解释需求不足以支持增加复杂度 |

最终保留 K=2；PCA 前两维保留约 69.1% 的方差。配置与指标见[实验结果](results.md)。

**结果含义：** 这里得到的是消费特征与预处理条件下的一种分组。Channel 仅作事后解释对照；既然它曾参与选择理由，就不能再把同一对照当作独立验证。不能把簇与 Channel 的一致比例叫作本任务的分类准确率。
