## 监督学习与无监督学习

**监督学习（Supervised Learning）**的数据中，每个样本都有一个希望模型学习的**标签**（目标值）。模型从“特征 → 标签”的对应关系中学习，再预测新样本的标签。例如：根据花萼、花瓣特征预测鸢尾花品种是分类；根据房屋特征预测房价是回归。因为有真实标签，可以用准确率、F1、MSE 等指标直接比较预测结果。

**无监督学习（Unsupervised Learning）**通常只有样本的**特征**，没有供模型学习的正确标签。模型尝试从样本之间的相似性、差异或结构中发现规律。例如，根据客户消费、访问频率和停留时间聚类，或根据传感器读数寻找相似的设备运行状态。

本周使用的 K-Means 属于无监督学习：它按特征距离将相似样本分到同一簇，但 `cluster=0`、`cluster=1` 等编号只是代号，不等于天然的真实类别。轮廓系数、肘部图、PCA 图和簇画像可帮助理解分组，却不能单独证明分组就是客观规律；最终仍要结合业务或领域知识解释。

## 聚类是什么？

**聚类（Clustering）**是把一批没有标签的样本分成若干组（称为**簇**，cluster）的任务。它希望达到的直观效果是：**同一簇内的样本彼此更相似，不同簇的样本相对更不同。**

例如，每位客户由年龄、月消费额、月访问次数和平均停留时间描述。聚类不会告诉我们“这位客户属于某个预先定义的正确类别”，而是尝试发现诸如“低消费、低频访问”“高消费、高频访问”这类在数据中自然形成的模式。完成聚类后，才由人查看各簇的统计特征，为它们做业务解释或命名。

聚类的输入是特征表；输出通常包括每条样本的簇编号、每个簇的中心/统计画像和簇规模。簇编号可以任意交换：一次运行中的 `cluster=0` 在下一次运行中可能变成 `cluster=2`，这不代表结果变好或变差。

## K-Means 做了什么？

K-Means 中的 `K` 是希望分成的簇数，`Means` 指每个簇用其成员特征的**平均值**作为中心（centroid）。给定 `K` 后，算法反复进行以下两步：

1. **分配样本**：计算每个样本到各个簇中心的距离，将它分给最近的中心。
2. **更新中心**：对每个簇内的所有样本按列求平均，得到新的簇中心。

中心更新后，样本可能会被分到另一个更近的簇；算法继续“分配 → 更新”，直到分配或中心几乎不再变化。它所要减小的是每个样本到所属中心的平方距离之和（`inertia`）：数值越小表示簇内更紧凑，但因为增加 `K` 总会使它下降，所以不能只凭它选择 K。

```text
指定 K=3，随机放置 3 个中心
        ↓
每个样本分给最近中心
        ↓
每个中心移动到本簇样本的平均位置
        ↓
中心或样本归属仍在变化？──是──→ 重复上述两步
        ↓ 否
输出每个样本的簇编号与 3 个簇中心
```

本项目在 K-Means 之前进行“中位数填补 → 可选异常值处理 → 缩放”。这是因为 K-Means 依赖距离：量纲大的消费金额会压过访问次数，极端值也可能把平均中心拉偏。它更适合大小相近、近似圆团状的簇；若数据呈细长、弯曲、密度差异很大的形状，K-Means 的分组未必合适。

## 如何阅读聚类结果？

无监督学习通常没有一个现成的“标准答案”可直接计算准确率。因此，本项目从不同角度检查聚类是否值得解释；它们是**辅助证据**，不能替代对数据和业务背景的判断。

### 轮廓系数（Silhouette Score）

轮廓系数衡量一个样本与“自己所在簇”相比，是否离“其他簇”更近。对一个样本来说：

- `a`：它与同簇其他样本的平均距离，越小表示簇内越紧密；
- `b`：它与最近其他簇样本的平均距离，越大表示簇间越分离；
- 轮廓系数：`(b - a) / max(a, b)`，范围约为 `-1` 到 `1`。

接近 `1` 表示样本在本簇内较合适；接近 `0` 表示处于两个簇的边界；小于 `0` 则提示它可能更接近另一个簇。脚本输出的是**所有样本的平均轮廓系数**，可用于比较候选 K；但最高分的 K 仍可能产生过小的簇，或不符合实际解释。

### 肘部图（Elbow Plot）

肘部图的横轴是簇数 `K`，纵轴通常是 K-Means 的 `inertia`（簇内平方距离和）。K 增大时，每个簇可以更细地覆盖数据，所以 inertia 必然下降。我们寻找的是下降趋势从很快变得较慢的位置，形状像手肘弯折处；它意味着再增加簇数带来的紧凑度改善开始有限。

“肘部”不一定清晰，也不保证它就是最佳 K。应同时查看轮廓系数、最小簇规模、PCA 图和簇画像，而不是为了找出一个图上的拐点而强行选择 K。

### PCA 图（Principal Component Analysis Plot）

原始数据可能有许多特征，难以直接画图。**PCA（主成分分析）**会把多个特征线性组合成少量新坐标轴（主成分），其中第一主成分保留的数据变化最多，第二主成分在与第一不同的方向上保留尽可能多的变化。本项目把缩放后的特征投影到前两个主成分，画成二维散点图，并按簇编号着色。

PCA 图适合观察大致的分离、重叠、离群点和簇形状；坐标轴不再是“年龄”或“消费额”这类原始字段。二维投影会丢失部分高维信息，因此图上重叠不必然说明高维空间无法区分，图上分开也不等于聚类一定正确。可结合输出的 `pca_explained_variance_ratio` 查看前两个主成分保留了多少变化。

### 簇画像（Cluster Profile）

簇画像是对每个簇的原始特征进行汇总后的描述，例如样本数、占比、各特征的均值和中位数。本项目的 final_k2_cluster_profiles.csv（`outputs/tables/final_k2_cluster_profiles.csv`，原项目数据或生成产物，未迁入） 就是最终簇画像：它帮助回答“这个簇的客户通常有什么特征”“它是否足够大、值得单独解释”。

还会导出距簇中心最近的若干代表样本。它们便于回到原始记录核对，但不能被当作整个簇的唯一真相；均值容易受极端值影响，所以应同时看中位数、分布和多个代表样本。

#### IQR 是什么？

`IQR` 是**四分位距（Interquartile Range）**，描述一列数据中间 50% 样本的分布范围。先将数值从小到大排列：

- `Q1`（第一四分位数）：位于 25% 位置的数值；约 25% 的样本不大于它。
- `Q2`：位于 50% 位置的数值，也就是中位数。
- `Q3`（第三四分位数）：位于 75% 位置的数值；约 75% 的样本不大于它。
- `IQR = Q3 - Q1`：中间 50% 数据覆盖的宽度。

常见的 IQR 异常值诊断边界为：

```text
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
```

小于下界或大于上界的样本会被标记为统计异常值。例如 `Fresh` 的 `Q1≈3,128`、`Q3≈16,934`，所以 `IQR≈13,806`、上界约为 `37,643`；消费额超过该上界的客户会被标记。这个规则只是帮助发现远离主要人群的样本，并不能证明它们是错误数据。

#### 长尾分布如何影响距离？

“长尾距离”不是一个专门术语。这里实际涉及两个概念：**数据呈长尾分布**，而 **K-Means 使用样本之间的距离**。

长尾分布是指大多数数值集中在较小范围内，但少数数值非常大，使直方图的一端拖出很长的尾巴。本数据的六种消费额都呈右长尾：大多数客户消费不高，少数大型客户消费远高于中位数。

K-Means 使用欧氏距离。假设只看 `Fresh`：普通客户消费 5,000 和 10,000，差距为 5,000；若另一个大客户消费 100,000，它与 5,000 的差距为 95,000。加入其他特征后，各列差距还会以平方和的方式共同进入距离。于是长尾中的少数客户可能：

- 离大多数客户和簇中心特别远；
- 把用平均值计算的簇中心拉向自己；
- 单独形成一个很小的簇；
- 让聚类结果主要反映“消费规模”，而忽略不同商品类别的消费结构。

因此需要缩放，并考虑 `log1p` 等长尾转换；是否截断则要先判断极端值是不是有业务意义的真实大客户。

#### 本阶段的决定：保留全部客户并进行 log1p 转换

查看六列分布后，本阶段不删除客户，也不使用 IQR 截断。原因是这些极端消费额可能代表真实的大型批发客户，不能仅凭统计规则认定为错误。

对六个消费字段分别计算：

```text
x_log1p = ln(1 + x)
```

加 `1` 是为了让原始值为 `0` 时也能计算对数。转换会压缩大数值之间的差距，同时保留大小顺序。生成的 wholesale_customers_log1p.csv（`outputs/tables/wholesale_customers_log1p.csv`，原项目数据或生成产物，未迁入） 包含全部 440 位客户：

- `customer_row` 是为对照原始 CSV 添加的行号，不作为聚类特征；
- `Channel` 和 `Region` 保留原值，不参与 `log1p`；
- 六个以 `_log1p` 结尾的字段是转换后的消费额；
- 当前文件尚未执行 `RobustScaler`，也没有进行 K-Means。

这是一份用于观察转换效果的**衍生数据**，不是对原始数据的覆盖或修正。原始 wholesale_customers.csv（`data/wholesale_customers.csv`，原项目数据或生成产物，未迁入） 始终保持不变。

#### RobustScaler 是什么？

`RobustScaler` 对每一列分别使用下面的方式缩放：

```text
x_scaled = (x - median) / IQR
IQR = Q3 - Q1
```

其中 `median` 是中位数，`Q1` 和 `Q3` 分别是第 25% 和第 75% 分位数。缩放后，中位数附近通常接近 `0`，一个四分位距大致对应 `1` 个缩放单位。它不像 `StandardScaler` 那样依赖均值和标准差，因此缩放参数较不容易被少数极端消费额拉偏，适合本数据的长尾分布。

但 `RobustScaler` **不会删除或截断异常值**：极端大客户缩放后仍可能离其他样本很远。`--scaler robust` 负责改变尺度；`--clip-outliers` 才负责把超出 1.5 IQR 边界的数值截到边界。是否截断必须结合业务判断，二者不能混为一谈。

#### 本阶段完成：对 log1p 特征进行稳健特征缩放

本阶段以 wholesale_customers_log1p.csv（`outputs/tables/wholesale_customers_log1p.csv`，原项目数据或生成产物，未迁入） 为输入，只对六个 `_log1p` 消费特征拟合 `RobustScaler`。`customer_row`、`Channel` 和 `Region` 仅用于追踪和事后参考，不参与缩放参数的计算。

生成了两份衍生文件：

- wholesale_customers_log1p_robust_scaled.csv（`outputs/tables/wholesale_customers_log1p_robust_scaled.csv`，原项目数据或生成产物，未迁入）：440 位客户的六个缩放后特征；没有删除或截断任何样本。
- robust_scaler_parameters.csv（`outputs/tables/robust_scaler_parameters.csv`，原项目数据或生成产物，未迁入）：每个特征的 Q1、中位数、Q3 和 IQR，可用于核对缩放过程。

检查结果为：六个缩放后特征的中位数都约为 `0`，IQR 都约为 `1`。这些值没有原始货币单位，而表示某位客户相对于该商品类别典型消费范围的位置。负数不是负消费，而是表示转换后的消费低于该列中位数。

术语上，“缩放”是正确说法，更完整的是**特征缩放（feature scaling）**；本次还可以精确称为**基于中位数和 IQR 的稳健特征缩放（robust feature scaling）**。“标准化”有时特指 `StandardScaler` 的零均值、单位标准差处理，“归一化”又常指缩放到固定范围或把样本向量变成单位长度，因此本项目优先使用“稳健特征缩放”，避免混淆。

### 从原始数据到 K-Means：完整复习路线

本项目最终采用的路线是：

```text
理解字段并确认没有缺失值
        ↓
查看分布与 IQR 异常值，但保留全部客户、不截断
        ↓
log1p 缓解右长尾
        ↓
RobustScaler 统一中心与典型尺度
        ↓
检查六个聚类特征之间的相关性
        ↓
比较 K=2～6 的 K-Means
        ↓
结合指标、PCA 图和簇画像选择并解释结果
        ↓
最后才用 Channel 做事后参考
```

#### 第 1 步：log1p 处理分布形状

原始消费额具有明显右长尾，少数大型客户会与大部分客户相距很远。`log1p` 使用 `ln(1+x)` 压缩大数值差距，同时保留数值大小顺序。它的目标是**缓解长尾和偏斜**，并不保证把数据变成正态分布，也不会删除客户。

#### 第 2 步：RobustScaler 处理特征尺度

在 `log1p` 之后，再对每个特征使用 `(x-median)/IQR`。这使六列的中位数约为 `0`、IQR 约为 `1`，避免某一列仅因数值范围较大而主导欧氏距离。RobustScaler 不改变 `log1p` 后的分布形状，也不删除或截断离群点。

两步解决的问题不同：`log1p` 主要改变分布形状，RobustScaler 主要统一中心和尺度。K-Means 应只读取 wholesale_customers_log1p_robust_scaled.csv（`outputs/tables/wholesale_customers_log1p_robust_scaled.csv`，原项目数据或生成产物，未迁入） 中六个以 `_robust_scaled` 结尾的特征；`customer_row`、`Channel`、`Region` 都不参与距离计算。

#### 第 3 步：K-Means 前检查相关性

相关性检查回答的是：两列特征是否在大体上一起升高或一起降低。常用的 Pearson 相关系数 `r` 介于 `-1` 和 `1`：

- `r` 接近 `1`：两列具有较强的正线性关系；
- `r` 接近 `-1`：两列具有较强的负线性关系；
- `r` 接近 `0`：没有明显的线性关系，但仍可能存在非线性关系。

##### Pearson 相关系数如何把关系量化为数字？

对两个特征 `X` 和 `Y`，Pearson 相关系数的计算公式为：

```text
         Σ[(xᵢ - x̄)(yᵢ - ȳ)]
r = ─────────────────────────────────
    √[Σ(xᵢ - x̄)² × Σ(yᵢ - ȳ)²]
```

其中 `x̄`、`ȳ` 分别是两列的平均值。计算可以分成四步理解：

1. 分别计算两列的平均值。
2. 对每位客户，计算它在两列中高于或低于平均值多少。
3. 将两个偏离值相乘并累加：两列同时高或同时低时得到正数，一高一低时得到负数。
4. 除以两列各自的总体波动大小，将结果限制到 `-1～1`，从而消除原始量纲的影响。

因此，`r` 的正负表示共同变化的方向，绝对值表示线性关系的紧密程度：

| Pearson r | 直观含义 |
| ---: | --- |
| `1` | 完全正线性关系；一列增加时，另一列按固定比例增加。 |
| 接近 `1` | 较强正线性关系。 |
| `0` | 没有明显线性关系，但仍可能存在曲线等非线性关系。 |
| 接近 `-1` | 较强负线性关系。 |
| `-1` | 完全负线性关系；一列增加时，另一列按固定比例减少。 |

从几何角度看，先将两列分别减去其平均值，Pearson `r` 就等于这两个中心化向量夹角的余弦：方向相同为 `1`，近似垂直为 `0`，方向相反为 `-1`。这里计算相关性时仍会按定义减去**平均值**；此前 RobustScaler 使用中位数居中，并不会改变 Pearson 的计算规则。

相关性不表示因果关系。例如 `Grocery` 与 `Detergents_Paper` 同时较高，不能据此断定购买杂货导致购买清洁剂。RobustScaler 只进行平移和正比例缩放，所以不会改变 Pearson `r`；`log1p` 是非线性转换，可能改变相关系数。

通常可将 `|r| ≥ 0.8` 暂时视为“值得重点检查的强相关”，但这只是经验阈值，不是自动删除特征的规则。`RobustScaler` 是正比例线性缩放，不会改变 Pearson 相关系数，因此可以在 `log1p` 数据或缩放后数据上检查；结果应相同。

K-Means 使用欧氏距离。如果多个高度相关的特征表达几乎同一件事，相当于在距离中重复强调同一方向。例如 `Milk`、`Grocery`、`Detergents_Paper` 若高度相关，可能让“这类商品共同消费较高”获得过多权重。

| 检查结果 | 应该怎么做 | 不应该怎么做 |
| --- | --- | --- |
| 出现强相关 | 先查看字段含义和散点图，判断它们是否真的重复；可保留全部特征作为基线，再尝试删除其中一个、合成一个指标或使用 PCA，并比较聚类是否稳定、是否更容易解释。 | 只看到相关系数高就立即删除一列。不同字段即使相关，也可能有不同业务含义。 |
| 没有明显强相关 | 若字段含义合理，可保留六个特征继续 K-Means；说明没有某一对特征在明显重复表达同一条线性信息。 | 认为低相关就是“特征没用”。低相关只表示线性关系弱，不代表它对区分客户没有价值。 |
| 出现较强负相关 | 检查是否代表一种真实的消费取舍，例如某类商品消费越高、另一类越低；若有业务意义通常可以保留。 | 把负相关直接当成异常或错误。 |

相关性不是越低越好，也不是越高越坏。它只是帮助我们理解：K-Means 的距离究竟会综合哪些重复或互补的信息。

##### 相关性与 PCA 有什么关系？

两者有关，但用途不同：

- 相关系数表逐对描述两个原始特征的线性关系，方便人直接阅读“哪两类消费一起变化”。
- PCA 同时利用所有特征的协方差结构，将相关特征组合成新的主成分。若几列一起升高，第一个主成分可能把它们合并成一个“共同消费变化”方向。
- PCA 产生的主成分彼此正交、不相关，因此可以压缩相关信息；但主成分是多个原始字段的组合，通常比原始消费类别更难解释。

更严格地说，PCA 默认在输入数据的**协方差矩阵**上寻找变化最大的方向；相关系数矩阵是将各列按标准差标准化后的协方差矩阵。本项目使用 RobustScaler，使 IQR 相同但不保证标准差完全相同，所以后续 PCA 与这张 Pearson 相关系数表密切相关，却不是直接对该表做同一个计算。

本项目第一轮不会在 K-Means 前用 PCA 降维：K-Means 仍使用全部六个缩放特征，PCA 只在聚类后把六维结果投影到二维，帮助画图。若以后改成“先 PCA、再 K-Means”，那是另一套需要单独比较的实验，不能与当前结果混在一起。

#### 第 4 步：比较多个 K，而不是直接指定答案

本项目先尝试 `K=2、3、4、5、6`。对每个 K 使用同一份六特征缩放数据，并固定随机种子；K-Means 的内部过程为：

1. 使用 `k-means++` 选择 K 个较分散的初始中心。
2. 计算每位客户到各中心的欧氏距离，将客户分给最近的中心。
3. 对每个簇内的客户按列求平均，更新簇中心。
4. 重复“分配客户 → 更新中心”，直到结果基本不再变化。
5. 使用多个初始化结果（例如 `n_init=20`），保留 inertia 较小的一次，减少偶然初始中心的影响。

每个 K 都至少记录：

- `inertia`：客户到所属簇中心的平方距离之和；K 增大时必然下降，主要用于观察肘部趋势。
- 轮廓系数：同时考虑簇内紧密和簇间分离；越高通常越好，但不能机械选择最高值。
- 各簇样本数：检查是否出现只有一两位客户的极小簇。
- 结果稳定性：更换初始化后，簇规模和画像是否大体一致。

## 使用自己的机器人传感器或客户 CSV

将 CSV 放入 `data/`（通常不提交原始敏感数据），并把四条分析命令中的 `--data-path data/your_file.csv` 与 `--feature-columns` 改为实际字段。例如：

```bash
python src/explore_data.py \
  --data-path data/robot_sensors.csv \
  --feature-columns motor_current,temperature,vibration_rms,cycle_time
```

当前框架只直接接受数值特征。不要输入流水号、时间戳、设备 ID、客户 ID、由未来信息得到的字段，或事后人工标签。若有类别字段，需要先在业务上决定是否应编码以及如何赋权；简单地把任意编码后的编号交给 K-Means 往往会制造无意义距离。

## 预处理与选择 K

当前 Wholesale Customers 实验使用固定顺序：`保留全部客户 → log1p → RobustScaler → 相关性检查 → K-Means`。六个消费特征没有缺失值，因此没有发生填补；也没有执行 IQR 截断。若以后替换数据集，应重新判断缺失值、异常值、长尾和缩放方式，不能机械复用本次决定。

| 输出 | 应如何使用 | 不应如何使用 |
| --- | --- | --- |
| `inertia`（肘部图） | 看增加一个簇后的下降是否开始变缓 | 期待自动出现唯一明显的折点 |
| `silhouette_score` | 比较簇内紧密、簇间分离的相对程度 | 机械选择最大值而忽略极小簇或不可解释的簇 |
| `final_k2_cluster_profiles.csv` | 查看最终簇规模与原始金额画像 | 仅因簇大小均等就判断聚类可靠 |
| PCA 二维图 | 辅助观察大致分离和重叠 | 把二维投影误认为完整高维距离 |

本次正式结果统一使用 `final_k2_*` 命名，候选比较文件则使用 `k_candidate_*` 或 `k2_k3_*` 命名。簇编号本来没有天然语义；为方便前后阅读，本项目按簇内总消费额中位数从低到高映射为 C0、C1，并把映射一同保存在模型包和元数据中。
