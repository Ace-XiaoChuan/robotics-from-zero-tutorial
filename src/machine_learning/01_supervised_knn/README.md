# 01 监督学习与 KNN：距离、邻居与决策边界

本文行数：90行，预期阅读时长：6分钟

## 速记要点

- 监督学习的数据包含特征与标签；分类输出类别，回归输出数值。
- KNN 保存训练样本，预测时找最近的 K 个邻居并投票；它不靠反向传播学习权重。
- 距离会受特征单位和尺度影响。选 K 用训练集内部的交叉验证，预处理也必须在每折内拟合。
- 特征空间是按特征坐标摆放样本的空间；决策边界是预测类别发生变化的位置，不是物体的几何轮廓。
- 邻居投票比例描述当前邻居构成，不能直接当作事实可靠度或机器人动作成功率。

本章的新增数值是人为教学例子，已经用[标准库核对程序](../examples/README.md)检查；Iris 的成绩仍是历史记录。

## 例子：三个邻居怎样投票

下面用二维、已经统一尺度的特征作示意，不是实际 Iris 数据。新样本是 `(2, 2)`，使用欧氏距离和等权投票。

| 训练样本 | 类别 | 到新样本的距离 |
| --- | --- | ---: |
| (1, 2) | A | 1 |
| (2, 3) | A | 1 |
| (4, 2) | B | 2 |

**结果：** K=3 时，A 获得两票，输出 A。这只说明相似性规则怎样得到一个预测，不证明类别一定正确。实际使用中，噪声、样本稀疏或特征选得不好都可能使邻居误导预测。

K 较小容易跟随局部细节，K 较大更平滑；不能断言越大越好。KNN 的 K 是邻居数量，与聚类中“分成多少簇”的 K 含义不同。

## 特征空间：距离实际在比较什么

一个二维特征向量 `x=[x₁,x₂]` 就对应平面上的一个点；四个特征对应四维空间，不需要画出来才能计算。训练输入 `X` 为 `[N,D]`，一个新输入为 `[D]`，每个训练样本有一个类别标签。

欧氏距离为 $d(x,z)=\sqrt{\sum_{j=1}^{D}(x_j-z_j)^2}$。它把各维差异的平方相加，因此每一维的数值尺度会影响谁更近。特征可以是物体长度、重量或网络特征，距离含义随这些选择改变。

**例子：只换重量单位，最近邻就变了。** 新物品的特征是 `[长度 1.0 m, 重量 100 g]`，属于类别 A 的训练物品是 `[1.1 m,300 g]`，属于类别 B 的训练物品是 `[2.0 m,110 g]`。以下故意直接对混合单位的数字计算距离，展示问题；这些距离没有统一的物理单位。

| 表示方式 | 到 A 的数值距离 | 到 B 的数值距离 | K=1 输出 |
| --- | ---: | ---: | --- |
| 长度用 m、重量用 g | 200.000025 | 10.049876 | B |
| 长度用 m、重量改用 kg | 0.223607 | 1.000050 | A |

**结果与解释（静态计算，已核对）：** 物品没有改变，预测却反转，因为重量这一维的数值缩小了 1,000 倍。直接相加并没有替我们决定长度和重量哪个更重要。

可以用训练集确定的尺度 `s_j` 比较无量纲差异 `(x_j-z_j)/s_j`。例如本例选 `s_长度=1 m`、`s_重量=100 g`，两组归一化差异为 A `[0.1,2]`、B `[1,0.1]`。将重量改为 kg 时也把尺度改为 `0.1 kg`，这两个向量保持不变。真实标准化常用训练集标准差；它统一数值尺度，但不保证得到最符合任务的距离。具体计算见[第 03 章](../03_preprocessing_pipeline/README.md)。

## 同一个输入：改变 K 或投票方式

另设无量纲输入 `(2,2)`，三个邻居依次为 `(1.9,2)` 的 B、`(2,2.2)` 的 A、`(2.3,2)` 的 A，距离分别为 0.1、0.2、0.3。

| 规则 | 计算 | 输出 |
| --- | --- | --- |
| K=1，等权 | 只看最近的 B | B |
| K=3，等权 | A 两票，B 一票 | A |
| K=3，距离加权 | 权重取 1/d：A 为 5+3.333333，B 为 10 | B |

**结果与解释（静态计算，已核对）：** K 控制取多少邻居，投票方式控制邻居贡献，两者共同决定预测。等权时 A 的比例为 2/3，表示选中的三位邻居里有两位属于 A；它不保证新物品属于 A 的真实概率为 66.67%。本例距离均非零，实际实现需处理零距离；并列距离或票数也需要明确处理规则。接口见 [scikit-learn 1.7 近邻说明](https://scikit-learn.org/1.7/modules/neighbors.html)。

## 决策边界：预测在哪些位置会改变

只有两个训练点时，设 A 在 `(-1,0)`、B 在 `(1,0)`，使用 K=1。对新点 `(x,y)`，两边平方距离之差为：

$$d_A^2-d_B^2=(x+1)^2+y^2-[(x-1)^2+y^2]=4x.$$

**结果（静态推导，已核对）：** x<0 时更靠近 A，x>0 时更靠近 B，x=0 时距离相等。直线 x=0 是这个分类器的决策边界；边界上的输出取决于并列规则。增加训练点后边界会由多个局部区域组成，少量错误标签就可能切出不合理的小区域。

样本很多不等于特征有用：若特征主要描述背景而标签描述物体，最近邻可能按背景分组。维度增加还会使样本覆盖更稀疏；把所有像素直接当作特征，也不会自动获得对位置和光照变化的适应能力。第 07 章进一步解释学习视觉特征。

## 仓库例子：Iris

每朵花是一个样本，四个特征为花萼长度、花萼宽度、花瓣长度、花瓣宽度，原始单位均为厘米。输入特征表 `[N, 4]`，输出 N 个品种编号；编号本身不是大小关系。

[训练源码](src/train_knn.py)将标准化和 KNN 放在 Pipeline 中。标准化按训练数据计算每列均值与标准差，将各列转成无量纲尺度；即使单位相同，不同列的变化范围也可能不同。

| 历史记录项 | 数值 |
| --- | ---: |
| 划分种子 | 42 |
| 训练 / 测试样本数 | 120 / 30 |
| 交叉验证选出的 K | 3 |
| 最佳交叉验证准确率 | 96.67% |
| 测试准确率 | 93.33%（28 / 30） |

来源：[历史指标](outputs/knn_results.json)，本次未重训。交叉验证与测试分数不同并不矛盾，它们使用的数据不同；30 个测试样本中改变一个预测，准确率就变化约 3.33 个百分点。

## 易混点

训练不是一定得到一条公式；保存用于比较的样本也是一种学习方式。标准化则确实需要拟合统计量，不能因为 KNN 没有梯度训练就对全量数据提前标准化。

混淆矩阵能看出哪两个品种容易混淆，不能只看总准确率。指标含义统一见[预处理与分类指标](../03_preprocessing_pipeline/README.md)。
