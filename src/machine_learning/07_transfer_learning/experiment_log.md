## 自拍照片单张推理：2026-09-21

- 使用 `picture.jpg` 运行 `src/predict.py`，照片实际类别为纸张。
- 模型预测为纸板，softmax 分数：纸板 56.02%、纸张 35.72%、金属 8.26%。
