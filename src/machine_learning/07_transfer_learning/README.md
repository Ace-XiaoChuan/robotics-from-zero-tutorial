# 07 迁移学习：只训练分类头，也在使用深度学习

本文行数：83行，预期阅读时长：4分钟

## 速记要点

- 这个项目同时属于监督学习、深度学习应用和迁移学习，三个名称描述不同角度。
- ResNet18 的多层特征提取部分已经训练过；本项目冻结它，只学习新的三分类头。
- 冻结是不更新参数，不是跳过计算；每张图片仍然经过深度网络。
- 三轮训练是遍历训练集三次，不是只更新三次，也不是“网络有三层”。

## 第七周到底做了什么

输入一张物品照片，输出材料类别：纸张 `paper=0`、纸板 `cardboard=1`、金属 `metal=2`。这是图像分类，不输出物体位置，也没有学习机器人动作。

```text
RGB 图片 [B, 3, 224, 224]
          ↓
预训练 ResNet18 特征提取部分（冻结，但照常计算）
          ↓
每张图的 512 个特征 [B, 512]
          ↓
新 Linear 分类头（本项目训练）
          ↓
三个类别的 logits [B, 3]
```

B 为批次大小；输入经过缩放、中心裁剪及预训练权重对应的归一化。512 个数是网络算出的特征，不是 512 个类别，也不能简单逐项命名成“颜色”“边缘”。

## 深度学习藏在哪里

ResNet18 是残差卷积神经网络。卷积在图片局部窗口上进行共享权重的计算，多层卷积与非线性逐步形成特征；残差连接让部分输入通过捷径与后续变换结果相加，池化汇总空间信息。

这些计算已经封装在模型中，所以无需自己逐层编写也可以使用。详细窗口计算、池化与残差例子见[CNN 概念笔记](concepts.md)。网络的“深”描述计算层次，与训练轮数无关。

| 部分 | 参数从哪里来 | 本项目是否更新 |
| --- | --- | --- |
| 特征提取部分 | ImageNet 预训练参数 | 否 |
| 原来的 1,000 类分类头 | 原任务 | 已被替换，不作为本任务输出 |
| 新的三分类头 | 随机初始化 | 是 |

**只看新分类头，它是单个线性层；看整个分类系统，它使用了深度网络。** 这解释了为什么“自己只训练分类头”与“已经用到深度学习”同时成立。[PyTorch 迁移学习教程](https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html)也区分固定特征提取器与微调网络两种方式。

## 例子：分类头学的是什么

将实际 512 维缩小为 2 维方便手算，假设特征为 `h=[2,1]`，参数是人为选择的示意值。

| 类别 | 权重 w | 偏置 b | 分数 w·h+b |
| --- | --- | ---: | ---: |
| 纸张 | [1, 0] | 0 | 2 |
| 纸板 | [0, 1] | 0 | 1 |
| 金属 | [-1, 1] | 0 | -1 |

**结果：** 最大分数为纸张。如果标签为纸板，训练会根据交叉熵梯度调整分类头，让这类特征更有利于正确类别；被冻结的特征提取参数保持不变。

实际分类头有 `3×512+3 = 1,539` 个可训练参数；[历史模型摘要](outputs/tables/model_summary.json)记录整个三分类网络共有 11,178,051 个参数。绝大多数参数参与计算，却不在这次训练中更新。

[模型源码](src/model.py)不仅冻结参数，也让骨干保持评估模式，避免 BatchNorm 运行统计量继续改变。单纯设置参数不求梯度，并不能自动冻结这类缓冲区。

## 三轮训练与历史结果

基础实验有 984 张训练图片，batch size 32，保留尾批：每轮 `ceil(984/32)=31` 次更新，三轮共 **93 次更新**。这是依据配置和训练循环的静态计数。

以下为迁入的两组历史记录，种子均为 42、SGD 学习率 0.01、训练三轮；每组根据最低验证 loss 保存模型，均选中第三轮。本次没有重新训练。

**结果与解释：** 增强版只多预测对一张测试图片，不能据此断言增强稳定改善泛化；验证准确率反而下降。准确率与 loss 衡量方式不同，最低验证 loss 不保证最高验证准确率。两组测试结果已经查看，不能再反复据此调参而仍把同一测试集称为全新独立评估。

## 推理与微调的边界

[predict.py](src/predict.py)已实现单图推理：加载完整 checkpoint、恢复固定预处理、输出三类 softmax 分数；相应权重没有迁入，本次未运行它。旧笔记中早期的“单图预测待实现”只代表当时阶段。

输入杯子、键盘等三类之外的物品，模型仍可能给某一类很高的分数。分数总和为 1 不代表可靠性已校准，分类结果也不能直接充当抓取位置。

微调是进一步允许部分或全部预训练参数更新；它是按任务需要选择的方法，不是完成迁移学习必须补做的一步。当前历史训练只更新分类头，不标记为骨干微调完成。
