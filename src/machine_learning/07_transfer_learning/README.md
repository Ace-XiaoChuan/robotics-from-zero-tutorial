# 07 CNN 与迁移学习：特征如何形成、训练改变什么

<a id="developer-overview"></a>

## 开发者理解：把已有视觉能力适配到自己的任务

**迁移学习是利用已经训练过的模型，再适配自己的任务。** 例如，已有视觉网络从大量图片中学到了一些有用的图像特征，现在利用这些能力，学习区分自己的纸张、纸板和金属照片。通常不必从头建立全部视觉能力。

本章使用的 **CNN（卷积神经网络）**可以先理解为：在图片各处分析局部模式，再逐层组合成用于判断的特征。具体卷积怎样算不影响先理解“图片进入，特征形成，类别预测出来”这个功能。

| 部分 | 负责什么 | 本章怎样使用 |
| --- | --- | --- |
| 预训练的特征提取部分 | 把图片变成用于判断的内部特征 | 使用已有参数 |
| 分类头，也就是末端的分类部分 | 把特征对应到本任务的类别 | 用自己的材料标签训练 |
| 完整分类系统 | 接收新图片，输出类别及分数 | 两部分一起参与预测 |

**例子（教学示意）：** 输入一张物品照片，先由已有网络提取视觉特征，再由新分类头比较纸张、纸板、金属，最后输出一个预测类别。这说明系统如何使用已有能力，没有新增实际推理结果。

**冻结**表示训练时保留某部分参数不变，它仍然参与预测。本章冻结已有特征提取部分，只训练新的分类头。因此，虽然自己只训练了末端的一小部分，整个预测过程仍在使用已经训练过的深度网络。

**微调**则进一步允许部分或全部已有参数改变，让内部特征也适应新任务。只训练分类头和微调都属于使用预训练能力的方式；是否需要进一步微调，取决于现有特征与新数据是否匹配。允许调整更多参数，也会增加数据与训练方面的要求，不保证一定改善。

**数据增强**是给训练图片增加应当保留答案的变化，例如适度改变亮度，让同一材料在不同外观条件下仍有学习例子。它不能随意改变任务含义：若任务要区分红杯和蓝杯，抹掉颜色差别就可能删除需要的信息。增强后的图片更多，也不等于独立采集了更多物体。

**分类功能的边界由任务定义决定。** 本章输出材料类别，不能直接给出物体在哪里或夹爪应去哪里。对纸张、纸板、金属之外的物品，它仍可能选出三类中的某一类；已有视觉能力也不保证能适应新背景、光照和拍摄视角。

**需要深入时：** [CNN 怎样处理图片](#深度学习藏在哪里) · [分类头的作用](#例子分类头学的是什么) · [冻结与微调](#冻结微调与增强改变的是哪一部分) · [预测能力的边界](#推理与微调的边界)。

## 速记要点

- 这个项目同时属于监督学习、深度学习应用和迁移学习，三个名称描述不同角度。
- ResNet18 的多层特征提取部分已经训练过；本项目冻结它，只学习新的三分类头。
- 冻结是不更新参数，不是跳过计算；每张图片仍然经过深度网络。
- 三轮训练是遍历训练集三次，不是只更新三次，也不是“网络有三层”。
- 卷积保持局部空间布局，池化和分类头逐步汇总信息；图像分类结果不会自动保留可用于抓取的物体位置。

## 仓库任务：从照片到材料类别

输入一张物品照片，输出材料类别：纸张 `paper=0`、纸板 `cardboard=1`、金属 `metal=2`。这是图像分类，不输出物体位置，也没有学习机器人动作。

```text
RGB 图片 [B, 3, 224, 224]
          ↓
预训练 ResNet18 特征提取部分（冻结，但照常计算）
          ↓
每张图的 512 个特征 [B, 512]
          ↓
新 Linear 分类头（本项目训练）
          ↓
三个类别的 logits [B, 3]
```

B 为批次大小；输入经过缩放、中心裁剪及预训练权重对应的归一化。512 个数是网络算出的特征，不是 512 个类别，也不能简单逐项命名成“颜色”“边缘”。

## 深度学习藏在哪里

ResNet18 是残差卷积神经网络。卷积在图片局部窗口上进行共享权重的计算，多层卷积与非线性逐步形成特征；残差连接让部分输入通过捷径与后续变换结果相加，池化汇总空间信息。

这些计算已经封装在模型中，所以无需自己逐层编写也可以使用。详细窗口计算、池化与残差例子见[CNN 概念笔记](concepts.md)。网络的“深”描述计算层次，与训练轮数无关。

## 一个卷积核怎样产生局部特征

沿用[详细笔记中的手算输入](concepts.md)：单通道图片 `[[1,2,3],[4,5,6],[7,8,0]]`，教学卷积核 `[[1,0],[0,−1]]`，步幅 1、无填充、无偏置。左上窗口得到 `1×1+2×0+4×0+5×(−1)=−4`，四个窗口组成：

~~~text
卷积响应        ReLU 后
−4  −4          0  0
−4   5          0  5
~~~

**结果与解释（静态计算，已核对）：** 同一组权重在四个位置复用，分别比较局部窗口的左上值与右下值。输出保留窗口位置，数值表示响应，不是类别概率。这里采用深度学习通常使用的“不翻转核”的互相关计算；接口定义见 [PyTorch 2.6 Conv2d](https://docs.pytorch.org/docs/2.6/generated/torch.nn.Conv2d.html)。实际模型的核通过训练学习，本例核为人为选择。

RGB 输入的一层普通卷积会同时汇总三个输入通道。若输入为 `[B,3,5,5]`、输出通道数为 2、核为 3×3、步幅 1、无填充、膨胀系数为 1、`groups=1`，输出为 `[B,2,3,3]`，权重形状为 `[2,3,3,3]`。含偏置参数数目为 `2×(3×3×3+1)=56`；它与 B 和窗口数量无关，这是权重共享减少参数的具体体现。

### 感受野：一个输出能关联多大的输入区域

**感受野（receptive field）**是一个输出位置通过网络计算能够依赖的输入区域。第一层 3×3 卷积看 3×3 输入；第二层若再用 3×3、步幅 1，就结合邻近的第一层响应，所以看的是 5×5 输入，而不是 6×6。

| 层，均无填充且步幅为 1 | 对 7×7 输入的输出尺寸 | 一个输出位置的理论感受野 |
| --- | --- | --- |
| 第一层 3×3 卷积 | 5×5 | 3×3 |
| 第二层 3×3 卷积 | 3×3 | 5×5 |

**结果与解释（静态推导，已核对）：** 多层把局部响应组合成更大范围的信息。若某些权重为零，实际贡献可能小于理论覆盖；增加步幅、池化或膨胀会改变覆盖和采样间隔。权重共享使相同局部模式可在不同位置被处理，但不保证整网对任意平移都完全不变，边界、下采样和任务输出都会影响结果。

### 池化与残差各解决什么问题

对上面的 ReLU 特征图，全局平均池化得到 `(0+0+0+5)/4=1.25`，最大池化整个区域得到 5。平均保留区域整体响应，最大值保留最强响应；两者都汇总掉了这里的具体位置，不能从一个数恢复右下角目标坐标。详细窗口例子见 CNN 笔记。

残差块写为 `y=x+F(x)`，F 是若干层计算出的变换，x 提供另一条信息和梯度路径。相加要求形状兼容，不同时需要投影。它不是“跳过全部计算”，也不保证深网一定训练成功；完整梯度仍沿第 06 章的链式法则传播。

| 部分 | 参数从哪里来 | 本项目是否更新 |
| --- | --- | --- |
| 特征提取部分 | ImageNet 预训练参数 | 否 |
| 原来的 1,000 类分类头 | 原任务 | 已被替换，不作为本任务输出 |
| 新的三分类头 | 随机初始化 | 是 |

**只看新分类头，它是单个线性层；看整个分类系统，它使用了深度网络。** 这解释了为什么“自己只训练分类头”与“已经用到深度学习”同时成立。[PyTorch 迁移学习教程](https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html)也区分固定特征提取器与微调网络两种方式。

## 例子：分类头学的是什么

将实际 512 维缩小为 2 维方便手算，假设特征为 `h=[2,1]`，参数是人为选择的示意值。

| 类别 | 权重 w | 偏置 b | 分数 w·h+b |
| --- | --- | ---: | ---: |
| 纸张 | [1, 0] | 0 | 2 |
| 纸板 | [0, 1] | 0 | 1 |
| 金属 | [-1, 1] | 0 | -1 |

**结果：** 最大分数为纸张。如果标签为纸板，训练会根据交叉熵梯度调整分类头，让这类特征更有利于正确类别；被冻结的特征提取参数保持不变。

**接着算一次更新（教学示意）：** 类别顺序为 `paper=0`、`cardboard=1`、`metal=2`，纸板标签为 1。上述分数对应概率约 `[0.705385,0.259496,0.035119]`，交叉熵为 `1.349012`；分数梯度为“概率减正确类别的 one-hot”，即 `[0.705385,−0.740504,0.035119]`。每个权重的梯度再乘上对应特征值，偏置梯度直接等于该类别的分数梯度。

使用学习率 `0.01` 做一步无动量 SGD 后，纸板概率增至 `0.276122`、损失降至 `1.286911`，最高分类别仍为纸张。3×2 权重与三个偏置的完整求导、更新值和实际 `[B,512] → [B,3]` 对应见[分类头求导](head_gradients.md)；批量反向链复用 [06 的推导](../06_pytorch_networks/backpropagation.md)。这些手算数值与下方真实图片的历史训练记录分别说明不同问题。

实际分类头有 `3×512+3 = 1,539` 个可训练参数；[模型摘要](outputs/tables/model_summary.json)记录整个三分类网络共有 11,178,051 个参数。绝大多数参数参与计算，却不在这次训练中更新。

[模型源码](src/model.py)不仅冻结参数，也让骨干保持评估模式，避免 BatchNorm 运行统计量继续改变。单纯设置参数不求梯度，并不能自动冻结这类缓冲区。

## 冻结、微调与增强：改变的是哪一部分

| 方式 | 特征提取部分 | 分类头 | 主要影响 |
| --- | --- | --- | --- |
| 本仓库固定特征提取 | 权重固定，骨干保持 eval | 学习新三分类参数 | 适应已有特征的分类规则 |
| 微调，教学方案 | 选定层允许更新；层模式另行设置 | 通常同时更新 | 让部分特征适应新数据，也增加过拟合和训练不稳定的可能 |

BatchNorm 还保存运行均值和方差，这些是模型缓冲区，训练模式的前向就可能更新。**批次变化会改变统计与输出，不意味着冻结的可学习权重自行改变。** 因此本项目让骨干保持 eval；`no_grad()` 是否记录梯度、`requires_grad` 是否对参数求导、`train/eval` 怎样使用统计，各自需要判断。若之后改为训练骨干，就不能沿用包住骨干的 `no_grad()`。

数据增强利用“某些输入变化应保留标签”的任务假设。材料分类中，适度翻转或光照扰动可能保留“金属”标签；裁剪掉整个物体则可能破坏标签。机器人动作或位姿任务中，翻转画面会改变左右方向和几何关系，动作标签与标定也需要相应处理，不能直接复制分类增强配置。

**结果与解释：** 固定特征训练、微调与增强针对不同问题，是否改善要用相同划分与指标判断。本案例比较固定特征训练与分类增强，配置和指标见[实验结果](results.md)。

## 三轮训练与测试结果

基础实验有 984 张训练图片，batch size 32，保留尾批：每轮 `ceil(984/32)=31` 次更新，三轮共 **93 次更新**。这是依据配置和训练循环的静态计数。

两组实验均使用种子 42、SGD 学习率 0.01，训练三轮，按最低验证 loss 保存权重，均选中第三轮。

| 方案 | 验证准确率（211 张） | 测试准确率（212 张） | 测试正确张数 |
| --- | ---: | ---: | ---: |
| 未增强基线 | 94.31% | 87.26% | 185 |
| 水平翻转、轻微亮度/对比度增强 | 92.89% | 87.74% | 186 |

来源：[基线训练记录](outputs/runs/20260914_164706_687481/history.json)、[基线测试指标](outputs/runs/20260914_164706_687481/test_evaluation/test_metrics.json)、[增强训练记录](outputs/runs/20260921_augmented/history.json)、[增强测试指标](outputs/runs/20260921_augmented/test_evaluation/test_metrics.json)。

**结果与解释：** 增强版只多预测对一张测试图片，不能据此断言增强稳定改善泛化；验证准确率反而下降。准确率与 loss 衡量方式不同，最低验证 loss 不保证最高验证准确率。两组测试结果已经查看，不能再反复据此调参而仍把同一测试集称为全新独立评估。

## 推理与微调的边界

[predict.py](src/predict.py)加载训练 checkpoint、恢复固定预处理并输出三类 softmax 分数。运行时需要对应权重文件。

输入杯子、键盘等三类之外的物品，模型仍可能给某一类很高的分数。分数总和为 1 不代表可靠性已校准，分类结果也不能直接充当抓取位置。

微调是进一步允许部分或全部预训练参数更新；它是按任务需要选择的方法，不是完成迁移学习必须补做的一步。当前历史训练只更新分类头，不标记为骨干微调完成。
