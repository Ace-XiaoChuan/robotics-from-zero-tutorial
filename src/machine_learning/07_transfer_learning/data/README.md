## 推荐：TrashNet

[作者仓库与数据说明](https://github.com/garythung/trashnet)提供已经标注的生活废弃物图片，共 2,527 张、6 类，缩放版图片尺寸为 512 × 384：

| 标签 | 中文含义 | 图片数 |
| --- | --- | --- |
| glass | 玻璃 | 501 |
| paper | 纸张 | 594 |
| cardboard | 纸板 | 403 |
| plastic | 塑料 | 482 |
| metal | 金属 | 410 |
| trash | 其他垃圾 | 137 |

建议先选 `paper`、`cardboard`、`metal` 三类，共 **1,407 张**。规模较小，适合先体验完整流程；纸张与纸板之间的混淆也可以作为错误分析的素材。这是本项目的入门建议，并非作者规定的分类组合。

标签就是每张图片对应的正确类别。原始项目已提供分类数据，后续用代码读取类别即可，不需要重新逐张标注。下载入口见作者 README 的 Dataset 部分；项目可以只使用图片，用我们自己的 PyTorch 代码学习。

## 使用时理解两个局限

- 作者是在白色背景板上拍摄物品的，因此该数据上的成绩不能直接代表杂乱桌面或摄像头场景中的效果。
- 标签描述的是材料类别，不是当地垃圾投放规则；本周任务是图片分类练习。

## 划分原则与当前实施

先检查重复和近似图片。如果能识别同一个物品或同一拍摄组，应把它们放在同一个集合里；不能只依靠随机打乱保证没有泄漏。

在这个前提下，尽量保持各类比例，按约 70% / 15% / 15% 划分训练、验证和测试集，并保存划分记录。训练集用于学习，验证集用于选择设置，测试集用于最终评估。数据增强只用于训练集，并在划分之后进行。
