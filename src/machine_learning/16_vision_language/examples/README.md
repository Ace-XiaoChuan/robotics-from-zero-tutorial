## 核对范围

程序完成 8 组检查：softmax 概率和共同平移不变性；余弦及比例缩放；对比损失的正确配对、反配对和行列交换；token 向量生成 Q/K/V、注意力及 key/value 同步重排；连接器投影与 patch 计数；回答 loss；单层 LoRA 参数；像素反投影及重投影。

结果显示 checks_passed=8。对比损失还用非对称矩阵检查双向平均的转置不变性，避免只靠对称例子掩盖计算方向错误。相机点重新投影回原像素，核对单位与公式方向。

程序要求小型有限数值输入，不提供自动求导、训练循环、tokenizer、视觉编码器或网络生成。几何例子也未估计真实标定或深度误差，不能证明机器人任务成功。
