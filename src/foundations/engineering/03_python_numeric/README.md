# S0 · 单元 03：Python 与数值数据

本文行数：59行，预期阅读时长：3分钟

**一句话回忆：Python 负责表达处理流程，NumPy 数组负责表达有形状、有单位的数据；看到结果先核对形状、顺序和单位。**

## 速记

- `list` 适合保存一组对象；NumPy `ndarray` 适合批量数值计算，`shape` 描述每一维长度。
- `a @ b` 是矩阵乘法，`a * b` 是逐元素乘法；两者都能运行，但含义完全不同。
- 机器人数据的关节顺序、角度单位（通常是 rad）、坐标系和时间戳必须由接口约定，不能凭数组下标猜。
- 函数输入输出写清楚：例如输入 `q.shape == (7,)`，输出位姿矩阵 `T.shape == (4, 4)`。

## 例子：从关节角度得到一个简单统计量

**条件 / 输入：** 一个 7 自由度机械臂的关节角度向量，顺序固定为 `joint_1 ... joint_7`，单位为 rad：

```python
import numpy as np

q = np.array([0.0, 0.5, -0.5, 1.0, 0.2, -0.2, 0.1])
mean_q = q.mean()
max_abs_q = np.abs(q).max()
```

**结果：** `q.shape` 为 `(7,)`；`mean_q` 约为 `0.157 rad`，`max_abs_q` 为 `1.0 rad`。

**解释：** `(7,)` 表示一维向量，不是 7×1 矩阵。`mean()` 和 `max()` 不会改变关节顺序；它们只提供检查状态范围的摘要。若把角度误当成度数，数值和限位判断会相差约 57.3 倍。

结果依据：数值由上述代码静态推导，可用 NumPy 直接复核；不是机器人实测状态。

## 例子：形状决定运算含义

```python
R = np.eye(3)                 # (3, 3)，旋转矩阵示意
p = np.array([0.1, 0.0, 0.2]) # (3,)，位置，单位 m
p_rotated = R @ p             # (3,)
scaled = R * 2                # (3, 3)，每个元素乘 2
```

`R @ p` 才是矩阵对向量的变换；`R * 2` 只是逐元素缩放，结果不再是合法旋转矩阵。这里的 `R` 是教学示意，未表示某个真实坐标系之间的变换。

## 遇到问题时查

| 现象 | 原因或检查方向 |
| --- | --- |
| `IndexError` 或关节数量不符 | 检查 `shape`、关节顺序和接口版本；不要只看打印出的部分数值 |
| 矩阵乘法报维度错误 | 对照每个数组的 `shape`；`(3, 3) @ (3,)` 可以，而 `(3, 3) @ (7,)` 不可以 |
| 数值看起来大约 57 倍 | 可能混用了 degree 和 radian；确认 API 约定 |
| 广播后结果“能运行但不对” | 检查是否意外把 `(N, 1)` 与 `(N,)` 组合；先打印形状再解释结果 |
| 结果无法复现 | 记录输入文件、随机种子、Python/NumPy 版本和单位；不要只保存最终数字 |
