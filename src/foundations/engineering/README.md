# S0：工程与实验基础

本文行数：26行，预期阅读时长：2分钟

这里提供便于快速复习的工程基础。对应 [学习路线 S0](../../../doc/learning-roadmap.md#s0)。每个单元用少量要点、例子和结果解释帮助找回印象，无需执行代码；语法、配置和常规实现交给 AI 协助。

## 单元安排

| 顺序 | 单元 | 状态 |
| --- | --- | --- |
| 01 | [终端、路径与环境](01_shell_paths/README.md) | 路径选择例子与排错速查 |
| 02 | [Git 与文件管理](02_git/README.md) | 改动摘要、提交状态例子与协作速查 |
| 03 | [Python 与数值数据](03_python_numeric/README.md) | 速记、形状与单位例子 |
| 04 | [C++ 与构建](04_cpp_build/README.md) | `g++`、CMake 与 `colcon` 的构建边界和排错 |
| 05 | [调试与错误定位](05_debugging/README.md) | 日志、最小复现、回溯和错误分类 |
| 06 | [配置与实验复现](06_reproducibility/README.md) | 参数边界、环境记录与可解释复现 |

单元 01 解释启动位置和输入路径；单元 02 帮助看懂 agent 的改动与保存状态；单元 04 连接独立 C++ 程序、CMake target 与 ROS 2 工作区构建；单元 05、06 用于定位失败原因和保存可复现实验条件。

## 怎样使用

1. 看速记要点，结合例子的结果恢复印象。
2. 有疑问再查速查表，或让 AI 针对具体问题解释。
3. 只有例子难以说明的问题才考虑实际操作；无需完成一套练习后再继续机器人主线。

前三个单元均可直接阅读。配套代码和命令作为需要时的实现参考，相关知识也可用于 [Lesson 1](../../lesson1/README.md) 的整理与复现。
