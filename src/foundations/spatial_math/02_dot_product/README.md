# 02：点积——沿一个方向有多少分量

本文行数：109行，预期阅读时长：4分钟

**点积把两个向量变成一个数。与单位方向做点积时，这个数就是沿该方向的有符号分量。**

## 先看怎么算

这里讨论实数向量，点积也叫内积，写成 $a\cdot b$ 或 $a^Tb$。`T` 表示转置：将列向量变成行向量，行乘列得到一个数。

$$
a\cdot b=a_xb_x+a_yb_y+a_zb_z
$$

规则就是：**对应分量相乘，再把乘积相加。** 例如无量纲向量 `[1, 2, 0]` 和 `[3, 4, 0]`：

$$
1\times3+2\times4+0\times0=11
$$

NumPy 中，两个形状为 `(3,)` 的数组用 `a @ b` 得到这个标量；`a * b` 只得到逐元素乘积 `[3, 8, 0]`，还没有求和。

## 例子 1：沿 x 方向还差多少

**输入：** 在右手坐标系 A 中，目标位移 `d = [0.3, 0.4, 0] m`，x 轴单位方向 `ex = [1, 0, 0]`，无量纲。

$$
d\cdot e_x=0.3\times1+0.4\times0+0\times0=0.3\ \mathrm{m}
$$

把位移箭头垂直投到 x 轴上，就像在轴上留下一个“影子”：

```text
A 系 xy 平面（示意，单位 m）
y
↑
0.4          ● 目标 (0.3, 0.4)
             │
             │ 垂直投到 x 轴
O────────────●────────→ x
            0.3
```

**结果：** 点积 `0.3 m` 是影子的有符号长度；投影向量是 `0.3 × ex = [0.3, 0, 0] m`。前者是一个数，后者才是箭头。

同理，投到 y 轴得到 `0.4 m`。位移总长度是 `0.5 m`，所以“沿 x 的分量”和“到目标的距离”是不同的量。

## 为什么能看出方向关系

对于非零向量，夹角 $\theta\in[0,\pi]$，点积还可以写成：

$$
a\cdot b=\|a\|\|b\|\cos\theta
$$

若 `b` 是单位方向，$\|b\|=1$，就只剩下 $\|a\|\cos\theta$，正是直角三角形中的有符号投影长度。

| 相对方向 | 点积的符号 | 含义 |
| --- | --- | --- |
| 夹角小于 90° | 正 | 沿指定方向有正分量 |
| 夹角等于 90° | 零 | 在这个方向上没有分量 |
| 夹角大于 90° | 负 | 分量指向指定方向的反向 |

例如 `[-0.3, 0.4, 0] @ ex = -0.3`，表示沿 x 的分量朝 −x。零向量与任何向量点积都为零，但零向量没有方向，不能据此讨论它的夹角。

## 例子 2：方向不沿坐标轴怎么办

**输入：** 仍用 `d = [0.3, 0.4, 0] m`，现在关心 xy 平面中朝右上方 45° 的方向。用无量纲 `v = [1, 1, 0]` 表示，它的长度为 $\sqrt{2}$，不是单位向量。

先归一化：$u=v/\sqrt{2}$。于是沿这个方向的有符号分量为：

$$
s=d\cdot u=\frac{0.3+0.4}{\sqrt{2}}\approx0.495\ \mathrm{m}
$$

再乘方向得到投影向量：

$$
p=s u=[0.35,\ 0.35,\ 0]\ \mathrm{m}
$$

**解释：** 剩余部分 `d − p = [-0.05, 0.05, 0] m` 与 `v` 点积为零，说明余下的位移垂直于所选方向。

如果直接算 `d @ v = 0.7`，结果被 `v` 的长度放大了，不能当成投影长度。省去显式归一化时，投影到非零 `v` 所在直线的公式为：

$$
\mathrm{proj}_v(d)=\frac{d\cdot v}{v\cdot v}v
=\frac{0.7}{2}[1,1,0]=[0.35,0.35,0]\ \mathrm{m}
$$

## 对应代码与易错点

```python
import numpy as np

d = np.array([0.3, 0.4, 0.0])  # A 系位移，m
v = np.array([1.0, 1.0, 0.0])  # 无量纲方向，非零
u = v / np.linalg.norm(v)
s = d @ u                     # 约 0.495 m，标量
projection = s * u             # [0.35, 0.35, 0] m，向量
```

- 点积可以交换顺序：$a\cdot b=b\cdot a$；叉积则不同。
- 点积单位是两个输入单位的乘积：位移与无量纲单位方向点积仍为 m；两个位移点积则为 m²。
- 比较方向时先归一化，否则数值大小也受向量长度影响；不能只凭点积更大就断言夹角更小。

结果依据：教学数值推导，经 NumPy 核对，不是机器人实测。
