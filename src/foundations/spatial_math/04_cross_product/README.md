# 04：叉积——垂直方向、旋转轴与力矩

本文行数：119行，预期阅读时长：5分钟

**三维叉积把两个向量变成一个新向量：方向垂直于两者，大小反映两者张开的程度，也受各自长度影响。**

## 先理解方向：四指从第一个向量弯向第二个

看到 **`a × b`，就按“从 a 到 b”判断方向：右手四指从 a 弯向 b，伸出的拇指指向结果。** 这里先假设两个向量非零，而且既不同向也不反向。

具体做法：把两个箭头的起点放在一起，让右手四指先沿 **a** 的方向，再沿小于 180° 的夹角弯向 **b**。拇指与四指弯曲所在的平面垂直，它指的就是 **a × b** 的方向。

### 看纸上的两个箭头

假设你正对纸面，a 向右，b 向上。两个箭头都在纸面内，叉积则垂直纸面：

```text
         b（第二个向量）
         ↑
         │
         O──────→ a（第一个向量）

    a × b：⊙ 朝向你，穿出纸面
    b × a：⊗ 远离你，穿入纸面
```

`⊙` 像看见箭头的尖端，表示朝向你；`⊗` 像看见箭尾，表示远离你。

**先算 `a × b`：** 四指从“向右”弯向“向上”，在你眼里是逆时针，拇指朝向你。**再算 `b × a`：** 四指从“向上”弯向“向右”，变成顺时针，拇指远离你。两个输入箭头都没变，只是交换计算顺序，结果方向就反了。

### 这和右手坐标系有什么关系

**坐标系先规定 x、y、z 三条轴朝哪里；叉积再根据 a、b 的顺序确定结果方向。** 本教程使用右手坐标系 A，分量按 `[x, y, z]` 排列；叉积不会重新确定这三条轴。

在刚才的纸面例子中，若把向右定为 +x、向上定为 +y，那么右手坐标系的 +z 就朝向你。因此，取单位向量 `ex = [1, 0, 0]`、`ey = [0, 1, 0]` 时：

$$
e_x\times e_y=e_z,\qquad e_y\times e_x=-e_z
$$

任意两个不平行向量都按同一手势判断，不要求它们沿 x、y 轴，结果也不一定沿 z 轴；它总垂直于这两个向量所在的平面。交换顺序满足 $a\times b=-(b\times a)$，这与点积不同。

**例外：** 两向量同向、反向，或其中一个为零向量时，叉积为零向量，没有方向，此时不再用手势寻找一个结果方向。

## 再看大小：平行时为零，垂直时最大

对于两个非零向量，夹角 $\theta\in[0,\pi]$：

$$
\|a\times b\|=\|a\|\|b\|\sin\theta
$$

如果将两个位移作为平行四边形的相邻边，那么底边长度是 $\|a\|$，高是 $\|b\|\sin\theta$；它们的乘积就是面积，也是叉积的大小。

| 夹角 | 叉积大小 | 原因 |
| --- | --- | --- |
| 0° 或 180° | 0 | 两个箭头共线，张不出面积 |
| 90° | $\|a\|\|b\|$ | 固定两向量长度时，面积最大 |
| 其他角度 | $\|a\|\|b\|\sin\theta$ | 使用垂直于底边的高度计算 |

例如 `a = [2, 0, 0] m`、`b = [0, 3, 0] m`，叉积为 `[0, 0, 6] m²`：方向是 +z，大小是矩形面积 6 m²。它不是一个位置坐标，虽然同样有三个分量。

## 真正计算时怎样展开

三维叉积的分量公式为：

$$
a\times b=
\begin{bmatrix}
a_yb_z-a_zb_y\\
a_zb_x-a_xb_z\\
a_xb_y-a_yb_x
\end{bmatrix}
$$

代入上面的 `a = [2, 0, 0]`、`b = [0, 3, 0]`：

- x 分量：`0×0 − 0×3 = 0`。
- y 分量：`0×0 − 2×0 = 0`。
- z 分量：`2×3 − 0×0 = 6`。

```python
import numpy as np

a = np.array([2.0, 0.0, 0.0])  # A 系，m
b = np.array([0.0, 3.0, 0.0])  # A 系，m
c = np.cross(a, b)              # [0, 0, 6]，m²
axis = c / np.linalg.norm(c)    # [0, 0, 1]，无量纲
```

## 机器人里怎么用

**旋转轴方向：** 对不平行的非零方向 `a`、`b`，将 `a × b` 归一化，可得到从 `a` 转到 `b` 的较小夹角旋转的轴方向。叉积大小含有 `sinθ`，不是角度本身；不能把上例的 `6` 读成 6 rad。

两个方向反平行时，需要转 180°，但叉积仍为零。这时有多条可选的垂直旋转轴，不能除以零强行归一化。同向时无需旋转；输入为零向量时，方向本身没有定义。

**力矩：** 假设从转轴上一参考点到施力点的力臂是 `r = [0.2, 0, 0] m`，施加的力是 `F = [0, 10, 0] N`，都在 A 系中：

$$
\tau=r\times F=[0,0,2]\ \mathrm{N\cdot m}
$$

结果表示绕 +z 的力矩为 2 N·m。从 +z 看，它有使物体逆时针转动的趋势。力矩大小等于 `0.2 m × 10 N`，因为这里力与力臂垂直。若改成沿力臂的力 `[10, 0, 0] N`，叉积为零，对这个参考点没有力矩。实际是否转动还取决于其他力矩与约束。

## 与点积放在一起记

| 对比 | 点积 $a\cdot b$ | 叉积 $a\times b$ |
| --- | --- | --- |
| 输出 | 一个数 | 三维向量 |
| 几何含义 | 沿另一个方向的分量关系 | 垂直方向与张开的面积 |
| 非零输入时结果为零 | 垂直 | 平行或反平行 |
| 交换顺序 | 不变 | 反号 |
| NumPy 三维数组 | `a @ b` | `np.cross(a, b)` |

两种运算的单位都是输入单位的乘积。只有与无量纲单位方向点积，才直接得到原向量单位下的投影分量。
