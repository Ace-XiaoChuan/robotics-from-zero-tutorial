# 09：SVD、伪逆与阻尼最小二乘

本文行数：181行，预期阅读时长：10分钟

**伪逆处理非方阵或秩不足的线性求解；阻尼用一定残差换取较小、较稳定的解。它们不能让不可达方向变得可达，也不能替代运动限位。**

## 先分清：雅可比与雅可比伪逆

- **雅可比矩阵 J**：在当前机械臂姿态下，把“关节怎么动”映射为“末端怎么动”，速度关系为 `x_dot = J(q) q_dot`。反过来，从期望末端速度求关节速度，是在求解这个方程，并不是直接乘 J。
- **雅可比伪逆 J⁺**：用于反向求解，`q_dot = J⁺ x_dot_期望`；能满足要求时，选关节速度范数最小的解；不能完全满足时，先使末端速度残差平方和最小，再从中选关节速度范数最小的解。

**满秩不等于可逆：普通逆要求矩阵既是方阵又满秩，伪逆不只用于秩不足的情况。**

| J 的情况 | 普通逆与伪逆 |
| --- | --- |
| 方阵且满秩 | 普通逆存在，且 `J⁺ = J⁻¹` |
| 非方阵但满秩 | 没有普通逆，可以用伪逆求解 |
| 不满秩 | 没有普通逆，仍可用伪逆求最小二乘解 |

例如，七关节机械臂的末端速度用 6 个分量表示（3 个线速度、3 个角速度），J 就是 `6×7`；即使秩为 6，也没有普通逆。同一个末端速度可以由多种关节速度实现，伪逆给出其中范数最小的一组。各速度分量须与 J 的参考坐标系及排列顺序一致；线速度单位为 m/s、角速度及转动关节速度为 rad/s，混合单位时的“最小”需结合尺度或权重理解。

下面改用小位移关系 `Delta p ≈ J Delta q` 讲例子，求解思路相同，但关节增量不是关节速度，且这一位移关系只在当前姿态附近近似成立。

## 速记要点

- 本章用局部线性关系 `Delta p ≈ J Delta q`：`Delta p` 是任务位移，`Delta q` 是关节角增量。
- `J` 形状 `(m,n)`，任务有 m 个分量、关节有 n 个自由度。例子只用位置任务，J 的单位为 m/rad。
- 伪逆 `J⁺` 形状 `(n,m)`；`Delta q=J⁺ Delta p` 给出最小二乘解中的最小欧氏范数解。
- 这里的“最小”取决于变量尺度；含转动与移动关节时，应先定义尺度或权重，不能把 rad 与 m 直接比较。

## 例子 1：两个关节共同完成一个方向的位移

假设某局部位置处 `J=[1,1] m/rad`，希望沿任务轴移动 `Delta p=0.2 m`，即 `Delta q1+Delta q2=0.2 rad`。

解有无穷多组：`[0.2,0]`、`[0,0.2]`、`[0.1,0.1] rad` 都满足方程。伪逆选择 `[0.1,0.1] rad`，其平方范数为 `0.02 rad²`，小于前两组的 `0.04 rad²`。

```python
import numpy as np

J = np.array([[1., 1.]])
dp = np.array([0.2])
dq = np.linalg.pinv(J) @ dp  # [0.1, 0.1] rad
```

**解释：** 对任意角度 a，加上 `[a,-a]` 不改变线性化的末端位移，因为 `J @ [a,-a]=0`。这就是本例的零空间；它不保证有限运动后仍保持末端不动，真实机械臂需要持续更新 Jacobian。

## SVD 把“哪个方向难以运动”显示出来

**SVD（奇异值分解）是把一个复杂的雅可比拆开，看清“哪些关节配合方式能让末端动得多，哪些动得少”。** 它不是新的运动规律，而是同一个 J 的另一种写法。

先看一个已经拆得很清楚的简化模型：`J=diag(1,0.01) m/rad`(对角矩阵)。它表示两个关节分别影响末端的两个位置方向，当前局部关系为：

- 第一方向：`Delta p1 = 1 × Delta q1`，关节改变 `0.01 rad`，末端移动 `0.01 m`。
- 第二方向：`Delta p2 = 0.01 × Delta q2`，关节同样改变 `0.01 rad`，末端只移动 `0.0001 m`。

**同样大小的关节变化，第二方向的末端位移只有第一方向的百分之一。** 这里的 1 和 0.01 就是两个**奇异值 σ**，表示对应方向上的运动传递比例，单位为 m/rad。这些结果由局部线性模型推导，并非实际运动测量。

真实机械臂通常不是“一个关节只管一个方向”，而是多个关节一起影响末端。SVD 会找出一些互相正交的“关节配合方式”，以及各自对应的末端运动方向，让复杂的 J 也能像上面那样逐个方向分析：

| 分解中的部分 | 在机械臂中怎么理解 |
| --- | --- |
| V 的列 | 关节配合方式，例如几个关节按一定比例同向或反向运动；不一定是单独一个关节 |
| U 的列 | 对应的末端运动方向；不一定与原来的 x、y、z 轴重合 |
| Sigma 中的奇异值 | 每种关节配合方式让末端动起来的比例；越小，沿对应末端方向运动越困难 |

公式写成 `J = U Sigma V.T`。从右往左理解：**V.T 把关节增量分解到这些配合方式上 → Sigma 按各自比例缩放 → U 把结果组合成末端位移。** 在上面的对角矩阵例子里，U 和 V 都可以取单位矩阵，无需改变方向，只剩两个比例。

这也解释了伪逆为什么会产生很大的关节变化：反向求解时，要把期望末端位移**除以对应的奇异值**。若第二方向也想移动 `0.01 m`，线性模型要求 `0.01 / 0.01 = 1 rad` 的关节变化；奇异值越小，反算出的变化越大，也越容易放大该方向上的测量噪声。

若奇异值为零，这种关节配合方式在当前线性模型中不产生末端运动，不能通过除以零来反求；伪逆将对应的倒数系数设为零。实际数值实现还会用阈值把足够小的奇异值当作零处理。下一节的阻尼则用更温和的方式抑制小奇异值带来的放大。

本例最大与最小奇异值之比为 `1/0.01=100`，称为 2-范数条件数，用于判断求解对扰动的敏感程度。比较奇异值或条件数前，要统一单位和尺度；混合位置与姿态任务时，未经归一化的比较可能误导。

### 具体分解一次：两个关节同时影响两个方向

取一个教学用的局部位置雅可比，关节顺序为 `[q1,q2]`，末端位移按同一固定坐标系的 `[p1,p2]` 排列：

$$
J=\begin{bmatrix}2&1\\1&2\end{bmatrix}\ \mathrm{m/rad}
$$

也就是 `Delta p1 = 2 Delta q1 + Delta q2`、`Delta p2 = Delta q1 + 2 Delta q2`。两个关节都影响两个方向，不能直接把对角线上的 2、2 当作奇异值。

**第一步：找出关节的两种配合方式。** 先省略单位计算 `J.T @ J`：

$$
J^T J=\begin{bmatrix}5&4\\4&5\end{bmatrix}
$$

这个矩阵乘 `[1,1]` 得到 `9[1,1]`，乘 `[1,-1]` 得到 `1[1,-1]`。这两个方向乘完后方向不变，只被缩放，叫作特征向量，对应特征值为 9 和 1。将向量长度归一化为 1，作为 V 的两列：

$$
v_1=\frac{1}{\sqrt{2}}\begin{bmatrix}1\\1\end{bmatrix},\qquad
v_2=\frac{1}{\sqrt{2}}\begin{bmatrix}1\\-1\end{bmatrix}
$$

它们分别表示**两个关节等量同向动**和**等量反向动**。这里“方向”指关节角增量的组合，不是机械臂在空间中的朝向。

**第二步：求传递比例和末端方向。** 奇异值是 `J.T @ J` 的特征值的平方根，所以 `sigma1=3 m/rad`、`sigma2=1 m/rad`。再用 `u_i = J v_i / sigma_i` 得到对应的末端单位方向；本例恰好有 `u1=v1`、`u2=v2` 的数值形式。因此，一组完整分解为：

$$
U=\frac{1}{\sqrt{2}}\begin{bmatrix}1&1\\1&-1\end{bmatrix},\qquad
\Sigma=\begin{bmatrix}3&0\\0&1\end{bmatrix}\ \mathrm{m/rad},\qquad
V^T=\frac{1}{\sqrt{2}}\begin{bmatrix}1&1\\1&-1\end{bmatrix}
$$

三者相乘正好还原 J。U、V 本身无量纲；本例 U 与 V 数值相同是这个矩阵的特性，不能推广到所有雅可比。

**第三步：用实际数值理解分解结果。** 在这个局部线性模型中：

| 关节增量 / rad | 预测末端位移 / m | 位移范数与关节增量范数之比 |
| --- | --- | --- |
| `[0.01,0.01]`（同向） | `[0.03,0.03]` | `3 m/rad`，对应第一个奇异值 |
| `[0.01,-0.01]`（反向） | `[0.01,-0.01]` | `1 m/rad`，对应第二个奇异值 |

两组关节增量的大小相同，但第一组产生的末端位移大小是第二组的 3 倍。**SVD 找出的就是这两种配合方式、对应的末端方向，以及 3 和 1 这两个传递比例。**

下面的 NumPy 代码可核对奇异值和矩阵重建；`Vt` 是 V 的转置，`np.diag(sigma)` 将奇异值数组放到对角线上：

```python
J = np.array([[2., 1.], [1., 2.]])
U, sigma, Vt = np.linalg.svd(J)
print(sigma)                                  # [3. 1.]
print(np.allclose(U @ np.diag(sigma) @ Vt, J)) # True
```

软件输出的某一对 `u_i`、`v_i` 可能同时与手算相差一个负号，仍是同一有效分解，因为两个负号在重建时抵消。以上是教学模型的数值推导；实际计算 SVD 直接用数值库，不必先构造 `J.T @ J`。

## 例子 2：小末端位移为何要求很大的关节变化

仍用 `J=diag(1,0.01) m/rad`，目标 `Delta p=[0.01,0.01] m`：

| 求解方式 | 关节增量 / rad | 线性模型预测位移 / m |
| --- | --- | --- |
| 普通伪逆 | `[0.01,1.0]` | `[0.01,0.01]` |
| 阻尼最小二乘，lambda=0.1 m/rad | `[0.00990099,0.00990099]` | `[0.00990099,0.00009901]` |

普通伪逆为了在第二方向移动 1 cm，要求第二关节改变 1 rad，约 57.3°。这已经不是很小的局部修正，可能使线性近似失效。

阻尼求解的是：

$$
\min_{\Delta q}\ \|J\Delta q-\Delta p\|^2+
\lambda^2\|\Delta q\|^2
$$

$$
\Delta q=(J^TJ+\lambda^2 I)^{-1}J^T\Delta p
$$

本例 lambda 单位 m/rad，使两项都具有 m² 单位。若先做变量和残差归一化，lambda 才可按无量纲参数使用。实现时使用线性求解，不显式求逆：

```python
J = np.diag([1., 0.01])
dp = np.array([0.01, 0.01])
damping = 0.1
dq = np.linalg.solve(J.T @ J + damping**2 * np.eye(2), J.T @ dp)
```

**结果与解释：** 阻尼压低了弱方向的关节变化，也留下约 `0.00990099 m` 的第二方向任务误差。它是明确的折中，不是同时获得“零误差”和“很小的关节变化”。上述数值是线性模型结果，不是实际机械臂运动测量。

在 SVD 方向上，阻尼把 `1/sigma` 换成 `sigma/(sigma²+lambda²)`。当 sigma 很小时，增益不再无限变大。lambda 越大通常越抑制解的幅度，但也更难精确匹配目标。

上面的正规方程写法用于小型教学例子；对数值要求更高的问题，可用 SVD，或对增广系统 `[J; lambda I] Delta q ≈ [Delta p; 0]` 调用 `lstsq`，避免显式形成正规方程。

## 例子 3：完全不可动的方向

若 `J=diag(1,0)`，目标仍是 `[0.01,0.01] m`，伪逆给出 `Delta q=[0.01,0] rad`，预测位移为 `[0.01,0] m`。第二方向仍差 1 cm，因为当前线性模型根本没有这个方向的运动能力。

这只能说明当前局部方向受限；是否可以换一个构型后到达，需要完整运动学与规划分析。

## 易错点

- 阻尼不是关节限位，也不能保证避碰；这些条件需要作为约束处理。
- 伪逆中的奇异值截断阈值与阻尼参数不是同一机制；默认阈值也不是机器人安全阈值。
- 奇异附近有问题时，先核对尺度、参考系、关节顺序和 Jacobian，再考虑增大阻尼。
- 位置修正问题中的 J 单位为 m/rad；速度关系 `v=J q_dot` 则将 rad/s 映射成 m/s，不能把解出的角增量不经时间处理直接当速度。
