# 09：SVD、伪逆与阻尼最小二乘

本文行数：90行，预期阅读时长：5分钟

**伪逆处理非方阵或秩不足的线性求解；阻尼用一定残差换取较小、较稳定的解。它们不能让不可达方向变得可达，也不能替代运动限位。**

## 速记要点

- 本章用局部线性关系 `Delta p ≈ J Delta q`：`Delta p` 是任务位移，`Delta q` 是关节角增量。
- `J` 形状 `(m,n)`，任务有 m 个分量、关节有 n 个自由度。例子只用位置任务，J 的单位为 m/rad。
- 伪逆 `J⁺` 形状 `(n,m)`；`Delta q=J⁺ Delta p` 给出最小二乘解中的最小欧氏范数解。
- 这里的“最小”取决于变量尺度；含转动与移动关节时，应先定义尺度或权重，不能把 rad 与 m 直接比较。

## 例子 1：两个关节共同完成一个方向的位移

假设某局部位置处 `J=[1,1] m/rad`，希望沿任务轴移动 `Delta p=0.2 m`，即 `Delta q1+Delta q2=0.2 rad`。

解有无穷多组：`[0.2,0]`、`[0,0.2]`、`[0.1,0.1] rad` 都满足方程。伪逆选择 `[0.1,0.1] rad`，其平方范数为 `0.02 rad²`，小于前两组的 `0.04 rad²`。

```python
import numpy as np

J = np.array([[1., 1.]])
dp = np.array([0.2])
dq = np.linalg.pinv(J) @ dp  # [0.1, 0.1] rad
```

**解释：** 对任意角度 a，加上 `[a,-a]` 不改变线性化的末端位移，因为 `J @ [a,-a]=0`。这就是本例的零空间；它不保证有限运动后仍保持末端不动，真实机械臂需要持续更新 Jacobian。

## SVD 把“哪个方向难以运动”显示出来

奇异值分解写成 `J=U Sigma V.T`。U 和 V 的正交方向分别对应任务空间与关节空间，Sigma 中的非负奇异值表示沿对应关节组合运动时，任务变化的放大比例。

对非零奇异值，伪逆使用增益 `1/sigma`；零奇异值不能取倒数，实际数值实现会根据阈值决定保留哪些方向。

例如 `J=diag(1,0.01) m/rad`：第二方向的传递能力只有第一方向的百分之一。两奇异值为 1 和 0.01，条件数为 100。条件数需结合单位、尺度和噪声解释；混合位置与姿态任务时，未经归一化的比较可能误导。

## 例子 2：小末端位移为何要求很大的关节变化

仍用 `J=diag(1,0.01) m/rad`，目标 `Delta p=[0.01,0.01] m`：

| 求解方式 | 关节增量 / rad | 线性模型预测位移 / m |
| --- | --- | --- |
| 普通伪逆 | `[0.01,1.0]` | `[0.01,0.01]` |
| 阻尼最小二乘，lambda=0.1 m/rad | `[0.00990099,0.00990099]` | `[0.00990099,0.00009901]` |

普通伪逆为了在第二方向移动 1 cm，要求第二关节改变 1 rad，约 57.3°。这已经不是很小的局部修正，可能使线性近似失效。

阻尼求解的是：

$$
\min_{\Delta q}\ \|J\Delta q-\Delta p\|^2+
\lambda^2\|\Delta q\|^2
$$

$$
\Delta q=(J^TJ+\lambda^2 I)^{-1}J^T\Delta p
$$

本例 lambda 单位 m/rad，使两项都具有 m² 单位。若先做变量和残差归一化，lambda 才可按无量纲参数使用。实现时使用线性求解，不显式求逆：

```python
J = np.diag([1., 0.01])
dp = np.array([0.01, 0.01])
damping = 0.1
dq = np.linalg.solve(J.T @ J + damping**2 * np.eye(2), J.T @ dp)
```

**结果与解释：** 阻尼压低了弱方向的关节变化，也留下约 `0.00990099 m` 的第二方向任务误差。它是明确的折中，不是同时获得“零误差”和“很小的关节变化”。上述数值是线性模型结果，不是实际机械臂运动测量。

在 SVD 方向上，阻尼把 `1/sigma` 换成 `sigma/(sigma²+lambda²)`。当 sigma 很小时，增益不再无限变大。lambda 越大通常越抑制解的幅度，但也更难精确匹配目标。

上面的正规方程写法用于小型教学例子；对数值要求更高的问题，可用 SVD，或对增广系统 `[J; lambda I] Delta q ≈ [Delta p; 0]` 调用 `lstsq`，避免显式形成正规方程。

## 例子 3：完全不可动的方向

若 `J=diag(1,0)`，目标仍是 `[0.01,0.01] m`，伪逆给出 `Delta q=[0.01,0] rad`，预测位移为 `[0.01,0] m`。第二方向仍差 1 cm，因为当前线性模型根本没有这个方向的运动能力。

这只能说明当前局部方向受限；是否可以换一个构型后到达，需要完整运动学与规划分析。

## 易错点

- 阻尼不是关节限位，也不能保证避碰；这些条件需要作为约束处理。
- 伪逆中的奇异值截断阈值与阻尼参数不是同一机制；默认阈值也不是机器人安全阈值。
- 奇异附近有问题时，先核对尺度、参考系、关节顺序和 Jacobian，再考虑增大阻尼。
- 位置修正问题中的 J 单位为 m/rad；速度关系 `v=J q_dot` 则将 rad/s 映射成 m/s，不能把解出的角增量不经时间处理直接当速度。
