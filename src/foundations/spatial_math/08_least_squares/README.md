# 08：最小二乘、残差与加权

本文行数：94行，预期阅读时长：5分钟

## 先理解概念

- **残差（residual）**：模型预测值与实际观测值之间的差。本篇约定为“预测减观测”。例如，沿同一坐标轴，预测位置是 `1.00 m`，测量位置是 `0.98 m`，残差就是 `+0.02 m`。它反映预测与观测的偏差，不一定是与真实值的偏差。
- **最小二乘（least squares）**：一种确定模型参数的方法，使所有残差的**平方和最小**，让模型整体上尽量贴近观测。使用平方可以避免正负残差相互抵消。
- **标准差（standard deviation）**：表示各次测量值围绕自身平均值的分散程度，标准差越小，测量值越集中；越大，越分散。

例如，多次测量同一个静止目标的位置，用最小二乘估计其固定位置；当每次测量权重相同时，结果就是这些测量值的平均数。下面的例子 1 给出具体计算。

**测量或方程无法同时精确满足时，最小二乘寻找使残差平方和最小的参数；得到一个最优数值，并不意味着模型和数据一定正确。**

## 速记要点

- 线性问题写成 `A x ≈ b`：`A` 形状为 `(m,n)`，未知参数 `x` 为 `(n,)`，观测 `b` 为 `(m,)`。
- 本章残差定义为 `r = A x - b`，是“模型预测减观测”；与控制中“目标减实际”的符号约定不同。
- 普通最小二乘求 `min ||A x - b||²`。相加的残差必须有可比较的单位与尺度。
- `m > n` 不保证解唯一；还需要 A 的列线性无关。是否能唯一确定参数，要看数据提供的信息。
- 数值实现优先使用 `np.linalg.lstsq` 等求解器，不通过显式求逆实现正规方程。

## 例子 1：三次位置测量互不相同

某静止目标沿同一测量轴的位置测得 `[0.98,1.01,1.01] m`，假设三次测量可信程度相同，估计一个固定位置 x。

$$
\min_x (x-0.98)^2+(x-1.01)^2+(x-1.01)^2
$$

对 x 求导并令其为零，得到 `3x = 0.98+1.01+1.01`，即 `x=1.00 m`。

**结果：** 残差为 `[0.02,-0.01,-0.01] m`，平方和为 `0.0006 m²`，残差均方根为 `sqrt(0.0006/3) ≈ 0.014142 m`。三个观测没有变成一致；估计值只是使它们的平方偏差总和最小。

```python
import numpy as np

A = np.ones((3, 1))
b = np.array([0.98, 1.01, 1.01])
x, _, rank, singular_values = np.linalg.lstsq(A, b, rcond=None)
r = A @ x - b
```

这里 x 形状为 `(1,)`，`rank=1`。显式计算 `r`，比假定求解器返回的残差摘要在所有形状下都非空更稳妥。

## 例子 2：同时估计初始位置和速度

在同一坐标轴上，用匀速模型 `p(t)=a+v t` 拟合观测：时间 `[0,1,2] s`，位置 `[1,2,2] m`。参数顺序固定为 `x=[a,v]`，a 单位 m、v 单位 m/s。

$$
A=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix},\quad
b=\begin{bmatrix}1\\2\\2\end{bmatrix},\quad
x=\begin{bmatrix}7/6\\1/2\end{bmatrix}
$$

A 第二列是以秒计的时间数值；不能只看数组都是浮点数，就忽略两列与参数的单位。

**结果：** 初始位置 `a≈1.166667 m`，速度 `v=0.5 m/s`；预测为 `[1.166667,1.666667,2.166667] m`，残差为 `[1/6,-1/3,1/6] m`，平方和为 `1/6 m²`。

**解释：** 匀速直线无法穿过这三个点。最小二乘允许各点留有残差，而不是强行满足某两点。若残差呈明显规律，需要怀疑匀速假设是否合理，而不只是调求解器。

## 例子 3：两次测量的可信程度不同

两次位置观测为 `[0.98,1.02] m`，已知独立测量误差的标准差为 `[0.02,0.01] m`，假设误差无偏。使用无量纲标准化残差：

$$
\min_x \left(\frac{x-0.98}{0.02}\right)^2+
\left(\frac{x-1.02}{0.01}\right)^2
$$

第二次测量的方差更小，权重为第一次的 4 倍。加权平均为 `x=(0.98+4×1.02)/5=1.012 m`；普通平均则是 `1.000 m`。

**结果与解释：** 估计向更精确的测量靠近，但“更精确”不等于没有系统偏差。标准差必须有测量依据，不能为了得到想要的答案任意设置。

对于独立误差，代码将 A 和 b 的每一行都除以该行标准差，再调用 `lstsq`；只给 b 加权会改变问题。若误差相关，需要协方差模型，不能简单沿用逐行独立权重。

## 正规方程与数值实现的区别

目标函数的驻点满足 `A.T @ A @ x = A.T @ b`。当 A 满列秩时，理论上可写 `x=(A.T @ A)^(-1) @ A.T @ b`，但显式计算逆矩阵不是推荐实现。

在 2-范数下，满列秩 A 的正规方程矩阵满足 `cond(A.T @ A)=cond(A)²`，会放大原有的病态问题。使用 QR 或 SVD 类求解方式更合适；`lstsq` 还能返回秩和奇异值供检查。

非线性模型则先在当前参数附近线性化：`f(x+Delta x)≈f(x)+J Delta x`，再迭代求修正量。局部线性化的来源见[位姿误差](../07_pose_errors/README.md)，机器人 IK 应用见[已有 Jacobian 笔记](../../../kinematics/examples/model_alignment/qpos_jacobian_notes.md)。

## 易错点

- 米与毫米混用会让某类残差权重扩大百万倍，因为目标函数使用平方。
- 平均能减小独立随机噪声的影响，不能自动消除标定偏差。
- 平方项会放大离群点影响；鲁棒损失属于后续扩展，不等于盲目删去不符合预期的数据。
- 小残差不保证参数可辨识：若所有观测时间都是 0，上例中的速度就无法从数据确定。
