# 06：坐标系、齐次变换与变换链

本文行数：79行，预期阅读时长：4分钟

**位姿同时包含朝向和原点位置；齐次变换把旋转和平移放在同一个矩阵里，并通过明确的坐标系下标连接起来。**

## 速记要点

- 本章右手系、列向量，位置单位 m，角度单位 rad。
- `T_A_B` 表示 B 在 A 中的位姿，也把 B 中点坐标变成 A 中点坐标。
- `R_A_B` 是 `3 × 3` 旋转矩阵；`t_A_B` 是 B 原点在 A 中的位置，形状 `(3,)`。
- `p_A = R_A_B @ p_B + t_A_B`；齐次写法使用 `4 × 4` 矩阵和末项为 1 的点。

$$
T_{A\_B}=\begin{bmatrix}R_{A\_B}&t_{A\_B}\\0\ 0\ 0&1\end{bmatrix},
\qquad
\begin{bmatrix}p_A\\1\end{bmatrix}
=T_{A\_B}\begin{bmatrix}p_B\\1\end{bmatrix}
$$

齐次矩阵中旋转无量纲、平移以 m 表示，不应把所有元素解释成同一种物理量。

## 例子：工具系中的点，在基座系哪里

输入 `R_A_B = Rz(pi/2)`、`t_A_B = [1,2,3] m`。工具上的点在 B 中为 `p_B = [1,0,0] m`。

```python
import numpy as np

T_A_B = np.eye(4)
T_A_B[:3, :3] = [[0., -1., 0.], [1., 0., 0.], [0., 0., 1.]]
T_A_B[:3, 3] = [1., 2., 3.]
p_A_h = T_A_B @ np.array([1., 0., 0., 1.])
```

**结果：** `p_A_h = [1,3,3,1]`，实际位置为 `[1,3,3] m`。先把工具系的 +x 方向换成基座系的 +y，得到 `[0,1,0] m`，再加上工具原点位置 `[1,2,3] m`。

如果输入的是位移 `d_B = [1,0,0] m`，齐次末项写 0，结果为 `[0,1,0,0]`。**换原点会改变点的坐标，却不会给位移额外增加一段平移。** 无量纲方向同样只旋转。

## 例子：两个变换怎样串起来

现在改用另一组数据：`T_A_B` 的旋转为 `Rz(pi/2)`、平移为 `[1,0,0] m`；`T_B_C` 的旋转也为 `Rz(pi/2)`、平移为 `[0,2,0] m`。

```mermaid
flowchart LR
    C["C 系点坐标"] -->|"T_B_C"| B["B 系点坐标"]
    B -->|"T_A_B"| A["A 系点坐标"]
```

$$
T_{A\_C}=T_{A\_B}T_{B\_C},\quad
R_{A\_C}=R_{A\_B}R_{B\_C},\quad
t_{A\_C}=R_{A\_B}t_{B\_C}+t_{A\_B}
$$

**结果：** `R_A_C = Rz(pi)`，`t_A_C = [-1,0,0] m`。对 `p_C = [1,0,0] m`，逐段转换得到 `p_B = [0,3,0] m`、`p_A = [-2,0,0] m`；直接用 `T_A_C` 得到相同结果。

**解释：** 第二段平移 `[0,2,0]` 在 B 中，不能直接加到 A 中的 `[1,0,0]`。先旋转后，它在 A 中为 `[-2,0,0]`。矩阵连乘右边先作用，下标相接能帮助检查变换方向。

## 逆变换为什么不能只把平移取负

由 `p_A = R @ p_B + t` 移项得到 `p_B = R.T @ p_A - R.T @ t`，因此：

$$
T_{B\_A}=T_{A\_B}^{-1}
=\begin{bmatrix}R_{A\_B}^{T}&-R_{A\_B}^{T}t_{A\_B}\\0\ 0\ 0&1\end{bmatrix}
$$

使用本章第一个例子的平移 `[1,2,3] m`，逆变换平移为 `[-2,1,-3] m`，不是 `[-1,-2,-3] m`。把 `[1,3,3] m` 变回 B 系，恢复 `[1,0,0] m`。

## 机器人场景中的含义

固定相机观测目标时，可以写 `T_base_target = T_base_camera @ T_camera_target`。眼在手上时，则常写 `T_base_target = T_base_tool @ T_tool_camera @ T_camera_target`。

这些矩阵的来源不同：机械臂 FK 提供工具位姿，手眼标定提供相机安装关系，视觉估计提供目标位姿。移动相机的观测必须与对应时刻的机械臂状态配对；矩阵维度正确不代表时间关系正确。
