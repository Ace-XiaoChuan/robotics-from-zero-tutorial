# 01：向量、范数与单位方向

本文行数：49行，预期阅读时长：2分钟

**向量同时表达大小和方向；范数取出大小，归一化留下方向。**

## 速记

- 本单元使用右手坐标系 A，分量按 `[x, y, z]` 排列。位置和位移单位为 m。
- 位置 `p` 是相对于坐标系原点的坐标；位移 `d = p_goal - p_now` 从当前位置指向目标。
- 两个位置相减之前，必须统一坐标系和单位。
- 本单元的范数均指欧氏范数：$\|d\|=\sqrt{d_x^2+d_y^2+d_z^2}$。
- 非零向量的单位方向为 $u=d/\|d\|$，长度为 1、无量纲；零向量没有确定方向，不能归一化。

## 右手坐标系是什么意思

这里的三维直角坐标系由一个原点和互相垂直的 x、y、z 三条轴组成。**“右手”规定的是三条轴正方向的排列关系。** A 只是这套坐标系的名字。

伸出右手，让三个手指互相垂直：**食指指向 +x，中指指向 +y，拇指就指向 +z。** 也可以用右手四指从 +x 沿 90° 的夹角弯向 +y，此时拇指指向 +z。

**例子：** 在纸上画 +x 向右、+y 向上，那么 +z 必须垂直纸面朝向你（穿出纸面）；若 +z 朝纸内，就成了左手坐标系。

“右手”不代表 x 必须向右、z 必须向上。整套坐标系可以任意转动，只要三条轴仍满足上述关系，它就是右手坐标系。之后讲叉积时，这个约定写成：**x 轴单位向量 × y 轴单位向量 = z 轴单位向量**。

## 例子：末端到目标的直线距离

**输入：** A 系中的当前位置 `[0.1, 0.2, 0] m`，目标位置 `[0.4, 0.6, 0] m`。

```python
import numpy as np

p_now = np.array([0.1, 0.2, 0.0])
p_goal = np.array([0.4, 0.6, 0.0])
d = p_goal - p_now
distance = np.linalg.norm(d)
u = d / distance
```

**结果与解释：**

1. 位移 `d = [0.3, 0.4, 0] m`：向 +x 走 0.3 m，向 +y 走 0.4 m。
2. 直线距离为 $\sqrt{0.3^2+0.4^2}=0.5\ \mathrm{m}$；分量相加得到的 0.7 m 是沿两条坐标轴分段走的路程。
3. 单位方向 `u = [0.6, 0.8, 0]`；乘回长度 `0.5 m`，就恢复原位移。

公式中将向量视为列向量；示例里的 NumPy 数组形状是 `(3,)`，不是 `(3, 1)`。

结果依据：教学数值推导，经 NumPy 核对，不是机器人实测。
