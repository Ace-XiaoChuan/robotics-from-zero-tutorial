# 07：位姿误差与局部线性化

本文行数：95行，预期阅读时长：5分钟

**位置误差可以在同一坐标系中直接相减；姿态误差应先求相对旋转。把两者用于求解时，还要统一参考系、分量顺序和尺度。**

## 速记要点

- 世界系记为 W，当前工具系为 C，目标工具系为 D；`T_W_C`、`T_W_D` 均把工具系坐标转换到 W。
- `e_p_W = p_W_D - p_W_C` 是世界系位置误差，单位 m。
- `R_C_D = R_W_C.T @ R_W_D` 是目标相对当前的旋转；其旋转向量在 C 系表达，单位 rad。
- 本章六维排列约定为 `[平移部分, 旋转部分]`。其他库可能采用不同顺序，应核对接口。
- 误差是“还差多少”，速度是“每秒变化多少”；二者之间需要带时间单位的控制增益或求解规则。

## 符号怎样读

本章约定：**前一个下标是参考坐标系，后一个下标是被描述的坐标系。**

| 符号 | 含义 |
| --- | --- |
| W | 世界坐标系，World |
| C | 工具当前的坐标系，Current |
| D | 工具期望到达的坐标系，Desired |
| `p_W_C` | C 系原点在 W 系中的位置，按 `[x,y,z]` 排列，单位 m |
| `R_W_C` | C 系相对于 W 系的朝向，用无量纲的 `3 × 3` 旋转矩阵表示 |

例如，`p_W_C = [1,0,0] m` 表示当前工具原点在世界系的 `x=1、y=0、z=0`；`p_W_D = [1,1,0] m` 则表示目标工具原点的位置。

`Rz(theta)` 表示绕 z 轴按右手正方向旋转 theta。`pi` 是 π，角度用弧度：`pi/2 rad = 90°`，`pi rad = 180°`。因此，本例 `R_W_C = Rz(pi/2)` 时，当前工具 +x 轴指向世界 +y；`R_W_D = Rz(pi)` 时，目标工具 +x 轴指向世界 -x。

记变换方向时，可读成 `v_W = R_W_C @ v_C`：将同一向量的 C 系坐标换成 W 系坐标。若转换的是点的位置，还需加原点平移：`p_W = R_W_C @ p_C + p_W_C`；这里 `p_C`、`p_W` 是同一个点在两系中的坐标。

## 例子：同一位置误差，在世界系与工具系中方向不同

当前工具位置 `p_W_C = [1,0,0] m`、朝向 `R_W_C = Rz(pi/2)`；目标位置 `p_W_D = [1,1,0] m`、朝向 `R_W_D = Rz(pi)`。

| 量 | 计算 | 结果 |
| --- | --- | --- |
| 世界系位置误差 | `p_W_D - p_W_C` | `[0,1,0] m` |
| 当前工具系位置误差 | `R_W_C.T @ e_p_W` | `[1,0,0] m` |
| 相对旋转 | `R_W_C.T @ R_W_D` | `Rz(pi/2)` |
| 当前工具系旋转误差向量 | 相对旋转的轴角向量 | `[0,0,pi/2] rad` |

**结果与解释：** 目标位于世界 +y 方向，而当前工具的 +x 正好指向世界 +y，因此工具系误差沿 +x。这两组位置误差描述同一段位移，不能不换参考系就混用。

本例旋转误差大小为 `pi/2 rad = 90°`。若只求相对旋转角，可用：

$$
\theta=\arccos\left(\operatorname{clip}\left(\frac{\operatorname{tr}(R_{C\_D})-1}{2},-1,1\right)\right)
$$

该式给出 `[0,pi]` 范围内的角度大小，不能单独给出旋转轴或完整有符号误差。`clip` 处理浮点舍入越界；近零和近 pi 的完整旋转向量计算宜使用成熟旋转库。

## 为什么不直接相减欧拉角或四元数

绕同一 z 轴，当前角 `179°`、目标角 `-179°`。直接相减得到 `-358°`，而最短相对转动为 `+2°`。这是角度表示跨过分支边界，不是机器人需要绕一大圈。

四元数 `q` 和 `-q` 表示相同姿态，但数组相减一般不为零；矩阵相减也得到 9 个分量，不是可直接当作三维角速度的量。

## SE(3) 的 log 与“直接拼接误差”有什么区别

先求相对位姿 `T_C_D = inverse(T_W_C) @ T_W_D`，再取刚体变换的对数坐标 `xi = [rho, phi]`。`phi` 是旋转向量；`rho` 是与旋转耦合的平移对数坐标，通常不等于 `T_C_D` 的平移 `t`。

上面的例子中 `t = [1,0,0] m`，`phi = [0,0,pi/2] rad`。对于此绕 z 轴的相对旋转，平移满足：

$$
t=V\rho,\qquad
V=\begin{bmatrix}2/\pi&-2/\pi&0\\2/\pi&2/\pi&0\\0&0&1\end{bmatrix}
$$

所以 `rho = [pi/4,-pi/4,0] m ≈ [0.785398,-0.785398,0] m`，而不是 `[1,0,0] m`。这里 V 是 SE(3) 指数映射中的平移映射，不是机械臂的 Jacobian。

**结果与解释：** `[t,phi]` 与 `[rho,phi]` 是两种不同的误差构造。前者便于分别观察位置与姿态，后者用于李群上的局部求解；误差的导数和 Jacobian 必须与所选构造匹配，不能替换一个数组就沿用另一套推导。需要代码对应时查[已有李群与李代数笔记](../../../kinematics/examples/model_alignment/lie_group_lie_algebra_notes.md)。

## 例子：为什么 IK 每次只做局部修正

对单关节平面臂，连杆长 `L=1 m`，关节角 q 以 rad 表示，端点纵坐标为 `y(q)=L sin(q)`。在 `q=0` 附近：

$$
y(q+\Delta q)\approx y(q)+L\cos(q)\Delta q
$$

当 `Delta q = 0.1 rad`，线性预测位移为 `0.1 m`，真实几何位移为 `sin(0.1) m ≈ 0.0998334 m`，相差约 `0.0001666 m`。若一步改 `1 rad`，预测 `1 m`，真实值约 `0.841471 m`，误差明显变大。

多关节时，这个导数推广为 Jacobian。求得的小增量执行后需要重新计算误差与导数；局部解不能保证一次到达远处目标，也不保证目标可达。Jacobian 的机器人推导归[运动学](../../../kinematics/README.md)。

## 误差的单位与权重

位置误差 `0.01 m` 和姿态误差 `0.1 rad` 不能直接声称谁更大。若任务允许位置偏差尺度 `s_p=0.01 m`、姿态尺度 `s_R=0.1 rad`，可用 `e_p/s_p` 与 `phi/s_R` 构造无量纲残差；本例两者归一化后的大小都为 1。

尺度表达任务要求，不是随意调到求解成功的参数。评估时仍应分别报告位置和姿态误差，避免一个混合范数掩盖其中一项超差。
