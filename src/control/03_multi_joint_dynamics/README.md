# 03：多关节动力学——为什么肩和肘不能分开算

本文行数：356行，预期阅读时长：15分钟

**机械臂的各个关节属于同一套相连的系统。一个关节转动会带动其他连杆，因此某个关节的加速度通常取决于多个关节的状态和力矩。** 这种相互影响叫作动力学耦合。

[第二章](../02_single_joint_dynamics/README.md)只有一根杆，转轴固定。现在在杆端再接一根杆：第一根像上臂，第二根像前臂，中间是肘关节。肩部一动，肘关节的位置也会移动，前臂的运动自然不能只由肘电机单独决定。

本章先看现象和具体数字，再认识矩阵。目标是能读懂多关节方程各项在做什么，不要求手工推导六七轴机械臂，也不要求先学拉格朗日力学。所有数值均为理想模型的瞬时计算，配套脚本已核对，不是 MuJoCo 或真机实测。

## 1. 从一根杆到两根杆，先确认角度指什么

### 1.1 肩角相对世界，肘角相对上臂

仍取纸面向右为世界 `+x`，向上为 `+y`，重力沿 `−y`；两个关节轴平行于朝向读者的 `+z`，逆时针为正。

- `q1` 是肩关节角：上臂竖直下垂时为零，向右抬到水平时为 `π/2 rad`。
- `q2` 是肘关节的**相对角度**：前臂与上臂同向伸直时为零；相对上臂逆时针弯曲为正。
- 前臂相对世界中竖直下垂方向的角度为 **`q1+q2`**。
- 所有关节向量固定按 `[肩, 肘]`，即 `[joint1, joint2]` 排列。

```text
两杆下垂：q1=0，q2=0             两杆水平：q1=π/2，q2=0

肩 O                              肩 O────上臂────E────前臂────P
   │                                                    → +x
  上臂
   │                              上臂水平、前臂下垂：
肘 E                              q1=π/2，q2=−π/2
   │
  前臂                            肩 O────上臂────E
   │                                              │
末端 P                                           前臂
                                                  │
                                                  P
```

最后一图的前臂世界角度是 `π/2−π/2=0`，所以它竖直下垂。若把 `q2` 误当作前臂相对世界的角度，重力、惯量和运动解释都会出错。

### 1.2 沿用原杆，再接一根相同的杆

| 参数 | 上臂（杆 1） | 前臂（杆 2） |
| --- | --- | --- |
| 质量 `m_i` | `2 kg` | `2 kg` |
| 长度 `L_i` | `0.6 m` | `0.6 m` |
| 质心到近端关节距离 `l_ci` | `0.3 m` | `0.3 m` |
| 绕自身质心、垂直纸面的惯量 `I_ci=m_i L_i²/12` | `0.06 kg·m²` | `0.06 kg·m²` |
| 关节黏性阻尼系数 `b_i` | `0.2 N·m·s/rad` | `0.2 N·m·s/rad` |

`g=9.81 m/s²`。两杆都是均匀细杆，肩基座固定，肘能自由转动，各有关节侧力矩输入；先不考虑接触、弹性、关节限位和额外负载。

这里参数表用的是**绕各杆自身质心的惯量** `0.06 kg·m²`，第二章使用的是绕杆端点的 `0.24 kg·m²`，两者不矛盾。把转轴从质心移到端点，要加上 `m l_c²=0.18 kg·m²`，所以 `0.06+0.18=0.24`。动力学库要求哪一种惯量、相对哪个坐标系表达，需要按模型接口确认。

关节速度也分绝对与相对：上臂的绝对角速度为 `q1_dot`，前臂的绝对角速度为 `q1_dot+q2_dot`；肘部的黏性阻尼作用于关节相对速度 `q2_dot`。

## 2. 为什么不能给每个关节各套一遍单杆公式

如果肩部转动，前臂即便与上臂保持同一夹角，也会整体移动和转动。肩电机要带动的是两根杆，不只是上臂。

如果肘部开始转动，前臂对上臂也会有作用；如果希望肩部保持某种运动，上游电机通常需要相应调整力矩。关节把两根杆连接起来，也让它们交换力和力矩。

因此，单关节里的：

```text
一个惯量 × 一个角加速度 = 一个净力矩
```

推广后，要同时描述：

```text
肩部的力矩收支：与肩加速度、肘加速度都有关系
肘部的力矩收支：与肩加速度、肘加速度都有关系
```

**“肘电机力矩为零”只说明电机没有主动施加力矩，不表示前臂没有受力，也不表示肘角不变。** 要保持肘角不变，可能需要肘电机或机械约束提供力矩。

## 3. 先看一个最直接的耦合例子

### 3.1 初始两杆下垂，肩电机施加 1 N·m

设当前 `q=[0,0] rad`，两关节速度都为零。此刻重力对两关节的力矩都为零，黏性阻尼也为零，因此可以清楚地单独观察惯性影响。

给肩电机 `tau1=+1 N·m`，肘电机 `tau2=0 N·m`。根据该两杆模型，这一时刻的两条力矩关系是：

```text
1.92 × q1_ddot + 0.60 × q2_ddot = 1
0.60 × q1_ddot + 0.24 × q2_ddot = 0
```

系数单位为 kg·m²，加速度单位为 rad/s²，右侧单位为 N·m。这些系数由两根杆的几何、质量与当前姿态计算；稍后再解释它们的组织方式，现在先看两条方程的意思。

第二条右侧虽然是零，但它没有说 `q2_ddot=0`。它说的是两项相加为零：

```text
q2_ddot = −(0.60 / 0.24) × q1_ddot = −2.5 × q1_ddot
```

代入第一条，得到：

```text
(1.92 − 0.60 × 2.5) × q1_ddot = 1
0.42 × q1_ddot = 1

q1_ddot ≈ +2.380952 rad/s²
q2_ddot ≈ −5.952381 rad/s²
```

**结果与解释：** 肩部开始沿正方向加速，肘部相对上臂则沿负方向加速。肘电机没有出力，肘角仍然会改变，这就是一个明确的惯性耦合例子。

前臂绝对角加速度是两者之和，约为 `−3.571429 rad/s²`；不要把相对肘角的加速度直接当作前臂相对世界的角加速度。这些结果只对应当前时刻，杆离开下垂状态后重力矩等会改变。

### 3.2 如果要求肘部保持伸直，结果会不同

现在改变条件：仍让肩部施加 `+1 N·m`，但要求肘角保持不变，当前 `q2_dot=0`，并要求 `q2_ddot=0`。

第一条变成：

```text
1.92 × q1_ddot = 1
q1_ddot ≈ +0.520833 rad/s²
```

第二条则给出保持肘部所需的总关节力矩：

```text
tau2 = 0.60 × 0.520833 = +0.3125 N·m
```

如果由肘电机保持，它需在此刻提供这个力矩；如果机械锁止，则由约束反力矩承担。**保持不动需要力矩，与不提供力矩是两种不同条件。**

| 相同的肩电机力矩 `+1 N·m` | 肩角加速度 / rad/s² | 肘角加速度 / rad/s² | 肘部条件 |
| --- | --- | --- | --- |
| 肘电机不出力、无锁止 | `+2.380952` | `−5.952381` | 自由响应 |
| 肘部保持伸直 | `+0.520833` | `0` | 需要 `+0.3125 N·m` 保持力矩 |

保持伸直时，肩部要带动两杆作为一个整体转动；肘部自由时，系统可以通过肘部相对运动产生不同响应。不能把其中一行的结果套到另一种控制条件下。

## 4. 惯量矩阵只是把这些关系放进一张表

### 4.1 从两个数字变成一个向量

令 `q=[q1,q2]ᵀ`，其中上标 `ᵀ` 表示把两个数按列排列。同样，`q_dot`、`q_ddot`、`tau` 都按 `[肩,肘]` 排列，长度为 2。

把前面的两条方程写成矩阵形式：

$$
\underbrace{\begin{bmatrix}1.92&0.60\\0.60&0.24\end{bmatrix}}_{M(q)}
\begin{bmatrix}\ddot q_1\\\ddot q_2\end{bmatrix}
=\begin{bmatrix}1\\0\end{bmatrix}
$$

读第一行，就是 `1.92×肩加速度 + 0.60×肘加速度`；第二行同理。矩阵乘法在这里没有改变物理内容，只是把两条方程紧凑地排在一起。

`M(q)` 叫惯量矩阵，也常叫质量矩阵（mass matrix）。在本章全转动关节模型中，每个元素单位为 kg·m²。

- 对角项描述对应关节加速度对相应力矩方程的贡献，但不一定等于把这个关节单独拆下后的惯量。
- 非对角项描述另一个关节加速度在该方程里的贡献，是加速度耦合的直接体现。
- 对非退化的刚体模型和独立关节坐标，矩阵对称且正定，意味着非零运动具有正的动能。本章不要求证明这两个性质。

尤其不能直接用 `tau1/M11` 预测自由肘部条件下的肩加速度，因为 `M12×q2_ddot` 也在同一条方程里。应同时求解两条方程；用库时通常调用线性方程求解，而不是逐元素相除。

### 4.2 为什么写成 M(q)，而不是一个不变的 M

两根杆质量没变，但弯肘后质量相对肩轴的位置分布变了，因此整个系统的惯量关系会随构型变化。本模型的 `M` 只随相对肘角 `q2` 变化：

| 肘部构型 | `M11` | `M12=M21` | `M22` |
| --- | --- | --- | --- |
| `q2=0`，同向伸直 | `1.92` | `0.60` | `0.24` |
| `q2=π/2`，弯曲 90° | `1.20` | `0.24` | `0.24` |
| `q2=π`，反向折回 | `0.48` | `−0.12` | `0.24` |

表中单位均为 kg·m²。这是无碰撞、无限位的理想杆模型；折回只用于说明质量分布，不意味着实体机械臂能够让连杆重叠。

前臂绕自身质心的惯量并没有改变，变化的是它对关节运动组合的惯性贡献。非对角项也可以为负，表示坐标方向下的耦合关系，不是物体出现了负质量。

还有一个容易与运动学混淆的点：两杆伸直时，末端位置雅可比会奇异，但这里惯量矩阵的行列式仍为 `1.92×0.24−0.60²=0.1008>0`，仍可求解动力学。**运动学奇异不等于惯量矩阵奇异。**

## 5. 重力也不能只按“各管自己那根杆”计算

### 5.1 两杆水平时，肩部需要托住什么

现在取 `q1=π/2`、`q2=0`，两杆水平向右且静止。

上臂质心离肩轴 `0.3 m`，前臂质心离肩轴 `0.6+0.3=0.9 m`。肩部需要抵消两根杆对肩轴的重力矩：

```text
肩部保持力矩 = 2 × 9.81 × 0.3 + 2 × 9.81 × 0.9
             = 5.886 + 17.658
             = 23.544 N·m
```

肘部需要抵消前臂绕肘轴的重力矩：

```text
肘部保持力矩 = 2 × 9.81 × 0.3 = 5.886 N·m
```

第二章只有上臂时，水平保持需要 `5.886 N·m`；接上前臂以后，肩部需求已经变成 `23.544 N·m`。如果还按单杆估计，就会严重低估。

这里肩部计算的是整个下游系统绕肩轴的重力效果，肘部计算的是前臂绕肘轴的效果。它们属于两个不同的关节力矩分量，不是让同一个电机重复承担两遍重力。

### 5.2 前臂下垂，肘部不需要保持力矩，肩部仍需要

令上臂继续水平，肘角改为 `q2=−π/2`，前臂竖直下垂。前臂重力作用线穿过肘轴，因此肘部重力矩为零。

但前臂的质心仍位于肩轴右侧 `0.6 m`，所以肩部依然承担它的重力作用：

```text
肩部保持力矩 = 2 × 9.81 × 0.3 + 2 × 9.81 × 0.6 = 17.658 N·m
肘部保持力矩 = 0 N·m
```

**肘部重力矩为零，不表示前臂对整台机械臂没有影响。** 判断重力矩，总要说明是绕哪根轴计算。

以后把各关节需要抵消的重力项排列为 `G(q)`。本章把 `G` 定义为重力补偿项；实际重力广义力为 `−G(q)`，不要把两者符号混用。

## 6. 运动起来以后，还有一类与速度有关的项

### 6.1 先从现象理解，不急着记名字

想象你在转动肩部的同时弯肘：前臂的转轴本身在移动，前臂相对上臂也在转。即使某时刻希望关节速度不再增加，维持这种运动也可能需要额外力矩。

这些由系统运动几何产生、与关节速度组合有关的惯性项，通常归在科里奥利与离心项中，本章记作向量 `c(q,q_dot)`。看到这个名字，先理解为“当前姿态和速度带来的额外动力学项”即可。

它与第二章的黏性阻尼不同：阻尼描述耗散，`c` 则来自相连刚体的运动关系；它不总反抗当前速度，也不能统一当作摩擦。

### 6.2 一个速度翻倍的例子

取 `q=[0,π/2] rad`，即上臂下垂、前臂水平向右。此刻惯量矩阵为：

```text
M = [[1.20, 0.24],
     [0.24, 0.24]] kg·m²
```

对本模型，速度相关项的结果如下；具体公式留在文末按需核对：

| 关节速度 `[q1_dot,q2_dot]` / rad/s | `c` / N·m | 黏性阻尼补偿项 `[b1*q1_dot,b2*q2_dot]` / N·m |
| --- | --- | --- |
| `[0,0]` | `[0,0]` | `[0,0]` |
| `[1,2]` | `[−2.88,0.36]` | `[0.2,0.4]` |
| `[2,4]` | `[−11.52,1.44]` | `[0.4,0.8]` |

所有速度翻倍时，此例 `c` 变为四倍，因为它包含速度乘积或平方；线性黏性阻尼只变为两倍。第一分量为负也说明，不能把 `c` 当作“每个关节上始终为正的阻力需求”。

上述 `c` 是放在方程左侧的速度相关项。单看它，不能确定机械臂到底加速还是减速；还要把电机、重力、阻尼和惯量关系放在一起。

## 7. 现在再看完整方程，每一项都有对应含义

本章固定基座、两个独立转动关节的模型可以写成：

$$
M(q)\ddot q+c(q,\dot q)+G(q)+D\dot q
=\tau_{\mathrm{motor}}+\tau_{\mathrm{ext}}
$$

`D=diag(0.2,0.2)` 表示两个关节各自的黏性阻尼系数，非对角元素为零。使用 `D` 是为了把阻尼与其他文献中可能出现的输入映射符号区分开。

| 项 | 本模型维度 | 单位与职责 |
| --- | --- | --- |
| `q`、`q_dot`、`q_ddot` | `2×1` | 分别为 rad、rad/s、rad/s²，均按 `[肩,肘]` |
| `M(q)` | `2×2` | kg·m²，描述角加速度与惯性力矩之间的耦合 |
| `M(q) q_ddot` | `2×1` | N·m，给定加速度对应的惯性项 |
| `c(q,q_dot)` | `2×1` | N·m，与运动速度有关的惯性项 |
| `G(q)` | `2×1` | N·m，抵消重力所需的项 |
| `D q_dot` | `2×1` | N·m，抵消本模型黏性阻尼所需的项 |
| `tau_motor`、`tau_ext` | `2×1` | N·m，关节侧实际电机力矩和额外广义外力矩 |

这里的 `tau2` 是与相对关节角 `q2` 对应的肘电机力矩。肘电机对相连两杆施加相反方向的物理力矩，这一作用关系已包含在模型中；不能再凭直觉额外从 `tau1` 减去一次 `tau2`。

有些资料写 `c=C(q,q_dot) q_dot`。`C` 的矩阵表示不唯一，先关注乘积产生的速度相关向量。也有库把多个项合并为 bias，具体是否包含重力、摩擦等需要核对接口，不能只凭名称猜。机械臂方程结构及这种记法可参考 [MIT：Multi-Body Dynamics](https://underactuated.mit.edu/multibody.html#the-manipulator-equations)。

## 8. 综合例子：两台电机此刻各需要多少力矩

沿用第 6 节状态：`q=[0,π/2] rad`、`q_dot=[1,2] rad/s`，没有额外外力矩。希望此刻肩角加速度为 `+1 rad/s²`，肘角加速度为零，即 `q_ddot_des=[1,0] rad/s²`。

把各项按相同关节顺序相加：

| 需求项 | 肩 / N·m | 肘 / N·m |
| --- | --- | --- |
| `M × [1,0]ᵀ` | `1.200` | `0.240` |
| 速度相关项 `c` | `−2.880` | `0.360` |
| 重力补偿项 `G` | `5.886` | `5.886` |
| 阻尼补偿项 `D q_dot` | `0.200` | `0.400` |
| 所需电机力矩 | **`4.406`** | **`6.886`** |

这一姿态下，上臂重力作用线穿过肩轴，前臂质心位于肩和肘右侧各 `0.3 m`，所以两个重力分量恰好相同；这不是所有姿态都满足的规则。

尽管肘的期望角加速度是零，肘电机仍需要 `6.886 N·m`。它要处理肩加速度带来的耦合、当前速度项、重力与阻尼；而且此时肘速度为 `2 rad/s`，加速度为零并不表示肘停止。

反向核对也很直接：从两个实际电机力矩中减去 `c`、`G`、`D q_dot`，得到 `[1.2,0.24] N·m`；联立 `M q_ddot=[1.2,0.24]ᵀ`，会还原 `[1,0] rad/s²`。

这是当前模型与状态下的计算需求。电机力矩是否受限、状态是否准确、实际参数是否一致，仍会影响真实加速度；它不是控制器已经完成跟踪的证明。

## 9. 外界在末端向下拉，会影响几个关节

回到两杆水平向右的静止姿态。若在末端向下施加 `10 N` 的额外力，力臂相对肩轴是 `1.2 m`，相对肘轴是 `0.6 m`。

因此额外关节力矩为：

```text
tau_ext = [−10 × 1.2, −10 × 0.6] = [−12, −6] N·m
```

原来静止保持力矩为 `[23.544,5.886] N·m`，现在为了抵消这一下拉力，电机需求变为 `[35.544,11.886] N·m`。

同一个末端力会同时影响多个关节，这不表示在末端重复施加了两次力，而是同一力对不同关节运动坐标的作用。一般三维情形可用 `tau_ext=JᵀF` 表达；本章用力臂已经能解释，不要求现在推导雅可比转置。使用该接口时必须对齐作用点、坐标系和力/力矩排列。

## 10. 现在使用动力学库，重点应该检查什么

你不需要手写每个关节的矩阵展开，但应能确认输入输出的物理含义：

- 模型是固定基座还是浮动基座，关节坐标和速度的维度是否相同？本章限定两者都为 2。
- 关节顺序、角度零位、旋转正方向和单位是否与状态来源一致？
- 质量、质心、惯量的参考点与坐标系是否正确？负载是否已进入模型？
- 得到的是实际重力力矩还是重力补偿项？速度项中是否已经合并了其他影响？
- 传入的是关节实际力矩，还是需要经过执行器映射的命令？是否发生限幅？

多关节增加的是耦合关系，不改变第二章的主线：**用当前状态和模型计算各项，再结合实际输入求加速度，随后才推进时间。** 想到达目标并停住，还要由控制器持续决定力矩。

## 按需核对：本例的矩阵数值从哪里来

第一次阅读可以在这里停下。下面只保留数值来源，不要求手工重推。

采用前述相对角度，记 `k=m2 L1 l_c2`，均匀杆质心惯量为 `I_c1`、`I_c2`。本模型的惯量元素为：

```text
M11 = I_c1 + m1*l_c1² + I_c2 + m2*(L1² + l_c2² + 2*L1*l_c2*cos(q2))
M12 = M21 = I_c2 + m2*(l_c2² + L1*l_c2*cos(q2))
M22 = I_c2 + m2*l_c2²
```

速度项和重力补偿项为：

```text
c1 = −k*sin(q2)*(2*q1_dot*q2_dot + q2_dot²)
c2 =  k*sin(q2)*q1_dot²
G1 = g*((m1*l_c1 + m2*L1)*sin(q1) + m2*l_c2*sin(q1+q2))
G2 = g*m2*l_c2*sin(q1+q2)
```

这里与 [MIT：Acrobot 的两连杆模型](https://underactuated.mit.edu/acrobot.html)使用相同类型的相对关节坐标与刚体惯量关系，但本例两关节都能输入力矩，参数和执行器配置由本章另行定义。细杆端点、质心及相对角度不能与质点单摆或绝对角度模型混用。
