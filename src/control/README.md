# 动力学、轨迹与控制

本文行数：57行，预期阅读时长：5分钟

**本主题对应学习路线 S5，面向“学过运动学、尚未学过动力学”的读者。先理解力怎样改变运动，再学习动力学接口、仿真步进和控制。**

学习目标是理解输入输出、正确调用、检查结果和定位常见错误。动力学计算可以交给现成库，但力矩、惯量、重力和状态的物理含义需要先建立直觉；不要求先学完整套理论力学或手写六七轴求解器。

01～06 依次解释动力学直觉、单关节与多关节模型、计算接口、时间积分和控制。第六章用单杆仿真展示跟踪、扰动、限幅、噪声与延迟；07 已有解析合成数据的参数辨识代码、指标与检查，按需查阅。

## 从运动学到动力学

运动学回答“给定关节角，末端在哪里”；动力学回答“施加力矩后怎样运动，以及产生某种运动需要多少力矩”。同一姿态下，空载与提着重物的工具位姿可以相同，但保持姿态和加速所需的力矩不同。

入门只需已有的关节角、坐标系和正方向概念；速度、加速度、力矩与惯量会从第一部分开始解释。正文面向首次学习，按“现象 → 概念与单位 → 具体例子 → 结果解释”逐步展开，允许比复习笔记更详细；无需运行代码即可阅读，不安排必做实验。

## 第六部分怎样逐步展开

控制与约束在动力学基础之后展开，先用单关节例子，再连接机械臂应用：

1. **输入与反馈：** 位置、速度、力矩接口；目标与实际值；P、PD、PID 各项分别解决什么问题。
2. **轨迹与运动限制：** 路径与带时间的轨迹；插值、时间参数化；速度和加速度限制。
3. **前馈与重力补偿：** 提前提供模型预测的力矩，理解为何仍需反馈处理误差。
4. **采样与执行器限制：** 控制周期、力矩饱和、积分累积、噪声与延迟，以及负载或扰动的影响。
5. **跟踪与结果判断：** 从单关节到关节空间轨迹，再到末端目标；区分求解误差和实际跟踪误差。

以上五项已在[第六章正文](06_control_constraints/README.md)展开；配套[验证记录](06_control_constraints/verification.md)保存 14 项检查、实际曲线、误差与失败说明。
