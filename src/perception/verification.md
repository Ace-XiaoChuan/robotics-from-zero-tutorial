# 感知与估计数值例子

本文行数：41行，预期阅读时长：2分钟

2026-09-22 使用 Python 3.10.12、NumPy 1.21.5 执行[检查脚本](check_examples.py)，12 项检查全部通过。使用当前已有环境，无需相机、ROS、MuJoCo 或外部模型。

维护者可从仓库根目录复核，阅读正文无需执行：

```bash
python3 src/perception/check_examples.py
```

## 核对范围

| 章节 | 实际核对内容 |
| --- | --- |
| 01 成像与标定 | 三组投影、射线深度歧义、给定像素映射后的内参、视场角焦距、两种 RMS 分母 |
| 02 位姿与坐标 | 标记边长尺度、带 90° 旋转的位移、逆变换恢复相机系坐标 |
| 03 测量误差 | 均值、样本标准差、偏差与 RMSE 分解、异常值的均值和中位数 |
| 04 误差传播 | 反投影 Jacobian 与中心差分对照、独立像素和深度误差合成、协方差旋转、杠杆臂近似与精确弦长、位置和旋转误差 |
| 05 滤波与估计 | 匀速尾随均值滞后、指数平滑、标量 Kalman 与信息形式对照、位置—速度更新、Joseph 协方差与半正定性、缺测预测 |
| 06 时间对齐 | 运动与延迟产生的位置偏差、插值算例、外推区间和过期年龄判据 |

## 关键结果

| 算例 | 实际计算值 |
| --- | --- |
| 带旋转的 Tag 基座位置 | `(0.40,0.10,0.80) m` |
| 三次位置读数相对 0.47 m 的 RMSE | `0.0310912635103 m` |
| 像素与深度独立误差合成的标准差 | `0.00538516480713 m` |
| 一维 Kalman 后验位置与方差 | `0.48 m`、`0.008 m²` |
| 位置—速度 Kalman 后验 | `(1.1666667 m,1.0333333 m/s)` |
| 0.10 m/s 运动、0.20 s 时间错位 | `0.02 m` |

中心差分步长对 u 为 `1e-3 px`、对 Z 为 `1e-5 m`，分别与解析导数比较，绝对容差 `1e-11`（按各导数自身单位）。Kalman 矩阵结果使用解析分数对照，绝对容差 `1e-12`。这些容差用于小型双精度算例，不代表传感器精度。

## 例子的条件

程序只依赖 NumPy，用给定投影、变换和噪声参数核对数学计算，没有调用 OpenCV、相机、PnP 或综合采集脚本。相机标定与 AprilTag 场景需结合实际图像、模型与外部接口运行，入口见[相机案例](examples/camera_and_tags/README.md)。OpenCV 参考资料版本为 4.13.0，不是旧脚本的运行验证版本。
