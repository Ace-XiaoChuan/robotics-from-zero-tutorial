# 05：滤波与 Kalman 状态估计

本文行数：87行，预期阅读时长：5分钟

**滤波结合已有状态和新测量；Kalman 滤波进一步用运动模型和协方差决定更新幅度。输出更平滑并不保证更接近当前真实状态。**

## 速记要点

- 滑动均值与指数平滑容易理解，但运动时会滞后。
- 预测根据模型推进状态；更新根据当前测量修正预测。
- Q 表示过程模型的不确定性，R 表示测量噪声；P 表示估计误差协方差。
- 经典线性 Kalman 在模型正确、零均值白噪声、已知协方差等条件下有明确最优性；线性高斯条件下给出条件均值与协方差。真实检测异常和固定偏差不自动满足这些假设。

## 例子：平滑会留下多大滞后

目标每 `0.1 s` 向前移动 `0.01 m`，当前连续五次无噪声读数为 `(0,0.01,0.02,0.03,0.04) m`。尾随五点均值是 `0.02 m`，当前真实位置是 `0.04 m`。

**结果与解释：** 即使没有噪声，均值也落后 `0.02 m`，对应 `0.2 s`。均匀采样、匀速运动时，n 点尾随均值等效于落后 `(n-1)Δt/2`；不能把这个关系推广到所有运动模式。

指数平滑 `x̂_k=αz_k+(1-α)x̂_{k-1}` 中，若 `α=0.2`、旧值 `0 m`、新测量 `0.10 m`，新输出仅 `0.02 m`。α 越小，单帧影响越小，也越不容易迅速跟上变化。固定偏差仍会进入输出。

## 例子：一维位置的一次更新

先用随机游走模型 `x_k=x_{k-1}+w_k`、测量 `z_k=x_k+v_k` 理解更新。位置单位 m，P、Q、R 单位 m²；Q 对应本次采样间隔。

$$
x_k^-=\hat x_{k-1},\quad P_k^-=P_{k-1}+Q,\qquad
K_k=\frac{P_k^-}{P_k^-+R}.
$$

$$
\hat x_k=x_k^-+K_k(z_k-x_k^-),\qquad P_k=(1-K_k)P_k^-.
$$

输入预测 `x⁻=0.40 m,P⁻=0.04 m²`，测量 `z=0.50 m,R=0.01 m²`：

| 量 | 结果 | 含义 |
| --- | --- | --- |
| 创新 `z-x⁻` | `0.10 m` | 新测量与预测的差 |
| K | `0.8` | 本次修正采用创新的 80% |
| 后验位置 | `0.48 m` | 向更可信的测量靠拢 |
| 后验方差 | `0.008 m²` | 两个信息来源融合后的不确定性 |

若 R 增为 `0.16 m²`，K 降为 `0.2`，后验位置为 `0.42 m`。这说明“信任多少”取决于相对方差；把 R 调得很小并不会让相机真的变准。

## 位置—速度模型：为什么只测位置也能修正速度

状态 `x=[p,v]ᵀ`，p 为固定坐标轴上的位置 m，v 为 m/s。匀速预测、只测位置时：

$$
F=\begin{bmatrix}1&\Delta t\\0&1\end{bmatrix},\quad H=\begin{bmatrix}1&0\end{bmatrix},\quad
x_k^-=F\hat x_{k-1},\quad P_k^-=FP_{k-1}F^T+Q.
$$

若每个区间内有独立的常值随机加速度 a、方差 `σ_a²`，可令 `G=[Δt²/2,Δt]ᵀ`、`Q=Gσ_a²Gᵀ`。这与连续时间白加速度噪声离散化的 Q 不同，选择时需声明假设。

**完整一步例子：** `Δt=1 s`，旧估计 `[0 m,1 m/s]ᵀ`，`P=diag(0.04 m²,0.01 m²/s²)`；为隔离协方差耦合，本步取 `Q=0`，假定区间内确实匀速。

```text
预测状态 x⁻ = [1, 1]ᵀ
预测协方差 P⁻ = [[0.05, 0.01],
                  [0.01, 0.01]]
新位置测量 z = 1.2 m，R = 0.01 m²
创新 ν = 0.2 m，创新方差 S = H P⁻ Hᵀ + R = 0.06 m²
K = P⁻ Hᵀ / S = [0.833333, 0.166667]ᵀ
后验状态 x̂ = [1.166667 m, 1.033333 m/s]ᵀ
后验协方差 P = [[0.00833333, 0.00166667],
                 [0.00166667, 0.00833333]]
```

P 的两个对角项单位分别为 m²、m²/s²，非对角项为 m²/s；K 的两项单位分别为 1 和 1/s。

**解释：** 预测位置比测量小，可能意味着速度也偏小。预测产生的位置—速度交叉协方差，使位置测量同时修正速度。这依赖旧状态与运动模型；单独一帧位置并不能无条件确定速度。

实现协方差更新时，可用 Joseph 形式 `P=(I-KH)P⁻(I-KH)ᵀ+KRKᵀ` 减少数值问题。Q=0 是本步算例条件，实际存在加速度时需允许模型误差，否则滤波器可能过度自信。

## 缺测、异常值与重复信息

缺测时跳过测量更新，继续预测并记录上次测量时间；不确定性按模型传播，不能将预测标为刚观测到的结果。过程噪声一般会增加不确定性，但并非任意模型下每个协方差分量都单调增加。

一维创新门控可看 `ν²/S`，它无量纲；拒绝阈值取决于假设和允许误拒率。突发运动也可能触发门控，持续拒绝需检查运动模型或重新初始化。重复融合同一帧、或把同源且相关的估计当作独立测量，会低估不确定性。

扩展 Kalman（EKF）把非线性运动或观测在当前估计处线性化；它不会自动解决姿态表示、错误数据关联或未建模延迟。完整机器人状态融合超出本章范围。

基础预测与更新可查 Welch、Bishop 的[原始教程](https://www.cs.unc.edu/~welch/media/pdf/kalman_intro.pdf)。本章人工算例与核对范围见[验证记录](../verification.md)，未做真实相机噪声拟合或闭环滤波性能评估。
