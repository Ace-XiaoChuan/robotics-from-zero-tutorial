# 03：测量噪声、偏差与有效性

本文行数：74行，预期阅读时长：4分钟

**重复读数的散布说明重复性，读数相对真值的偏移说明准确程度。平均可以减小部分随机波动，但固定标定偏差会保留下来。**

## 速记要点

- 一维测量可写为 `z_i=x_true+b+ε_i`；b 是偏差，ε 是随机项。
- 均值表示读数的平均水平，标准差表示读数围绕均值的散布；均方根误差（RMSE，Root Mean Square Error）表示读数偏离参考真值的整体幅度，计算时将各次误差平方、求平均，再开平方。三者的单位都与读数相同，报告时注明定义和单位。
- 遮挡、误识别、时间错位不一定符合“小幅高斯噪声”假设。
- 无效测量不能用数值零冒充；零可能就是合法位置或速度。

## 例子：很稳定，也可能一直偏

同一静止目标沿固定坐标轴的位置读数为 `(0.49,0.50,0.51) m`，独立参考真值为 `0.47 m`。样本数 n=3：

$$
\bar z=\frac1n\sum_i z_i,\qquad
s^2=\frac1{n-1}\sum_i(z_i-\bar z)^2.
$$

| 量 | 结果 | 回答的问题 |
| --- | --- | --- |
| 均值 | `0.50 m` | 测量集中在哪里？ |
| 样本标准差 s | `0.01 m` | 重复读数散布多大？ |
| 平均误差 | `+0.03 m` | 相对参考值朝哪边偏？ |
| RMSE | `0.031091 m` | 各次误差的整体幅度多大？ |

本例各次误差为 `z_i-x_true=(0.02,0.03,0.04) m`，因此：

$$
\mathrm{RMSE}=\sqrt{\frac{0.02^2+0.03^2+0.04^2}{3}}\approx0.031091\ \mathrm{m}.
$$

先平方可避免正负误差相互抵消，也让较大误差占更大权重；最后开平方将单位从平方米恢复为米。RMSE 同时反映固定偏差与随机波动，所以读数很稳定，RMSE 仍可能较大。

本例满足 `RMSE²=平均误差²+(n-1)s²/n`(RMSE均方根误差（Root Mean Square Error）)。不能直接用分母 n−1 的样本方差加平均误差平方当作有限样本 RMSE²。

**解释：** 没有可信真值时，可报告重复性，不能由小标准差直接断言准确。参考真值本身也有不确定性，实物实验需说明测量工具和误差范围。三次读数只是算例，不能支持稳定的统计结论。

## 平均为什么有用，又为什么会失效

对 n 个独立、同分布、零均值噪声样本，均值的标准差为 `σ/√n`。例如单次 `σ=0.01 m`，100 次独立采样的均值标准差是 `0.001 m`，固定偏差 `0.03 m` 仍然存在。

相邻图像往往相关，同一帧的重复处理也不构成新的独立证据。运动目标在长时间窗口中的位置变化，更不能全当测量噪声；应使用运动模型，见第五章。

## 例子：异常值会把均值拉走

读数 `(0.49,0.50,0.51,1.50) m` 的均值变为 `0.75 m`，中位数为 `0.505 m`。

**解释：** 中位数对这一个异常值更稳健，但它不证明 `1.50 m` 一定错误，也可能是目标真的移动或换了 ID。先核对目标关联、时间与检测质量，再决定拒绝或重新初始化估计；异常样本不能悄悄从失败统计中消失。

## 位姿质量与检测置信度

角点清晰度、标记解码质量、重投影残差和三维位姿不确定性是不同量。一个高检测分数不能直接解释成“位置标准差 1 mm”；这种映射需要数据或误差模型支持。

| 情况 | 状态表达与后续行为 |
| --- | --- |
| 未检测到目标 | `valid=false`，原因 `not_detected` |
| 多个目标无法确定关联 | 记录候选或 `ambiguous`，不随意切换 ID |
| 已有目标但测量过期 | 保留原时间戳，标记 `stale` |
| 测量质量不足 | 记录质量指标和拒绝原因 |
| 有效且满足任务条件 | 输出位姿、坐标系、采样时间与误差信息 |

这些字段是教学接口建议，并非旧脚本已经实现。滤波器可以在缺测时预测，但预测状态需与新测量区分；规划是否可用还取决于估计年龄、协方差和任务容差。

## 读图和读结果时查

偏差随距离按比例变化，先查标记尺寸与内参；偏差随视角变化，查外参和畸变；运动时偏、静止时准，查时间对齐。先定位物理来源，再调整滤波强度。
