    同一个名字，两种信息

    /lesson1/navigation 是 Action 的完整名称；robot_interfaces/action/Navigation 是它的类型。相对名 navigation 在本例命名空间下展开。

    画面中的节点是功能单位；一个进程可以包含多个节点。Workspace 组织包，Package 声明源码与依赖，Executable 启动后成为进程。

    接口定义决定字段

    .msg：消息字段；.srv：请求 --- 响应；.action：目标 --- 结果 --- 反馈。构建工具据此生成 C++ / Python 类型。
