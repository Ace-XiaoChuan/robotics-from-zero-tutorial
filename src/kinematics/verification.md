# 运动学数值例子与结果

本文行数：50行，预期阅读时长：3分钟

## 配置与结果

2026-09-22 使用 Python 3.10.12、NumPy 1.21.5，执行[检查脚本](check_examples.py)，26 项数值检查全部通过。无需机器人模型、ROS、MuJoCo、Pinocchio 或图形窗口。

脚本使用标准库 unittest。以下命令从仓库根目录执行，供维护者复核；阅读八章正文不要求运行代码：

```bash
python3 src/kinematics/check_examples.py
```

默认例子为平面 2R，长度 `[0.4,0.3] m`、顺序 `[q1,q2]`，各角相对前一连杆，基座右手系、转轴 +z。冗余例子为 3R，长度 `[0.3,0.2,0.1] m`、顺序 `[q1,q2,q3]`。位置在基座系表达，角度为 rad。

## 关键数值结果

| 检查 | 配置 | 实际结果 |
| --- | --- | --- |
| Jacobian 中心差分 | `h=1e-6 rad`，验差阈值 `1e-9 m/rad` | 最大元素绝对误差约 `5.336e-11 m/rad` |
| IK 单次线性修正 | 从 `[0,pi/2] rad` 指向 `[0.39,0.31] m` | 非线性 FK 位置残差约 `0.000208050 m` |
| 教学迭代 IK | 初值 `[0.2,1.0] rad`，目标 `[0.4,0.3] m` | 6 次更新收敛，FK 位置残差约 `3.107e-15 m` |
| 超出几何范围 | 目标 `[0.8,0] m` | `outside_workspace`，未进入迭代 |
| 可达但局部停滞 | 初值 `[0,0] rad`，目标 `[0.69,0] m` | `stalled`；解析 IK 仍有解 |
| 迭代预算耗尽 | 初值未达目标、最大更新次数设为 0 | `max_iterations`，没有冒充收敛 |
| 3R 零空间有限步 | `q=[0,pi/2,-pi/2]`，步长 `0.01*[1,-1,-3] rad` | 位置漂移约 `5.99978e-5 m`，朝向改变 `-0.03 rad` |

教学 IK 只求 2R 位置任务，阻尼 `lambda=0.001 m/rad`，使用 `J.T@J + lambda² I`；最大 80 次更新，每次最大关节分量增量限制为 `0.2 rad`。收敛阈值 `1e-10 m`，更新范数小于等于 `1e-12 rad` 且误差未达标时判停滞。没有时间超时机制、关节限位优化或碰撞约束；限位筛选是对解析候选解单独检查的。

极小残差来自双精度下对自包含几何模型的求解，不是设备精度。解析关系通常以约 `1e-12` 的数值绝对容差核对，浮点结果可能随环境略有差异。

检查对象是平面教学模型与 DH 数值脚本。Panda 的联合仿真、外部模型与末端控制需按[模型对齐案例](examples/model_alignment/README.md)另行运行。

理论参考：[Modern Robotics 官方教材入口](https://hades.mech.northwestern.edu/index.php/Modern_Robotics)中关于正运动学、速度运动学与逆运动学的章节；Craig《Introduction to Robotics: Mechanics and Control》中关于 Modified DH 的建系约定。两种 DH 的具体因子顺序以[本仓库第二章](02_dh_conventions/README.md)的显式定义为准。
