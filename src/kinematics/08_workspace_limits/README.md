# 08：工作空间、关节限制与可达性

本文行数：73行，预期阅读时长：4分钟

**末端位置落在机械臂长度覆盖范围内，只通过了最粗的一层判断。姿态、关节限制、碰撞和到达路径都可能继续排除这个目标。**

## 速记要点

- 关节空间中的合法集合，由关节拓扑、位置限制和其他约束共同决定。
- 位置工作空间是合法构型经过位置 FK 映射得到的集合；位姿工作空间还要包含朝向。
- 可达工作空间通常表示至少存在某种允许朝向可到达；灵巧工作空间讨论能满足所要求朝向集合的位置，定义时应说清朝向范围。
- 采样图只能显示采到的可达点；某位置没被采到，不等于已证明不可达。

## 例子 1：没有限位和障碍物的 2R

沿用长度 `L1=0.4 m`、`L2=0.3 m`，两个关节可完整转动。末端到基座原点的距离 r 满足：

$$
|L_1-L_2|\le r\le L_1+L_2
\quad\Longrightarrow\quad 0.1\le r\le0.7\ \mathrm{m}
$$

所以平面位置工作空间是一个圆环，不是半径 0.7 m 的实心圆。外边界来自完全伸直，内边界来自两连杆反向折叠。

| 基座系目标位置 / m | r / m | 无障碍、无限位位置任务 |
| --- | --- | --- |
| `[0.4,0.3]` | 0.5 | 可达 |
| `[0.8,0]` | 0.8 | 超过外边界，不可达 |
| `[0.05,0]` | 0.05 | 落在内孔，不可达 |
| `[0.7,0]` | 0.7 | 边界可达，但位置 Jacobian 奇异 |

## 例子 2：关节限制会改变位置工作空间

现在只允许 `q2∈[0,pi/2] rad`，q1 仍能完整转动。由：

$$
r^2=L_1^2+L_2^2+2L_1L_2\cos q_2
$$

得到 `0.5≤r≤0.7 m`。目标 `[0.2,0] m` 在原来的圆环内，但需要 `|q2|≈2.636232 rad≈151.045°`，不满足新限制。

**结果与解释：** 几何长度允许，不代表设备关节范围允许。若 q1 也受限，通常还会限制目标方向，工作空间不再是完整圆环。

新内边界 `r=0.5 m` 对应 `q2=pi/2`，此时 `det(J_p)=0.12 (m/rad)²`，并不奇异。这说明“工作空间边界”也可能来自限位，而不是 Jacobian 失秩。

## 同一位置不一定能摆出所需姿态

在 `[0.4,0.3] m`，无限位 2R 的两个 IK 分支只能给出 90° 或约 -16.260205° 的末端朝向，不能任意指定 0°。具体推导见[逆运动学](../05_inverse_kinematics/README.md)。

空间机械臂也一样：能把法兰原点移到某处，不代表工具能以要求的插入方向到达；增加工具偏移、姿态约束或夹爪尺寸后，应按真正的 TCP 与碰撞几何重新判断。

## 目标可达与路径可达是两件事

```mermaid
flowchart LR
    A["目标位置与姿态"] --> B["是否存在满足 FK 的构型"]
    B --> C["构型是否满足关节限制"]
    C --> D["该构型是否无禁止碰撞"]
    D --> E["是否存在从当前状态到它的合法路径"]
    E --> F["是否能按速度、加速度等要求执行"]
```

两个端点都无碰撞，连线或关节插值途中仍可能碰撞；多个合法区域也可能被障碍物分开。IK 通常只解决构型问题，路径搜索归[规划与操作](../../manipulation/README.md)，实际跟踪归[动力学、轨迹与控制](../../control/README.md)。

## 关节角周期与设备限制

连续转动关节的 `pi` 和 `-pi` 在几何上可表示同一姿态，但有硬限位、线缆绕转或多圈计数的设备不能任意对关节角取模。选择 IK 分支和计算到当前关节位置的距离时，应使用模型中的关节类型与实际限制。

位置合法也不代表轨迹合法。例如从 `0 rad` 到 `1 rad`，若速度上限为 `0.2 rad/s`，仅由速度限制就需要至少 `5 s`；还要求平滑起停或受加速度限制时，所需时间可能更长。
