# 05：解析逆运动学与数值迭代

本文行数：97行，预期阅读时长：5分钟

**逆运动学 IK 寻找满足目标任务的关节构型。它可能有多个解、没有解，或者数值求解没有找到解；这三种情况不能混为一谈。**

## 速记要点

- 先明确目标是位置还是完整位姿，以及目标参考系和 TCP。增加姿态约束可能让原来可达的位置变成不可达位姿。
- 解析 IK 利用机构几何直接求候选解；数值 IK 从初值出发逐步减小误差。
- 得到候选 q 后必须重新做 FK，分别核对位置与姿态误差，再检查限位等条件。
- IK 解是构型，不是带时间的轨迹；从当前构型怎样走到该构型，还要交给规划和执行。

## 例子：2R 的位置解析解

沿用基座系 B、长度 `L1=0.4 m`、`L2=0.3 m`，求目标 `(x,y)` 对应的 `[q1,q2]`，角度为 rad。先由余弦定理得到：

$$
c_2=\frac{x^2+y^2-L_1^2-L_2^2}{2L_1L_2},\quad
s_2=\pm\sqrt{1-c_2^2},\quad
q_2=\operatorname{atan2}(s_2,c_2)
$$

$$
q_1=\operatorname{atan2}(y,x)
-\operatorname{atan2}(L_2s_2,L_1+L_2c_2)
$$

当 `|c2|>1` 超出合理浮点容差时，目标不在无障碍、无限位的几何工作空间内。只有微小舍入越界才允许裁回 `[-1,1]`，不能把明显不可达目标强行裁成边界解。

## 同一目标对应两种姿态

目标为 `[0.4,0.3] m`，则 `c2=0`，得到两个分支：

| 分支 | `[q1,q2]` / rad | FK 位置 / m | 末端朝向 |
| --- | --- | --- | --- |
| q2 为正 | `[0,pi/2]` | `[0.4,0.3]` | 90° |
| q2 为负 | `[1.287002,-pi/2]` | `[0.4,0.3]` | 约 -16.260205° |

**结果与解释：** 两个分支都到达同一位置，但肘部和工具朝向不同。如果再要求末端朝向 0°，这两个分支都不满足，所以这个 2R 的该完整位姿无解。

若关节 2 限制为 `[0,pi] rad`，只能选第一个分支。若两者均合法，可以比较与当前构型的距离、离限位的余量和碰撞情况；不能仅因为数组中某个解排在第一位就认为它最好。

## 数值 IK 每一步在计算什么

对于本章仅位置任务，误差 `e=p_target-f(q)` 在 B 系表达，单位 m。用当前位置 Jacobian 做局部近似：

$$
J_p(q)\Delta q\approx e,\qquad
\Delta q=\arg\min_d\ \|J_p d-e\|^2+\lambda^2\|d\|^2
$$

随后更新 `q_next=q+alpha*Delta q`，alpha 为无量纲迭代步长，再重新计算 FK 和误差。这里是数值求解迭代，不是自动把 Delta q 当作真实关节速度。

```text
给定目标和初始 q
→ 计算 FK、位置误差和 Jacobian
→ 若满足误差要求则返回候选解
→ 解局部线性问题，限制更新步幅并处理约束
→ 更新 q，检查是否停滞、超时或超过迭代上限
→ 继续迭代，或返回明确的失败原因
```

## 例子：局部一步为什么不是精确答案

从 `q=[0,pi/2]`、当前位置 `[0.4,0.3] m` 出发，目标为 `[0.39,0.31] m`。取无阻尼的局部解：

$$
\begin{bmatrix}-0.3&-0.3\\0.4&0\end{bmatrix}
\Delta q=\begin{bmatrix}-0.01\\0.01\end{bmatrix}
\quad\Longrightarrow\quad
\Delta q=\begin{bmatrix}0.025\\0.008333333\end{bmatrix}\ \mathrm{rad}
$$

更新后必须用非线性的 sin、cos 重新算 FK。**本例结果：** 位置残差约 `0.000208050 m`，也就是 `0.208 mm`；线性方程残差为零，不表示新的几何误差恰好为零。

[检查脚本](../check_examples.py)还从 `[0.2,1.0] rad` 开始，迭代求位置目标 `[0.4,0.3] m`，在 6 次更新后达到 `1e-10 m` 的收敛阈值。它是有次数上限的二维教学迭代，未加入碰撞或关节限位优化；配置、残差与失败检查见[验证记录](../verification.md)，不代表三维机器人 IK 或实际执行通过。

## 失败怎样解释

| 现象或状态 | 能得出的结论 |
| --- | --- |
| 几何可达性判据失败 | 对指定模型和任务，目标超出已证明的几何范围 |
| 迭代到达上限 | 本次方法和初值未在预算内收敛，不足以证明目标不存在解 |
| 更新量接近零但误差仍大 | 可能位于奇异构型或局部停滞，需要分析任务方向 |
| 解满足位置但超限 | 候选解不符合设备约束，不能直接执行 |
| 解满足 FK 与限位 | 仍需检查碰撞、路径可达性和控制执行 |

一个典型例子是从完全伸直的 `[0,0]` 追踪 `[0.69,0] m`：目标在几何范围内，但此时沿 x 的 Jacobian 行为零，最小二乘可能给出零更新。改变初值或使用其他搜索策略可能找到解，不能直接宣布目标不可达。

## 与已有 Panda 实现怎样连接

[已有末端控制脚本](../examples/model_alignment/control_ee_with_pinocchio.py)使用 SE(3) 对数误差和相应误差 Jacobian；其符号、六维排列及 `Jlog6` 修正不能直接用本章二维位置公式替换。脚本中的阻尼项写为 `damping*I`，本章写为 `lambda²*I`，两者参数数值不能不加转换地照搬。

一般模型的关节更新应遵循其构型空间积分规则；位置与姿态误差也应分别核对或合理归一化。关节角逐项裁剪只能处理简单边界，不保证数值 IK 收敛，更不能替代完整约束求解。
