# 01：构型、关节空间与正运动学

本文行数：83行，预期阅读时长：4分钟

**正运动学 FK 回答：模型和关节位置已知时，指定连杆或工具在什么位置、朝向哪里。它描述几何关系，不负责让机械臂真的运动。**

## 速记要点

- 构型 q 描述机器人当前的几何状态。固定基座、两个转动关节的例子写成 `q=[q1,q2]`，单位 rad。
- 关节空间由 q 表示；任务空间由所关心的输出表示，例如平面位置 `[x,y]`，或平面位姿 `[x,y,phi]`。
- 输出包含几个数，不等于机器人能独立控制几个方向；平面 2R 只有两个自由度，不能任意指定三个独立位姿量。
- 固定模型、基座和工具定义后，给定合法 q，FK 的结果确定；关节角不是唯一决定因素，连杆尺寸也参与计算。
- 浮动基座、球关节或闭链机构需要相应的构型表示与约束，不应直接套用“每个关节一个角度”的假设。

## 贯穿例子：平面 2R 机械臂

基座系 B 为右手系，机械臂在 xy 平面运动，两个关节轴都沿 +z。长度 `L1=0.4 m`、`L2=0.3 m`。顺序固定为 `[joint1,joint2]`，q1 从基座 +x 方向测量，q2 是第二连杆相对第一连杆的角度，正方向按右手定则。

q 全零时两根连杆沿 +x 伸直；末端 E 在第二连杆远端，E 的 x 轴沿第二连杆。后续未注明时均使用这套定义。

```text
q1=0，q2=pi/2 的几何示意（不是按比例绘图）

 y_B                    E (0.4, 0.3)
  ↑                     ●
  |                     | L2=0.3 m
  O─────────────────────●──→ x_B
         L1=0.4 m      joint2
```

## 例子：从关节角算出末端位姿

第二连杆相对基座的角度是 `q1+q2`，因此：

$$
x=L_1\cos q_1+L_2\cos(q_1+q_2),\qquad
y=L_1\sin q_1+L_2\sin(q_1+q_2)
$$

$$
\phi=q_1+q_2,\qquad
T_{B\_E}=\begin{bmatrix}
\cos\phi&-\sin\phi&0&x\\
\sin\phi&\cos\phi&0&y\\
0&0&1&0\\0&0&0&1
\end{bmatrix}
$$

位置单位 m，phi 单位 rad，`T_B_E` 把 E 系点坐标变成 B 系坐标。phi 可按连续角记录；仅比较姿态时，差一个 `2pi` 的角度表示同一朝向。

| q1 / rad | q2 / rad | 末端位置 `[x,y]` / m | 末端朝向 phi / rad |
| --- | --- | --- | --- |
| 0 | 0 | `[0.7,0]` | 0 |
| 0 | pi/2 | `[0.4,0.3]` | pi/2 |
| pi/2 | 0 | `[0,0.7]` | pi/2 |
| pi/6 | pi/4 | `[0.424056,0.489778]` | 5pi/12 |

**结果与解释：** `q=[0,pi/2]` 时第一连杆向右，第二连杆向上，所以末端为 `[0.4,0.3] m`。若误把 q2 当作第二连杆的绝对方向，某些 q1=0 的例子仍会碰巧正确，但一般姿态会出错。

```python
import numpy as np

q1, q2 = np.deg2rad([30., 45.])
p_B_E = np.array([0.4*np.cos(q1) + 0.3*np.cos(q1+q2),
                  0.4*np.sin(q1) + 0.3*np.sin(q1+q2), 0.])
phi = q1 + q2
```

## 从几何公式到机器人模型

串联机械臂可以将各段变换连乘：`T_B_E = T_B_1(q1) @ T_1_2(q2) @ ... @ T_last_E`。DH、URDF、MJCF 和运动学库以不同方式保存关节轴、固定变换与关节变量，但最终都必须指向同一物理基座和工具。

计算某个连杆原点与计算工具尖端不是同一个问题。夹爪长度、法兰到 TCP 的偏移，应作为固定变换参与 FK，不能在结果对不上时随意补一个世界系平移。

构型空间也不总是普通欧氏空间：连续转动关节存在角度周期，单位四元数存在约束。对一般模型更新 q 时，应使用对应库的构型积分规则；本章只有两个普通转动关节，可以直接相加小角增量。

## 与仿真和控制的边界

给定 q 计算 FK、直接设置仿真 qpos 后观察位姿，都可用于运动学检查。它们不说明需要多大力矩、能否稳定跟踪、途中是否碰撞；这些分别涉及动力学、控制和规划。
