# S4：运动学与数值求解

本文行数：31行，预期阅读时长：4分钟

**先明确机器人模型与任务，再从关节构型求位姿、从目标求关节解，并理解哪些方向能动、哪些限制会让任务失败。八章按“速记 + 例子 + 结果与解释”组织，无需执行代码即可复习。**

面向机械臂工程应用，优先使用已有运动学库与模型。**以理解输入输出、正确调用、检查结果和定位常见错误为主；算法推导与手写实现按需深入。** 八个主题保留作复习与查阅，不要求以相同深度逐章学完后再开始应用。

| 章节 | 要回答的问题 | 建议定位 | 学到什么程度 |
| --- | --- | --- | --- |
| [01 构型、关节空间与正运动学](01_forward_kinematics/README.md) | 给定关节角，末端在哪里、朝向哪里？ | 重点理解 | 会调用 FK，明确输入的关节顺序、单位与零位，以及输出位姿的参考系和工具点 |
| [02 标准 DH 与 Modified DH](02_dh_conventions/README.md) | 坐标系与参数表怎样决定变换链，为什么不能混用约定？ | 按需查阅 | 知道两种建模约定不能混用；使用现成模型时不要求熟练手列参数表，自建或核对 DH 模型时再深入 |
| [03 关节映射、基座与工具对齐](03_model_alignment/README.md) | 两个库的 FK 为什么可能不同？ | 重点理解 | 能确认比较的是同一组关节状态、同一参考系和同一工具点，定位模型集成中的常见偏差 |
| [04 Jacobian 与微分运动学](04_jacobian/README.md) | 关节的小变化与速度怎样影响任务量？ | 直观了解 | 理解关节速度到末端速度的映射；编写末端速度控制或数值 IK 时再深入计算与推导 |
| [05 解析逆运动学与数值迭代](05_inverse_kinematics/README.md) | 多解、不可达和没有收敛分别是什么意思？ | 重点理解使用行为 | 会设置目标和初值，区分多解、求解失败与不可达，会用 FK 检查解；不要求手写完整求解器 |
| [06 奇异性、秩与可操作性](06_singularities/README.md) | 为什么某个方向突然难以运动，奇异性与限位有什么区别？ | 直观了解 | 理解某些方向难以运动、所需关节速度可能放大的现象；秩和可操作性指标的推导按需查阅 |
| [07 冗余、零空间与次要目标](07_redundancy/README.md) | 多出来的关节自由度怎样利用？ | 按需查阅 | 知道冗余机械臂保持末端位姿时仍可能调整关节姿态；自行控制肘部姿态或避限位时再深入零空间方法 |
| [08 工作空间、关节限制与可达性](08_workspace_limits/README.md) | 长度够得着、IK 有解、路径可行和能够执行有什么区别？ | 重点理解 | 分清几何上够得着、IK 有解、姿态无碰撞、路径可行和能够执行，不把求解成功当作执行保证 |

推荐复习主线为 **01 FK → 03 模型对齐 → 05 IK 使用 → 08 可达性判断**；04、06 补充速度与奇异性的直觉，02、07 留作专题参考。对 Panda 这类七轴机械臂，值得了解冗余现象，但零空间算法不作为继续学习规划、控制与仿真的前置门槛。

多数例子采用固定基座的平面 2R，长度 `0.4 m`、`0.3 m`，关节顺序 `[q1,q2]`、角度单位 rad。冗余章改用 3R，并单独声明模型。示例数值不代表 Panda 或其他实际机械臂参数。
