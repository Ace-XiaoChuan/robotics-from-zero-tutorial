# 碰撞检测：状态有效与运动段有效

本文行数：48行，预期阅读时长：3分钟

**检查一个构型，只能说明这一刻的几何关系；检查一段运动，还要覆盖两个构型之间。**

## 速记要点

- 状态有效性通常包含限位、禁止碰撞和任务约束；“无碰撞”只是其中一项。
- 检查机器人与环境、非豁免的自碰撞，以及附着物体与环境的关系；只看 TCP 不够。
- 粗检测用包围体筛除明显不相交的对象对，精检测再处理具体几何。包围体重叠不一定代表真实几何碰撞。
- 离散检测可能漏过薄障碍；连续碰撞检测也必须匹配实际插值运动与几何模型。
- 允许碰撞表改变哪些对象对需要检查，不会让实体失去碰撞或产生夹持力。

## 例子一：端点和粗采样都通过，仍有漏检

教学模型是一维滑块，中心坐标 x 在世界 X 轴上移动，单位 m，滑块半宽 `0.02 m`。障碍占据 `[0.49,0.51] m`，边界接触也视为碰撞；其他维度保证重叠。

碰撞条件为滑块区间 `[x−0.02,x+0.02]` 与障碍相交，即中心落入 `[0.47,0.53] m`。

| 检查方式 | 检查位置（m） | 结果 |
| --- | --- | --- |
| 只查运动端点 | 0、1 | 都无碰撞，但运动会穿过障碍 |
| 均匀粗采样 | 0、0.2、0.4、0.6、0.8、1 | 全部通过，仍漏检 |
| 加查 x=0.5 | 0.5 | 检出碰撞 |
| 对整段作区间相交判断 | 连续区间 [0,1] | 检出碰撞 |

有限检查点通过，不能直接推论所有连续位置通过。

结果依据：一维区间的解析计算。机器人关节插值下连杆的运动更复杂，不能把此处 `0.2 m` 直接用作七关节规划分辨率。

## 例子二：几何间隙与误差余量

若模型表面间隙为 `0.008 m`，沿最不利接近方向，机器人与障碍位置误差的确定上界分别为 `0.003 m` 和 `0.004 m`，那么保守剩余间隙下界为：

```text
0.008 − 0.003 − 0.004 = 0.001 m
```

这是明确误差上界下的静态示意，不是概率保证；标准差不能直接当确定上界。若存在未计入的姿态误差、几何误差或控制跟踪误差，还需要重新评估。附着物体会改变几何外形与通过空间，空手路径不自动适用于持物状态。

## 与现有 MoveIt 章节衔接

[规划场景与物体附着](../04_planning_scene/README.md)负责对象 ID、参考系、场景更新和允许碰撞关系。本专题负责解释检测结论。修改场景、轨迹平滑或更换插值方式后，要重新检查最终运动；场景快照的结论不覆盖之后移动的障碍。

OMPL 区分状态检查器和运动检查器；离散运动检查的分辨率会影响漏检风险与计算量，见[官方状态有效性说明](https://ompl.kavrakilab.org/stateValidation.html)。本文没有运行真实碰撞引擎，也未证明本地 ROS 包的检测配置有效。
