# 碰撞场景与物体关系

本文行数：19行，预期阅读时长：1分钟

## 速记要点

碰撞物体的尺寸、位姿和参考坐标系一起定义障碍物；抓取时还要区分世界物体与附着物体。

## 例子

`hello_moveit.cpp` 把 `box1` 放在接口返回的 planning frame 中，尺寸为 (0.5,0.1,0.5) m，中心为 (0.2,0.2,0.25) m。

## 结果与解释

这是源码配置，不是碰撞检测运行结果。若位姿数值来自相机坐标系，必须先转换或明确指定相应 frame，不能直接当成 planning frame 下的坐标。
