# 采样规划：从合法状态连接出路径

本文行数：51行，预期阅读时长：3分钟

**采样规划把难以完整枚举的空间，变成“采样、尝试连接、检查运动段”的搜索。**

## 速记要点

- 采到合法点不够，连接边也必须合法；路径由通过运动检查的边组成。
- RRT 从已有树向采样点扩展；RRT-Connect 尝试让起点树与目标树相连。
- PRM 保存路网，便于同一问题空间中的多次查询；场景改变后旧节点和边可能失效。
- RRT* 在相应假设下具有渐近最优性质；一次有限预算结果不保证最短。
- 概率完备性讨论的是满足适用条件时，随采样量增长找到可行解的概率趋近 1，不是固定时间必成功。

上述算法分类与性质可查 [OMPL 规划器说明](https://ompl.kavrakilab.org/planners.html)。这里不假定仓库配置已启用某个规划器。

## 例子：树怎样接受一条绕路边？

沿用[总览](../01_motion_planning/README.md)的二维人为构型空间：`q=[q1,q2]`，单位 rad，起点 A=(0,0)，终点 B=(1,1)，禁止区域为闭矩形 `[0.4,0.6]×[0.4,0.6]`，合法范围为 `[0,1]²`。这不是从具体机械臂几何生成的障碍。

假定局部连接为关节直线，并对整段精确检查；下面是人为指定的搜索示意，不是随机规划器实测日志。

| 尝试 | 检查结果 | 搜索行为 |
| --- | --- | --- |
| A → B | 穿过禁止区域 | 拒绝这条边 |
| A → P=(0,0.8) | q1 始终为 0 | 接受 |
| P → Q=(1,0.8) | q2 始终为 0.8 | 接受 |
| Q → B | q1 始终为 1 | 接受，形成完整路径 |

等权关节欧氏度量下，绕行长度为 `0.8+1+0.2=2.0 rad`，直连长度为 `sqrt(2)≈1.4142 rad`，但直连无效。这里 rad 表示此特定纯转动关节度量的单位，不是末端移动距离。

若后处理尝试把 A 直接接到 Q，直线上 `q2=0.8 q1`；当 q1=0.5 时 q2=0.4，碰到禁止区域边界，应拒绝这次缩短。**路径变短必须以有效性仍成立为前提。**

## 为什么狭窄通道难？

高维空间中的可通过区域可能只占很小比例，均匀采样不容易落入；步长太大也可能反复产生无效连接。增加预算、改变采样策略或改善局部连接可能有帮助，但不能修复无效起点或互相矛盾的约束。

```text
检查起点与目标候选
    → 采样候选 → 选择近邻 → 生成扩展段
    → 检查整个运动段 → 接受或拒绝
    → 找到连接后回溯路径，或预算耗尽返回失败
```

实际算法的步长、目标采样和连接策略各不相同，上述流程只帮助理解。搜索超时只能记录“本次预算内未找到解”；只有额外证明才能宣称无解。

## 比较结果时看什么？

同一模型、场景、起终点、约束与检测分辨率下，分别看成功率、规划耗时、路径代价和最小间隙。记录随机种子与时间预算，失败样本不从成功率分母删除；几何路径代价不等于实际执行时间。本文只核对静态例子，没有做规划器性能评测。
