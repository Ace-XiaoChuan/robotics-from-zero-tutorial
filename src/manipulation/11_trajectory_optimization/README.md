# 轨迹优化：改变路径形状与运动代价

本文行数：53行，预期阅读时长：3分钟

**轨迹优化通过调整路径点或时间，让运动更符合指定代价和约束；代价降低不等于运动已经可执行。**

## 速记要点

- 几何路径优化改变“经过哪里”；固定路径的时间参数化改变“什么时候到达”；两者也可联合求解。
- 短、平滑、远离障碍、快和省力是不同目标，权重与单位会影响取舍。
- 局部优化依赖初值，可能陷入局部极小或找不到可行解；采样搜索与优化可以组合。
- 碰撞惩罚是软代价，有限权重不保证绝无碰撞；最终结果仍需独立检查约束和运动段。

## 一个离散问题长什么样？

设 n 个转动关节，路径用 N+1 个点 `q_0,…,q_N ∈ R^n` 表示，关节顺序固定，单位 rad；路径参数 s 的采样间隔一致。一个教学目标可写为：

```text
J = w_l Σ ||(q_(k+1) − q_k)/q_ref||²
  + w_s Σ ||(q_(k+1) − 2q_k + q_(k−1))/q_ref||²
  + w_c Σ max(0, (d_safe − d_k)/d_ref)²
```

`q_ref>0` 单位 rad；`d_k` 为构型处的有符号几何间隙，单位 m，正值表示分离；`d_safe` 与 `d_ref>0` 单位 m。权重非负，归一化后各项无量纲。第一项只是固定采样数下的位移平方代价，不能直接称为真实弧长；第二项衡量离散弯曲，不自动等于加速度。

端点、关节限位、路径约束及运动段无碰撞应另行满足。上式只是教学模型，不是 CHOMP、STOMP 或本地规划器的原样实现。

## 例子：更平滑的路径为什么反而无效？

使用二维人为构型空间，`q=[q1,q2]` 单位 rad，碰撞区域为闭矩形 `[0.4,0.6]²`，没有其他约束。三个等间隔路径点固定首尾为 A=(0,0)、B=(1,1)，只调整中间点 P。

| 中间点 | 二阶差分 A−2P+B | 差分平方范数（rad²） | 两段关节直线的碰撞结果 |
| --- | --- | --- | --- |
| P=(0,1) | (1,−1) | 2 | 均无碰撞 |
| P=(0.5,0.5) | (0,0) | 0 | 中间点已在障碍内 |

若只最小化这个平滑项，取 P=(A+B)/2 得到零代价，却穿过障碍。采样路径的平滑、插值或抄近路都可能破坏原来的有效性。

结果依据：差分和线段位置的静态推导；没有运行优化器。这里将边界接触视为碰撞。

## 平滑项与时间有什么关系？

只有各点按相同时间间隔 `Δt` 排列时，内部点的加速度才可用 `(q_(k+1)−2q_k+q_(k−1))/Δt²` 近似，单位 rad/s²；等 s 间隔不能替代等 t 间隔。时间变短可能使速度、加速度和力矩超限。

对固定光滑路径有 `q_dot=q'(s)s_dot` 和 `q_ddot=q''(s)s_dot²+q'(s)s_ddot`。时间参数化例子复用[运动规划总览](../01_motion_planning/README.md)，反馈与执行限制见[控制与约束](../../control/06_control_constraints/README.md)。如果后处理改变了路径形状，也必须重新检查几何有效性。

## 与现有案例的关系

可以先搜索可行路径，再优化形状，再安排时间，并检查最终轨迹；实际流水线是否这样组合要以配置与返回数据为准。若动力学、力矩或接触是任务限制，还要显式建模，不能只凭平滑关节曲线推断满足。
