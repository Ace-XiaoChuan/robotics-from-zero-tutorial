# 构型空间：整台机器人的状态与可行区域

本文行数：50行，预期阅读时长：3分钟

**把一组关节变量当成一个点，才能讨论整台机器人怎样绕过障碍。** 末端位置相同的两个构型，肘部位置和可通行路线可能不同。

## 速记要点

- 固定基座的 n 个独立关节通常用 n 维构型 q 表示；夹爪是否包含在内，取决于规划组和任务。
- 有限转动关节对应区间；真正连续转动的关节具有圆周拓扑。不能对有限位关节随意取最短角度差。
- 构型空间中的障碍由整台机器人与环境、自碰撞关系共同决定，通常不是工作空间障碍的简单复制。
- 几何规划状态 q 不含速度；讨论动力学可行性时，往往还需要状态 (q, q_dot) 和控制输入。

## 例子一：同一末端位置，两种肘部位置

输入为水平面内 2R 机械臂，两杆均长 1 m，基座为平面坐标原点。q 按 `[肩关节 q1, 肘关节 q2]` 排列，单位 rad，逆时针为正，q2 相对第一杆；忽略杆粗与自碰撞。末端位置：

```text
x = cos(q1) + cos(q1+q2)   m
y = sin(q1) + sin(q1+q2)   m
```

| 构型 | 肘部位置（m） | 末端位置（m） |
| --- | --- | --- |
| A = (0, π/2) | (1, 0) | (1, 1) |
| B = (π/2, −π/2) | (0, 1) | (1, 1) |

在 `(1,0) m` 放半径 `0.1 m` 的圆形障碍，A 的肘部处于障碍内，B 的两杆与障碍最近距离均为 1 m。**结果：** 同一个末端位置有碰撞和无碰撞的 IK 分支。两者末端朝向不同；本例目标只约束位置，不代表满足同一完整位姿。

结果依据：上述正运动学和线段距离的静态推导，并非真实机械臂碰撞测量。

## 例子二：179° 到 −179° 是多远？

对连续转动关节，圆周最短变化为 `+2° ≈ 0.0349 rad`。若关节限制为 `[-180°,180°]`，穿过上限的这条短路线不合法；区间内直接运动为 `−358° ≈ −6.2483 rad`。相同端点数值因关节拓扑和限位不同，插值方式也不同。

混合转动和移动关节时，不直接把 rad 与 m 的平方相加。可用归一化距离：

```text
d(q,a) = sqrt(Σ_i (Δq_i / scale_i)²)
```

`scale_i` 是与对应关节同单位的正尺度，距离无量纲；连续关节的差值按周期计算。尺度改变“谁是近邻”，因此会影响搜索，但它不等同于末端距离、执行时间或能量。

## 从合法构型到合法路径

先在位置限位内排除禁止碰撞得到 `C_free`，再加入任务的路径约束。若用 `q(s), s∈[0,1]` 表示路径，要求每个 s 都合法；s 无量纲，不是时间。目标通常是容差集合或多个 IK 解，不一定是唯一点。

起终点属于 `C_free` 不保证位于同一个连通区域。两点绕障例子复用[运动规划总览](../01_motion_planning/README.md)，可达范围与 IK 的关系见[工作空间与限位](../../kinematics/08_workspace_limits/README.md)。
