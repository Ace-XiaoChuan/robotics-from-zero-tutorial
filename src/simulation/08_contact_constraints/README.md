# 08：碰撞、接触、摩擦与约束

本文行数：106行，预期阅读时长：6分钟

## 开发者理解：表面相遇后，怎样互相施加力

把方块放在桌面上，需要模型允许方块自由运动、几何能够检测碰撞，并计算桌面对方块的支撑力。要让方块滑动时减速，还需要切向摩擦。只有画面中的外形相交，不足以说明这些物理关系已经建立。

本章用一个落地的方块解释“几何关系 → 接触 → 约束力 → 运动变化”。同样的检查思路可用于夹爪与物体，但抓取稳定性还取决于姿态、接触位置、驱动力和摩擦等条件。

## 速记：四个容易混在一起的概念

| 概念 | 负责什么 | 例子 |
| --- | --- | --- |
| 显示 | 画出物体外观 | 一个透明或精细的表面 |
| 碰撞检测 | 判断候选几何表面的接近、接触与距离 | 方块底面靠近地面 |
| 接触求解 | 结合当前运动求接触力 | 地面提供向上的支撑 |
| 摩擦 | 限制接触处的切向相对运动 | 水平滑动逐渐减速 |

接触模型通常允许有限柔顺性。关节限位、等式约束也通过约束求解影响运动，不能简单理解成每步把坐标硬裁剪到某个值。

## 例子：方块为什么能停在地面上

使用 [contact_box.xml](../mujoco/models/contact_box.xml)：世界系 z 向上，地面 z=0；方块质量 `0.2 kg`，半尺寸为 `(0.05,0.04,0.05) m`，因此高 `0.1 m`。初始中心在 `(0,0,0.06) m`，底部离地 `0.01 m`，通过 freejoint 自由运动。

重力为 `(0,0,-9.81) m/s²`，步长 `0.002 s`，`implicitfast` 积分。静置 500 步，即 1 秒后，得到：

| 实际读数（MuJoCo 3.13.0） | 结果 | 怎样理解 |
| --- | --- | --- |
| 方块中心 z | 约 `0.0499733 m` | 很接近理想无穿入高度 0.05 m |
| 接触点数量 | 4 | 本例盒子底面与平面的接触表示 |
| 法向力之和 | 约 `1.962 N` | 与 `0.2×9.81` 的重力大小相同 |

支撑不是“冻结方块的位置”，而是接触力使它趋于静止。中心略低于 0.05 m，对应本配置下有限的接触穿入；其大小与接触参数、负载和数值求解有关。4 个接触点也是这个几何与状态的结果，换成球面或其他配置不一定相同。

## 对照：关闭碰撞之后会怎样

保持模型与重力不变，仅把两个 geom 的 `contype`、`conaffinity` 都设为零。1 秒后无接触点、无法向支撑，方块中心 z 约为 `-4.85481 m`，已经穿过地面。

画面中的地面和方块仍然存在。这说明显示与碰撞可以独立配置；颜色透明或隐藏某个显示分组，也不会自动取消物理碰撞。

对于自动生成的常规碰撞对，过滤需要考虑掩码兼容性：

```text
(geom1.contype & geom2.conaffinity) != 0
或者
(geom2.contype & geom1.conaffinity) != 0
```

此外还有同体、父子关系过滤、显式 exclude、显式 pair 等规则。本例没有显式 pair，两侧掩码全部清零后不会生成地面接触。复杂模型出现异常时，要同时查看这些规则，不能只看一侧 geom 的某个属性。

## 对照：有支撑，不一定有摩擦

方块先静置 1 秒，再给世界系 `+x` 方向的初始速度 `1 m/s`，继续推进 `0.5 s`。这次速度赋值是设置滑动实验的初态，之后不再覆盖位置或速度。

| 接触配置 | 静置时法向支撑 / N | 0.5 s 内滑动距离 / m | 最终 x 速度 / m/s |
| --- | --- | --- | --- |
| 无摩擦：`condim=1`，只有法向约束 | 约 1.962 | 0.500000 | 1.000000 |
| 有摩擦：`condim=3`，滑动摩擦系数 0.6 | 约 1.962 | 0.084408 | 约 0 |

两种配置都支撑方块；有摩擦时切向力使它停下，无摩擦时保持水平速度。无摩擦对照同时使用法向单维接触，避免用退化的零摩擦锥作为教学配置。完整改参在[检查脚本](../mujoco/check_tutorial.py)中列出。

## friction 与 condim 分别控制什么

geom 的 `friction` 三项分别对应滑动、扭转和滚动摩擦。滑动系数无量纲；扭转、滚动系数在 MuJoCo 的力矩约束中具有长度单位 m，不能把三项都按普通无量纲滑动系数解释。

`condim` 决定这对接触使用哪些方向的约束：

| condim | 包含的接触约束 |
| --- | --- |
| 1 | 法向支撑，无摩擦 |
| 3 | 法向 + 两个切向滑动方向 |
| 4 | 再加入绕法向的扭转摩擦 |
| 6 | 再加入两个滚动摩擦方向 |

两个 geom 的参数需要合成为接触参数；本例优先级相同、摩擦设置相同。常规同优先级 geom 的摩擦按分量取较大值，因此只把地面的系数改小，未必得到预期的低摩擦对照。显式 pair 和优先级配置还可能改变规则，按需查官方参数说明。

## 接触软硬、穿入与数值稳定性

`solref` 与 `solimp` 用于表达约束响应与阻抗。直观上，它们影响接触偏离后怎样恢复、恢复得多快、多硬；不是一个简单的“允许穿入毫米数”开关。

本例沿用默认接触参数。若接触过硬而步长相对过大，求解可能更困难；把参数调得极硬，也不保证获得更合理的抓取行为。明显穿透时先查碰撞几何、过滤、初始重叠和速度，再逐项比较步长与约束参数。

常规刚性 mesh 的碰撞通常按凸包处理。一个看起来有凹槽的零件，可能在碰撞中被填成凸形；可以用多个简单或凸几何组合出需要的接触轮廓。外观细节和碰撞近似要分别检查。

## 关节限位与等式约束

joint range 限制关节的允许运动范围；等式约束可规定物体间的相对关系，例如 weld 约束相对位姿、joint 等式耦合关节。它们会给系统增加约束力，不是新增一个电机目标。

例如，令物体与夹爪 weld 后，约束会帮助保持相对位姿。这适合某些固定连接或简化任务，但不能据此评价真实夹持所需的摩擦和夹紧力。要研究夹持，应让实际接触承担相应载荷。

## 按需查阅：怎样读取接触力

先确保接触计算与所读状态一致，再遍历 `data.ncon`。每条接触包含 geom 对、位置、距离和接触坐标系；需要区分“检测到候选接触”与“当前有非零约束力”。

```python
wrench = np.zeros(6)
mujoco.mj_contactForce(model, data, contact_index, wrench)
normal_force = wrench[0]  # N，接触坐标系第一轴是法向
```

六项依次为接触系的力与力矩，不能直接当成世界系的 `[Fx,Fy,Fz,Tx,Ty,Tz]`。接触系的第一轴为法向，后两轴为切向；需要世界系向量时按接触 frame 旋转，并确认所求的是 geom 对中哪一侧的受力方向。本章的支撑求和利用了所有接触都在同一水平地面的条件。
