# 07：物理参数怎样影响运动

本文行数：82行，预期阅读时长：5分钟

## 开发者理解：外形和姿态相同，运动仍可能不同

一根空心杆和一根实心杆可以看起来一样，摆在相同角度时，杆尖位置也一样。但使它们加速、停止或保持姿态所需的力矩可能不同。模型的几何部分回答“东西在哪里”，物理参数进一步决定“受力后怎样变化”。

使用 MuJoCo 时，先知道参数控制哪种现象，就能提出明确需求：改变负载、增加阻尼、比较重力影响，或检查某个模型是否过轻。动力学公式的部分推导请查阅[动力学与控制](../../control/README.md)展开。

## 速记：参数对应什么现象

| 参数或设置 | 含义与单位 | 主要影响 |
| --- | --- | --- |
| mass | 刚体质量，kg | 平移惯性、重力及关节上的等效负载 |
| 质心位置 | 相对刚体的位置，m | 重力力矩、转动时的惯性 |
| inertia | 围绕质心的转动惯量，kg·m² | 各方向转动的难易程度 |
| gravity | 世界系重力加速度，m/s² | 自由下落与重力负载 |
| joint damping | 与速度相反的黏性阻力系数 | 衰减振动、减慢运动 |
| joint frictionloss | 关节中的干摩擦上限；hinge 为 N·m | 小输入下可能不启动，运动时产生阻力 |
| joint armature | 附加到自由度的惯性；hinge 为 kg·m² | 改变加速响应，常用于表示折算到关节的转子惯性 |
| timestep / integrator | 时间离散与积分方法 | 计算误差、稳定性和速度 |

hinge 的 damping 单位为 N·m·s/rad，slide 的为 N·s/m。`frictionloss` 是关节内部摩擦；物体与桌面的接触摩擦在[下一章](../08_contact_constraints/README.md)解释。

## 质量、质心和惯量怎样放在一起理解

质量说明“有多少惯性”，质心说明质量中心在哪里，惯量进一步说明质量围绕转轴怎样分布。同样质量移到离转轴更远的位置，通常更难加速转动。

MuJoCo 的 body 可以显式提供 `<inertial>`，也可以按配置从附属 geom 的形状、质量或密度推算。惯量不仅有三个数值，还对应质心位置和惯性坐标轴；从 CAD 或其他格式导入时，要一起核对单位与坐标系。

编译器从 geom 推算惯性，也意味着修改形状或密度可能同时改了质量和惯量。若只是想比较碰撞外形，应明确是否保持原来的惯性参数。

## 例子：质量翻倍，加速度是否减半

使用[单摆](../mujoco/models/pendulum.xml)，保持杆长 `0.5 m`、半径 `0.025 m`、角度 `0.5 rad` 不变，质量分别为 `1 kg`、`2 kg`。各次计算速度均为零，geom 自动推算惯性，没有额外 armature；关节未触及限位。

**实际计算结果（MuJoCo 3.13.0）：**

| 比较条件 | 1 kg 杆的角加速度 / rad/s² | 2 kg 杆的角加速度 / rad/s² |
| --- | --- | --- |
| 关闭重力，motor 输入相同 `0.2 N·m` | 2.315014 | 1.157507 |
| 只保留重力，motor 输入为零 | -13.609863 | -13.609863 |

第一行的驱动力矩相同，惯性翻倍，所以加速度减半。第二行的重力矩与惯性同时翻倍，二者比值保持不变，所以瞬时角加速度相同。负号表示朝本例零位方向加速。

两种质量下，杆尖位置均为 `(-0.239713,0,0.561209) m`。这组数据来自当前时刻的 forward 计算，没有推进时间，也没有声称两根杆在任意外力、阻尼和接触条件下始终走同一条轨迹。配置与判据见[验证记录](../mujoco/verification.md)。

## 阻尼、干摩擦与控制增益不是同一种参数

对简单 hinge，黏性阻尼产生类似 `tau_d = -b × qvel` 的力矩。若 `b=0.1 N·m·s/rad`、速度为 `2 rad/s`，阻尼项为 `-0.2 N·m`；速度为零时这一项也为零。

干摩擦则可能在尚未启动时抵消一部分驱动力。位置伺服增益根据目标误差产生驱动，两者的职责不同。把阻尼调大可能让抖动减小，同时也会改变原系统动力学；调高 kp 可能让响应更快，也可能增加峰值力与数值刚性。

本教程机械臂的 joint damping 为 `0.1`，位置执行器还设置 kv=8：前者是被动关节阻尼，后者是伺服产生的速度反馈项。分析总受力时，需要同时考虑，不能因为有 kv 就假定 joint damping 不存在。

## 尺度为什么容易引入大误差

假设使用固定密度的同类几何，把所有长度放大 s 倍：质量按 s³ 变化，围绕相应质心轴的惯量按 s⁵ 变化。这个比例来自体积增加和距离平方的共同作用。

因此，把毫米网格当成米加载，影响远大于“看起来大了些”。反过来，只改 mesh 的显示尺度、保持外部提供的质量和惯量不变，也未必得到物理一致的新机器人。模型通常按 SI 单位组织，程序不会自动识别 CAD 导出时使用了毫米。

## 步长与积分器怎样影响判断

本例单摆用 Euler；接触方块与两关节机械臂用 `implicitfast`，物理步长均为 `0.002 s`。较大的步长可能更快，也可能漏掉快速变化、增加误差或使高增益系统不稳定；稳定还受到惯量、阻尼、接触刚性和求解器设置影响。

遇到数值异常，先核对模型尺度、初始重叠和输入，再用较小步长作对照。对同一个问题分别用 dt 与 dt/2，比较同一仿真时刻的角度、速度、接触行为和误差，才能知道结果对步长是否敏感。窗口流畅本身不说明数值准确。

## 按需查阅：单关节公式怎样对应这些量

无耦合、无接触的简化关节可以写作：

```text
等效惯量 × 角加速度
  = 驱动力矩 + 重力矩 - 黏性阻尼力矩 - 其他阻力
```

质量、质心和惯量进入左侧等效惯量与右侧重力项；阻尼和摩擦进入阻力；执行器配置决定驱动力矩。多关节系统还包含耦合，详见[单关节](../../control/02_single_joint_dynamics/README.md)与[多关节动力学](../../control/03_multi_joint_dynamics/README.md)。
